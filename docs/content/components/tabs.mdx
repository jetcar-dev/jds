## 기본 사용법

`x-tabs-trigger`와 `x-tabs-content`에 같은 `value`를 지정하면 탭과 패널이 연결됩니다. 처음 선택할 항목은 `value`로 지정합니다.

```blade preview name="tabs-basic"
<x-tabs value="photos">
    <x-tabs-list aria-label="미디어 종류">
        <x-tabs-trigger value="photos">사진</x-tabs-trigger>
        <x-tabs-trigger value="music">음악</x-tabs-trigger>
        <x-tabs-trigger value="videos">동영상</x-tabs-trigger>
    </x-tabs-list>
    <x-tabs-content value="photos">사진 콘텐츠입니다.</x-tabs-content>
    <x-tabs-content value="music">음악 콘텐츠입니다.</x-tabs-content>
    <x-tabs-content value="videos">동영상 콘텐츠입니다.</x-tabs-content>
</x-tabs>
```

### 동적으로 만들기

서버에서 받은 배열은 Blade 반복문으로 렌더링합니다. 항목 배열을 별도 속성으로 변환하지 않아 탭 제목과 패널에 원하는 마크업을 그대로 넣을 수 있습니다.

```blade preview name="tabs-dynamic"
@php
    $mediaTabs = [
        'photos' => ['label' => '사진', 'content' => '사진 12개'],
        'music' => ['label' => '음악', 'content' => '재생 목록 4개'],
        'videos' => ['label' => '동영상', 'content' => '동영상 7개'],
    ];
@endphp

<x-tabs value="photos">
    <x-tabs-list aria-label="보관함">
        @foreach($mediaTabs as $key => $tab)
            <x-tabs-trigger :value="$key">{{ $tab['label'] }}</x-tabs-trigger>
        @endforeach
    </x-tabs-list>
    @foreach($mediaTabs as $key => $tab)
        <x-tabs-content :value="$key">{{ $tab['content'] }}</x-tabs-content>
    @endforeach
</x-tabs>
```

### 전체 비활성화

`disabled`를 지정하면 모든 항목을 선택할 수 없습니다.

```blade preview name="tabs-disabled"

    <x-tabs-list aria-label="비활성 탭">
```

### 특정 항목 비활성화

각 `x-tabs-trigger`에 `disabled`를 지정하거나, 루트의 `disabled-keys`에 여러 값을 한 번에 전달할 수 있습니다.

```blade preview name="tabs-disabled-item"

    <x-tabs-list aria-label="일부 비활성 탭">
        <x-tabs-trigger value="photos">사진</x-tabs-trigger>
        <x-tabs-trigger value="music">음악</x-tabs-trigger>
```

### 아이콘과 함께 사용하기

`startContent`, `endContent` named slot으로 제목 앞뒤에 아이콘이나 배지를 넣습니다.

```blade preview name="tabs-icons"
<x-tabs color="primary" value="profile">
    <x-tabs-list aria-label="계정 메뉴">
        <x-tabs-trigger value="profile">
            <x-slot:startContent><x-icon name="solar:user-linear" /></x-slot:startContent>
            프로필
        </x-tabs-trigger>
        <x-tabs-trigger value="security">
            <x-slot:startContent><x-icon name="solar:lock-linear" /></x-slot:startContent>
            보안
        </x-tabs-trigger>
    </x-tabs-list>
    <x-tabs-content value="profile">프로필 설정입니다.</x-tabs-content>
    <x-tabs-content value="security">보안 설정입니다.</x-tabs-content>
```

### 선택값 제어하기

Blade에서 `selected-key` 또는 `value`로 초기 선택값을 지정합니다. 화면이 열린 뒤에는 Controller의 `setValue()`로 선택값을 바꿀 수 있습니다.

```blade preview name="tabs-controlled"
<div class="jds-example-stack">
    <x-tabs id="controlled-tabs" selected-key="music">
        <x-tabs-list aria-label="제어되는 탭">
            <x-tabs-trigger value="photos">사진</x-tabs-trigger>
            <x-tabs-trigger value="music">음악</x-tabs-trigger>
            <x-tabs-trigger value="videos">동영상</x-tabs-trigger>
        </x-tabs-list>
        <x-tabs-content value="photos">사진 콘텐츠입니다.</x-tabs-content>
        <x-tabs-content value="music">음악 콘텐츠입니다.</x-tabs-content>
        <x-tabs-content value="videos">동영상 콘텐츠입니다.</x-tabs-content>
    </x-tabs>
    <x-button size="sm" variant="bordered" onclick="AppUI.get(document.querySelector('#controlled-tabs')).setValue('videos')">
        동영상 선택
    </x-button>
</div>
```

### 위치

`placement`는 `top`, `bottom`, `start`, `end`를 지원합니다. `start`와 `end`에서는 탭 목록이 세로로 배치됩니다.

```blade preview name="tabs-placement"
<div class="jds-example-stack">
    @foreach(['top', 'bottom', 'start', 'end'] as $placement)
        <x-tabs :placement="$placement" value="overview">
            <x-tabs-list :aria-label="$placement.' 위치'">
                <x-tabs-trigger value="overview">개요</x-tabs-trigger>
                <x-tabs-trigger value="details">상세</x-tabs-trigger>
            </x-tabs-list>
            <x-tabs-content value="overview">{{ $placement }} 위치의 콘텐츠입니다.</x-tabs-content>
            <x-tabs-content value="details">상세 콘텐츠입니다.</x-tabs-content>
        </x-tabs>
    @endforeach
</div>
```

### 링크로 사용하기

`href`를 지정한 항목은 `<a>`로 렌더링되어 브라우저의 기본 링크 동작을 유지합니다. 현재 주소에 맞는 `value`를 서버에서 넘겨 선택 상태를 동기화할 수 있습니다.

```blade preview name="tabs-links"
<x-tabs value="overview">
    <x-tabs-list aria-label="문서 이동">
        <x-tabs-trigger value="overview" href="#overview">개요</x-tabs-trigger>
        <x-tabs-trigger value="api" href="#api">API</x-tabs-trigger>
        <x-tabs-trigger value="examples" href="#examples">예제</x-tabs-trigger>
    </x-tabs-list>
</x-tabs>
```

### 폼과 함께 사용하기

`name`을 지정하면 현재 선택값을 hidden input으로 전송합니다. 탭이 바뀔 때 native `input`, `change` 이벤트도 발생합니다.

```blade preview name="tabs-form"

            <x-tabs-trigger value="signup">회원가입</x-tabs-trigger>
```

## 슬롯

- `tabWrapper`: 위치와 방향에 맞게 탭 목록과 패널을 배치하는 루트
- `base`: 탭 목록의 외부 영역
- `tabList`: 탭 항목 목록
- `tab`: 개별 탭
- `tabContent`: 탭의 제목, 아이콘과 추가 콘텐츠
- `cursor`: 선택 상태를 표시하는 움직이는 배경 또는 밑줄
- `panel`: 선택된 탭의 콘텐츠

각 슬롯에는 같은 이름의 `data-slot`이 있어 별도 CSS에서 안정적으로 선택할 수 있습니다.

## 상태 속성

개별 탭에는 `data-hover`, `data-focus-visible`, `data-pressed`, `data-selected`, `data-disabled`가 반영됩니다. 루트에는 현재 값과 `data-orientation`, `data-placement`, `data-disabled`가 반영됩니다.

## 이벤트와 Controller

선택이 바뀌면 `app-ui:tabs:change` 이벤트가 발생하고 `event.detail.value`로 선택값을 전달합니다. `AppUI.get(tabs)`은 다음 메서드를 제공합니다.

- `getValue()`: 현재 선택값 반환
- `setValue(value)`: 항목 선택
- `focus()`: 선택된 탭으로 초점 이동
- `destroy()`: 이벤트와 관찰자 해제

`should-select-on-press-up`의 기본값은 `true`입니다. `false`로 지정하면 포인터를 누르는 순간 선택합니다. `disable-cursor-animation`은 움직이는 선택 표시를 숨기고, `disable-animation`은 정적인 선택 스타일을 사용합니다.

## 접근성

`tablist`, `tab`, `tabpanel` 역할과 `aria-selected`, `aria-controls`, `aria-labelledby`를 자동으로 연결합니다. 가로 탭은 좌우 방향키, 세로 탭은 위아래 방향키로 이동하며 Home/End도 지원합니다. `keyboard-activation="manual"`에서는 방향키로 초점만 이동하고 Enter 또는 Space로 선택합니다. 비활성 패널은 기본적으로 DOM에서 제거되며 `:destroy-inactive-tab-panel="false"`로 유지할 수 있습니다.
