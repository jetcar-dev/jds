## 기본 사용법

탭 버튼과 패널의 value를 같게 지정해 서로 연결합니다. 선택 표시와 패널 전환 효과는 자동으로 적용됩니다.

```blade preview name="tabs-default"
<x-tabs value="account">
    <x-tabs-list>
        <x-tabs-trigger value="account">계정</x-tabs-trigger>
        <x-tabs-trigger value="security">보안</x-tabs-trigger>
    </x-tabs-list>
    <x-tabs-content value="account">
        <x-input name="email" type="email" placeholder="이메일" />
    </x-tabs-content>
    <x-tabs-content value="security">
        <x-button variant="bordered">비밀번호 변경</x-button>
    </x-tabs-content>
</x-tabs>
```

## 전체 너비와 긴 라벨

`full-width`를 켜면 콘텐츠뿐 아니라 탭 목록과 각 탭도 같은 너비를 나눠 사용합니다. 공간보다 긴 라벨은 영역 밖으로 밀어내지 않고 말줄임 처리됩니다.

```blade preview name="tabs-full-width"
<x-tabs value="overview" variant="solid" full-width>
    <x-tabs-list>
        <x-tabs-trigger value="overview">전체 계약 현황</x-tabs-trigger>
        <x-tabs-trigger value="scheduled">곧 만료되는 장기 계약</x-tabs-trigger>
        <x-tabs-trigger value="closed">종료된 계약</x-tabs-trigger>
    </x-tabs-list>
    <x-tabs-content value="overview">전체 계약 내용</x-tabs-content>
    <x-tabs-content value="scheduled">만료 예정 계약 내용</x-tabs-content>
    <x-tabs-content value="closed">종료 계약 내용</x-tabs-content>
</x-tabs>
```

## 전체 너비와 비활성화

full-width는 탭을 같은 너비로 배치하고 disabled는 선택할 수 없는 항목을 표시합니다.

```blade preview name="tabs-advanced"
<x-tabs value="overview" variant="light" full-width>
    <x-tabs-list>
        <x-tabs-trigger value="overview">개요</x-tabs-trigger>
        <x-tabs-trigger value="history">이력</x-tabs-trigger>
        <x-tabs-trigger value="beta" disabled>베타</x-tabs-trigger>
    </x-tabs-list>
    <x-tabs-content value="overview">개요</x-tabs-content>
    <x-tabs-content value="history">변경 이력</x-tabs-content>
    <x-tabs-content value="beta">베타 기능</x-tabs-content>
</x-tabs>
```

## 대시보드 화면 전환

패널에는 카드, 표, 폼 등 구조가 다른 콘텐츠를 그대로 넣을 수 있습니다.

```blade preview name="tabs-dashboard"
<x-tabs value="summary" variant="solid" full-width>
    <x-tabs-list>
        <x-tabs-trigger value="summary">요약</x-tabs-trigger>
        <x-tabs-trigger value="activity">최근 활동</x-tabs-trigger>
    </x-tabs-list>
    <x-tabs-content value="summary">
        <div class="jds-example-grid">
            <x-card variant="secondary"><x-card-title>운행 차량</x-card-title><x-card-content>128대</x-card-content></x-card>
            <x-card variant="tertiary"><x-card-title>정비 예정</x-card-title><x-card-content>7대</x-card-content></x-card>
        </div>
    </x-tabs-content>
    <x-tabs-content value="activity">
        <x-card><x-card-content>차량 12가 3456의 배차가 완료되었습니다.</x-card-content></x-card>
    </x-tabs-content>
</x-tabs>
```
