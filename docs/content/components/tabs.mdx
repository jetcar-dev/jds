## 크기와 상태

`sm`, `md`, `lg` 크기와 disabled, invalid, selected, loading 상태는 컴포넌트 성격에 맞게 사용합니다. 상태는 루트의 안정적인 `data-*` 속성에도 반영됩니다.

```blade preview name="tabs-states"
<div data-theme="dark" style="padding:1rem;background:var(--background);color:var(--foreground)"><x-tabs value="photos"><x-tabs-list><x-tabs-trigger value="photos">사진</x-tabs-trigger><x-tabs-trigger value="music">음악</x-tabs-trigger></x-tabs-list><x-tabs-content value="photos">사진 콘텐츠</x-tabs-content><x-tabs-content value="music">음악 콘텐츠</x-tabs-content></x-tabs></div>
```

## 폼 전송

입력 컴포넌트는 실제 input 또는 hidden input을 렌더링합니다. 표시 전용 컴포넌트는 폼 안에서도 값 전송에 관여하지 않습니다.

```blade preview name="tabs-form"
<form method="post"><x-tabs value="photos"><x-tabs-list><x-tabs-trigger value="photos">사진</x-tabs-trigger><x-tabs-trigger value="music">음악</x-tabs-trigger></x-tabs-list><x-tabs-content value="photos">사진 콘텐츠</x-tabs-content><x-tabs-content value="music">음악 콘텐츠</x-tabs-content></x-tabs><x-button type="submit" size="sm">전송</x-button></form>
```

## 슬롯

기본 슬롯과 컴포넌트별 named slot을 사용해 아이콘, 설명, 사용자 정의 콘텐츠를 배치합니다. 목록형 컴포넌트는 배열보다 명시적인 하위 컴포넌트를 기본으로 사용합니다.

## 이벤트와 Controller

값 변경 시 native `input/change`와 `app-ui:tabs:change` 이벤트가 발생합니다. `AppUI.get(element)`로 controller를 가져와 지원되는 `getValue`, `setValue`, `open`, `close`, `focus`, `destroy`를 호출할 수 있습니다.

## 접근성

접근 가능한 이름을 제공하고 키보드 탐색, focus-visible, reduced motion을 보존합니다. 아이콘만 있는 작업에는 반드시 `aria-label`을 지정합니다.
