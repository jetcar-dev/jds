## 기본 사용법

name과 placeholder만 지정하면 서식 도구가 포함된 편집기를 사용할 수 있습니다.

```blade preview name="rich-text-editor-default"
<x-rich-text-editor
    name="content"
    :value="old('content', $post->content)"
    placeholder="내용을 입력해 주세요"
/>
```

## 형태

긴 글 입력 화면의 밀도에 맞춰 flat, faded, bordered를 선택합니다.

```blade preview name="rich-text-editor-variants"
<x-rich-text-editor variant="flat" placeholder="Flat" />
<x-rich-text-editor variant="faded" placeholder="Faded" />
<x-rich-text-editor variant="bordered" placeholder="Bordered" />
```

## 초기 내용 표시

저장된 HTML 콘텐츠를 초기값으로 표시합니다.

```blade preview name="rich-text-editor-initial-value"
<x-rich-text-editor name="content" value="<h2>공지사항</h2><p>내용을 수정하세요.</p>" />
```

## 입력 필드로 사용

라벨과 오류 상태를 포함한 폼 필드로 구성합니다.

```blade preview name="rich-text-editor-form"
<x-field :invalid="$errors->has('content')">
    <x-label for="content" required>본문</x-label>
    <x-rich-text-editor id="content" name="content" :value="old('content')" />
    <x-field-error :messages="$errors->get('content')" />
</x-field>
```

## 공지사항 작성

제목 입력과 공개 설정을 함께 배치한 실제 공지 작성 화면 예제입니다.

```blade preview name="rich-text-editor-announcement"
<x-card style="width: min(100%, 42rem);">
    <x-card-header>
        <x-card-title>공지사항 작성</x-card-title>
        <x-card-description>임직원에게 표시할 공지를 작성합니다.</x-card-description>
    </x-card-header>
    <x-card-content>
        <x-field><x-label for="notice-title">제목</x-label><x-input id="notice-title" name="title" full-width /></x-field>
        <x-field><x-label for="notice-body">내용</x-label><x-rich-text-editor id="notice-body" name="body" placeholder="공지 내용을 입력하세요" /></x-field>
    </x-card-content>
    <x-card-footer style="justify-content: flex-end; gap: 0.5rem;">
        <x-button variant="ghost">임시 저장</x-button><x-button>게시</x-button>
    </x-card-footer>
</x-card>
```

## 전체 너비

편집기를 폼이나 카드의 전체 너비로 확장합니다.

```blade preview name="rich-text-editor-full-width"
<x-rich-text-editor name="content" full-width placeholder="내용을 입력해 주세요" />
```
