## 기본 사용법

머리말, 본문, 하단 작업 영역을 조합하는 기본 카드입니다. 각 영역에는 원하는 Blade 컴포넌트나 HTML을 자유롭게 넣을 수 있습니다.

```blade preview name="card-default"
<x-card>
    <x-card-header>
        <x-card-title>차량 정보</x-card-title>
        <x-card-description>등록된 차량의 기본 정보입니다.</x-card-description>
    </x-card-header>

    <x-card-content>
        <strong>12가 3456</strong>
        <span>2026 현대 쏘나타</span>
    </x-card-content>

    <x-card-footer>
        <x-button size="sm">상세 보기</x-button>
    </x-card-footer>
</x-card>
```

## 강조 수준

정보의 중요도와 주변 배경에 맞춰 transparent, default, secondary, tertiary, outline 중 하나를 선택합니다.

```blade preview name="card-variants"
<x-card variant="transparent">
    <x-card-title>Transparent</x-card-title>
    <x-card-content>배경과 테두리가 없는 카드</x-card-content>
</x-card>

<x-card variant="default">
    <x-card-title>Default</x-card-title>
    <x-card-content>기본 surface 카드</x-card-content>
</x-card>

<x-card variant="secondary">
    <x-card-title>Secondary</x-card-title>
    <x-card-content>한 단계 낮은 강조 카드</x-card-content>
</x-card>

<x-card variant="tertiary">
    <x-card-title>Tertiary</x-card-title>
    <x-card-content>가장 낮은 강조 카드</x-card-content>
</x-card>

<x-card variant="outline">
    <x-card-title>Outline</x-card-title>
    <x-card-content>그림자 없이 테두리만 표시하는 카드</x-card-content>
</x-card>
```

## 내용 자유롭게 구성하기

카드 본문은 자유로운 슬롯이므로 입력 화면, 목록, 표처럼 복잡한 내용도 그대로 구성할 수 있습니다.

```blade preview name="card-custom-content"
<x-card variant="secondary">
    <x-card-header>
        <x-card-title as="h2">담당자 설정</x-card-title>
        <x-card-description>업무를 담당할 직원을 선택하세요.</x-card-description>
    </x-card-header>

    <x-card-content>
        <x-label for="manager">담당자</x-label>
        <x-select id="manager" name="manager" :options="[
            'kim' => '김담당',
            'lee' => '이담당',
        ]" :full-width="true" />
    </x-card-content>

    <x-card-footer style="justify-content: flex-end; gap: 0.5rem;">
        <x-button variant="ghost">취소</x-button>
        <x-button>저장</x-button>
    </x-card-footer>
</x-card>
```

## 요약 정보 배치

같은 구조의 카드를 반응형 격자에 배치해 핵심 업무 수치를 한눈에 비교합니다.

```blade preview name="card-summary-grid"
<div class="jds-example-grid">
    <x-card><x-card-title>오늘 접수</x-card-title><x-card-content><strong style="font-size: 1.5rem;">24건</strong></x-card-content></x-card>
    <x-card variant="secondary"><x-card-title>처리 중</x-card-title><x-card-content><strong style="font-size: 1.5rem;">8건</strong></x-card-content></x-card>
    <x-card variant="tertiary"><x-card-title>처리 완료</x-card-title><x-card-content><strong style="font-size: 1.5rem;">16건</strong></x-card-content></x-card>
</div>
```
