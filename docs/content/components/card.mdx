## 기본 사용법

Card는 관련 콘텐츠를 하나의 표면에 담습니다.

```blade preview name="card-basic"
<div style="display:flex;width:100%;justify-content:center;align-items:center">
    <x-card>
        <x-card-body>
            <p style="margin:0">Make beautiful websites regardless of your design experience.</p>
        </x-card-body>
    </x-card>
</div>
```

## 주요 작업

`pressable`은 Card를 실제 버튼으로 렌더링합니다. 공식 예제와 같은 8개 과일 Card를 4열로 배치했습니다.

```blade preview name="card-pressable"
<div style="display:grid;width:100%;grid-template-columns:repeat(4,minmax(0,1fr));gap:8px">
    @foreach([
        ['Orange', '$5.50', 1],
        ['Tangerine', '$3.00', 2],
        ['Raspberry', '$10.00', 3],
        ['Lemon', '$5.30', 4],
        ['Avocado', '$15.70', 5],
        ['Lemon 2', '$8.00', 6],
        ['Banana', '$7.50', 7],
        ['Watermelon', '$12.20', 8],
    ] as [$name, $price, $image])
        <x-card pressable shadow="sm" aria-label="{{ $name }} 선택">
            <x-card-body style="overflow:visible;padding:0">
                <img
                    src="https://v2.heroui.com/images/fruit-{{ $image }}.jpeg"
                    alt="{{ $name }}"
                    style="display:block;width:100%;height:140px;border-radius:12px;object-fit:cover;box-shadow:var(--shadow-small)"
                />
            </x-card-body>
            <x-card-footer style="justify-content:space-between;font-size:14px">
                <strong>{{ $name }}</strong>
                <p style="margin:0;color:hsl(var(--default-500))">{{ $price }}</p>
            </x-card-footer>
        </x-card>
    @endforeach
</div>
```

## 슬롯

- `base`: Header, Body와 Footer를 감싸는 Card 표면
- `header`: Card 상단 영역
- `body`: Card의 주 콘텐츠 영역
- `footer`: Card 하단 작업 영역

## 상태 속성

Card 루트에는 상호작용 상태에 따라 `data-hover`, `data-focus`, `data-focus-visible`, `data-disabled`, `data-pressed`가 반영됩니다.

## 이벤트와 Controller

`pressable` Card는 `app-ui:card:press-start`, `app-ui:card:press-end`, `app-ui:card:press-change`, `app-ui:card:press` 이벤트를 발생시킵니다.

```js
const card = document.querySelector('[data-ui-component="card"]');
const controller = AppUI.get(card);

controller.focus();
controller.press();
```

## 접근성

일반 Card는 `<div>`로, `pressable` Card는 실제 `<button type="button">`으로 렌더링됩니다. pressable Card에는 `aria-label`처럼 접근 가능한 이름을 제공하세요. 내부에 별도 링크나 버튼이 있다면 Card 자체는 pressable로 만들지 않습니다.

## API

| 속성 | 타입 | 기본값 |
| --- | --- | --- |
| `shadow` | `none \| sm \| md \| lg` | `md` |
| `radius` | `none \| sm \| md \| lg` | `lg` |
| `full-width` | boolean | `false` |
| `hoverable` | boolean | `false` |
| `pressable` | boolean | `false` |
| `blurred` | boolean | `false` |
| `footer-blurred` | boolean | `false` |
| `disabled` | boolean | `false` |
| `disable-animation` | boolean | `false` |
| `disable-ripple` | boolean | `false` |
| `allow-text-selection-on-press` | boolean | `false` |
