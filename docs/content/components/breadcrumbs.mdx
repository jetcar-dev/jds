## 기본 사용법

목록에는 명시적인 `<x-breadcrumb-item>`을 넣습니다. 마지막 항목은 별도 속성이 없어도 현재 페이지로 처리됩니다.

```blade preview name="breadcrumbs-basic"
<x-breadcrumbs>
    <x-breadcrumb-item href="/">Home</x-breadcrumb-item>
    <x-breadcrumb-item href="/music">Music</x-breadcrumb-item>
    <x-breadcrumb-item href="/music/artist">Artist</x-breadcrumb-item>
    <x-breadcrumb-item href="/music/artist/album">Album</x-breadcrumb-item>
    <x-breadcrumb-item>Song</x-breadcrumb-item>
</x-breadcrumbs>
```

## 비활성

루트에 `disabled`를 지정하면 현재 페이지를 제외한 모든 이동을 막습니다. 특정 항목만 막으려면 해당 항목에 지정합니다.

```blade preview name="breadcrumbs-disabled"
<div style="display:grid;gap:1rem">
    <x-breadcrumbs disabled>
        <x-breadcrumb-item href="/">Home</x-breadcrumb-item>
        <x-breadcrumb-item href="/music">Music</x-breadcrumb-item>
        <x-breadcrumb-item>Song</x-breadcrumb-item>
    </x-breadcrumbs>
    <x-breadcrumbs>
        <x-breadcrumb-item href="/">Home</x-breadcrumb-item>
        <x-breadcrumb-item href="/music" disabled>Music</x-breadcrumb-item>
        <x-breadcrumb-item>Song</x-breadcrumb-item>
    </x-breadcrumbs>
</div>
```

## 형태

기본값인 `light`는 배경 없는 경로입니다. `solid`는 옅은 배경, `bordered`는 2px 테두리와 약한 그림자를 사용합니다.

```blade preview name="breadcrumbs-variants"
<div style="display:grid;gap:1rem">
    <x-breadcrumbs variant="solid"><x-breadcrumb-item href="/">Home</x-breadcrumb-item><x-breadcrumb-item>Song</x-breadcrumb-item></x-breadcrumbs>
    <x-breadcrumbs variant="bordered"><x-breadcrumb-item href="/">Home</x-breadcrumb-item><x-breadcrumb-item>Song</x-breadcrumb-item></x-breadcrumbs>
    <x-breadcrumbs variant="light"><x-breadcrumb-item href="/">Home</x-breadcrumb-item><x-breadcrumb-item>Song</x-breadcrumb-item></x-breadcrumbs>
</div>
```

## 밑줄과 모서리

`underline`은 `none`, `hover`, `always`, `active`, `focus`를 지원합니다. `radius`는 `none`, `sm`, `md`, `lg`, `full`을 지원합니다.

```blade preview name="breadcrumbs-underline-radius"
<div style="display:grid;gap:1rem">
    <x-breadcrumbs underline="hover" radius="none"><x-breadcrumb-item href="/">Hover</x-breadcrumb-item><x-breadcrumb-item>Song</x-breadcrumb-item></x-breadcrumbs>
    <x-breadcrumbs underline="always" radius="lg"><x-breadcrumb-item href="/">Always</x-breadcrumb-item><x-breadcrumb-item>Song</x-breadcrumb-item></x-breadcrumbs>
    <x-breadcrumbs underline="focus" radius="full"><x-breadcrumb-item href="/">Focus</x-breadcrumb-item><x-breadcrumb-item>Song</x-breadcrumb-item></x-breadcrumbs>
</div>
```

## 시작·끝 콘텐츠

아이콘이나 보조 콘텐츠는 항목의 named slot에 넣습니다.

```blade preview name="breadcrumbs-content"
<x-breadcrumbs variant="light">
    <x-breadcrumb-item href="/">
        <x-slot:startContent><x-icon name="solar:home-angle-2-linear" /></x-slot:startContent>
        Home
    </x-breadcrumb-item>
    <x-breadcrumb-item href="/music">
        <x-slot:startContent><x-icon name="solar:bookmark-linear" /></x-slot:startContent>
        Music
    </x-breadcrumb-item>
    <x-breadcrumb-item>
        Song
        <x-slot:endContent><x-icon name="solar:bolt-linear" /></x-slot:endContent>
    </x-breadcrumb-item>
</x-breadcrumbs>
```

## 구분자

루트의 `separator`는 전체 구분자를 바꾸고, 항목의 `separator`는 해당 항목만 덮어씁니다. `hide-separator`로 숨길 수도 있습니다.

```blade preview name="breadcrumbs-separator"
<div style="display:grid;gap:1rem">
    <x-breadcrumbs separator="/">
        <x-breadcrumb-item href="/">Home</x-breadcrumb-item>
        <x-breadcrumb-item href="/music">Music</x-breadcrumb-item>
        <x-breadcrumb-item>Song</x-breadcrumb-item>
    </x-breadcrumbs>
    <x-breadcrumbs>
        <x-breadcrumb-item href="/" separator="•">Home</x-breadcrumb-item>
        <x-breadcrumb-item href="/music">Music</x-breadcrumb-item>
        <x-breadcrumb-item>Song</x-breadcrumb-item>
    </x-breadcrumbs>
</div>
```

## 긴 경로 접기

항목이 `max-items`보다 많으면 처음 `items-before-collapse`개와 마지막 `items-after-collapse`개만 남기고 중간을 줄입니다. 줄임표는 첫 번째로 숨겨진 항목의 링크를 사용합니다.

```blade preview name="breadcrumbs-collapse"
<x-breadcrumbs :max-items="3" :items-before-collapse="1" :items-after-collapse="2">
    <x-breadcrumb-item href="/">Home</x-breadcrumb-item>
    <x-breadcrumb-item href="/music">Music</x-breadcrumb-item>
    <x-breadcrumb-item href="/music/artist">Artist</x-breadcrumb-item>
    <x-breadcrumb-item href="/music/artist/album">Album</x-breadcrumb-item>
    <x-breadcrumb-item>Song</x-breadcrumb-item>
</x-breadcrumbs>
```

## 현재 항목 제어

현재 항목을 명시하려면 `current`를 지정합니다. 동적으로 바꿀 때는 각 항목에 `item-key`를 주고 controller의 `setValue(key)`를 호출합니다. 변경 시 `app-ui:breadcrumbs:change`, 항목 실행 시 `app-ui:breadcrumbs:action` 이벤트가 발생합니다.

```blade preview name="breadcrumbs-controlled"
<x-breadcrumbs id="account-path" variant="light">
    <x-breadcrumb-item item-key="profile" href="#profile" current>프로필</x-breadcrumb-item>
    <x-breadcrumb-item item-key="security" href="#security">보안</x-breadcrumb-item>
    <x-breadcrumb-item item-key="billing" href="#billing">결제</x-breadcrumb-item>
</x-breadcrumbs>
```

```js
const breadcrumbs = document.querySelector('#account-path');
AppUI.get(breadcrumbs).setValue('security');
```

## 슬롯

Breadcrumbs는 `base`, `list`, `ellipsis`, `separator`, BreadcrumbItem은 `base`, `item`, `separator`, `start-content`, `end-content` 슬롯을 제공합니다.

## 접근성

`nav`와 순서 있는 목록으로 렌더링되며 마지막 또는 `current` 항목에는 `aria-current="page"`가 설정됩니다. 키보드로 링크에 접근할 수 있고 포커스가 분명하게 표시됩니다.

## API

### Breadcrumbs

| 속성 | 타입 | 기본값 |
| --- | --- | --- |
| `variant` | `solid` \| `bordered` \| `light` | `light` |
| `color` | `foreground` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `foreground` |
| `size` | `sm` \| `md` \| `lg` | `md` |
| `radius` | `none` \| `sm` \| `md` \| `lg` \| `full` | `sm` |
| `underline` | `none` \| `active` \| `hover` \| `focus` \| `always` | `none` |
| `separator` | string | 기본 화살표 |
| `max-items` | number | `null` |
| `items-before-collapse` | number | `1` |
| `items-after-collapse` | number | `1` |
| `hide-separator` | boolean | `false` |
| `disabled` | boolean | `false` |
| `disable-animation` | boolean | `false` |
| `aria-label` | string | `Breadcrumbs` |

### BreadcrumbItem

| 속성 | 타입 | 기본값 |
| --- | --- | --- |
| `href` | string | `null` |
| `current` | boolean | 마지막 항목 |
| `disabled` | boolean | `false` |
| `hide-separator` | boolean | `false` |
| `separator` | string | 부모 구분자 |
| `color` | Breadcrumbs color | 부모 값 |
| `size` | `sm` \| `md` \| `lg` | 부모 값 |
| `underline` | Breadcrumbs underline | 부모 값 |
| `item-key` | string | 항목 텍스트 |
