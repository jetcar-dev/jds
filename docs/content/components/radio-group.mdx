## 기본 사용법

value => label 배열만 전달합니다.

```blade preview name="radio-group-default"
<x-radio-group name="plan" value="standard" :options="[
    'basic' => '기본',
    'standard' => '스탠다드',
]" />
```

## 설명과 함께 사용

설명과 비활성 상태가 필요하면 항목만 배열로 확장합니다.

```blade preview name="radio-group-descriptions"
<x-radio-group name="delivery" :options="[
    'normal' => ['label' => '일반 배송', 'description' => '2~3일 소요'],
    'dawn' => ['label' => '새벽 배송', 'description' => '현재 준비 중', 'disabled' => true],
]" />
```

## 가로 배치

한 줄 배치도 속성 하나로 변경합니다.

```blade preview name="radio-group-horizontal"
<x-radio-group name="status" orientation="horizontal" :options="['all' => '전체', 'active' => '활성']" />
```

## 업무 옵션 선택

업무 선택지는 라벨과 설명을 함께 제공해 차이를 바로 이해할 수 있게 합니다.

```blade preview name="radio-group-business-options"
<div class="jds-example-surface" style="width: min(100%, 32rem);">
    <strong>정산 주기</strong>
    <x-radio-group name="settlement_cycle" value="weekly" :options="[
        'daily' => ['label' => '매일', 'description' => '매 영업일 자동 정산'],
        'weekly' => ['label' => '매주', 'description' => '매주 월요일 일괄 정산'],
        'monthly' => ['label' => '매월', 'description' => '매월 첫 영업일 정산'],
    ]" />
</div>
```

## 박스형 라디오

박스형에서도 키보드 방향키 이동과 단일 선택 규칙이 그대로 유지됩니다. `show-indicator`의 기본값은 `true`입니다.

```blade preview name="radio-group-box"
<x-radio-group name="payment" value="card" variant="box" :options="[
    'card' => ['label' => '카드 결제', 'description' => '법인 카드로 즉시 결제'],
    'invoice' => ['label' => '세금계산서', 'description' => '월말에 일괄 정산'],
]" />

<x-radio-group
    name="density"
    value="comfortable"
    variant="box"
    orientation="horizontal"
    :show-indicator="false"
    :options="['compact' => '좁게', 'comfortable' => '보통', 'spacious' => '넓게']"
/>
```
