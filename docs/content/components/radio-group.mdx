## 기본 사용법

그룹 안에 `x-radio-group-item`을 넣습니다. 그룹의 `name`과 `value`가 제출 이름과 초기 선택값을 담당합니다.

```blade preview name="radio-group-default"
<x-radio-group name="plan" value="standard">
    <x-radio-group-item value="basic">기본</x-radio-group-item>
    <x-radio-group-item value="standard">스탠다드</x-radio-group-item>
</x-radio-group>
```

## 설명과 함께 사용

항목에 `description`과 `disabled`를 직접 지정합니다.

```blade preview name="radio-group-descriptions"
<x-radio-group name="delivery">
    <x-radio-group-item value="normal" description="2~3일 소요">일반 배송</x-radio-group-item>
    <x-radio-group-item value="dawn" description="현재 준비 중" disabled>새벽 배송</x-radio-group-item>
</x-radio-group>
```

## 가로 배치

한 줄 배치도 속성 하나로 변경합니다.

```blade preview name="radio-group-horizontal"
<x-radio-group name="status" orientation="horizontal">
    <x-radio-group-item value="all">전체</x-radio-group-item>
    <x-radio-group-item value="active">활성</x-radio-group-item>
</x-radio-group>
```

## 업무 옵션 선택

각 항목을 직접 작성하므로 항목별 설명과 상태를 읽기 쉽게 관리할 수 있습니다.

```blade preview name="radio-group-business-options"
<div class="jds-example-surface" style="width: min(100%, 32rem);">
    <strong>정산 주기</strong>
    <x-radio-group name="settlement_cycle" value="weekly">
        <x-radio-group-item value="daily" description="매 영업일 자동 정산">매일</x-radio-group-item>
        <x-radio-group-item value="weekly" description="매주 월요일 일괄 정산">매주</x-radio-group-item>
        <x-radio-group-item value="monthly" description="매월 첫 영업일 정산">매월</x-radio-group-item>
    </x-radio-group>
</div>
```

## 박스형 라디오

박스형에서도 키보드 방향키 이동과 단일 선택 규칙이 그대로 유지됩니다. `show-indicator`의 기본값은 `true`입니다.
그룹은 기본적으로 항목 너비에 맞고, 부모 너비를 모두 사용하려면 `full-width`를 지정합니다.

```blade preview name="radio-group-box"
<x-radio-group name="payment" value="card" variant="box" full-width>
    <x-radio-group-item value="card" description="법인 카드로 즉시 결제">카드 결제</x-radio-group-item>
    <x-radio-group-item value="invoice" description="월말에 일괄 정산">세금계산서</x-radio-group-item>
</x-radio-group>

<x-radio-group
    name="density"
    value="comfortable"
    variant="box"
    orientation="horizontal"
    :show-indicator="false"
>
    <x-radio-group-item value="compact">좁게</x-radio-group-item>
    <x-radio-group-item value="comfortable">보통</x-radio-group-item>
    <x-radio-group-item value="spacious">넓게</x-radio-group-item>
</x-radio-group>
```
