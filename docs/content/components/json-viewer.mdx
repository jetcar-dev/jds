## 기본 사용법

배열이나 객체를 value에 전달하면 자료형에 따라 색상이 구분된 트리로 표시됩니다.

```blade preview name="json-viewer-default"
<x-json-viewer
    root-label="응답 데이터"
    :data="['status' => 'success', 'items' => [['id' => 1]]]"
/>
```

## 접힌 상태로 시작

큰 데이터는 접힌 상태로 시작합니다.

```blade preview name="json-viewer-collapsed"
<x-json-viewer root-label="API 응답" :expanded="false" :data="$response" />
```

## 값 유형

문자열, 숫자, boolean, null, 배열을 구분해 표시합니다.

```blade preview name="json-viewer-types"
<x-json-viewer :data="['name' => 'JetCar', 'count' => 12, 'active' => true, 'memo' => null, 'tags' => ['ERP', 'UI']]" />
```

## 중첩된 API 응답

중첩된 객체와 배열도 레벨별로 접고 펼치며 전체 JSON을 복사할 수 있습니다.

```blade preview name="json-viewer-nested-response"
<x-json-viewer root-label="배차 API" :data="[
    'status' => 'success',
    'vehicle' => ['id' => 42, 'plate' => '12가 3456'],
    'driver' => ['name' => '김기사', 'available' => true],
    'stops' => [
        ['order' => 1, 'address' => '서울시 강남구'],
        ['order' => 2, 'address' => '서울시 송파구'],
    ],
]" />
```
