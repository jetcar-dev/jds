parts: [button]
---

## 기본 사용법

기본값은 `solid`, `default`, `md`입니다.

```blade preview name="button-basic"
<x-button>Button</x-button>
```

## 형태

작업의 중요도와 성격에 맞는 variant를 선택합니다.

```blade preview name="button-variants"
<x-button variant="solid">Solid</x-button>
<x-button variant="faded">Faded</x-button>
<x-button variant="bordered">Bordered</x-button>
<x-button variant="light">Light</x-button>
<x-button variant="flat">Flat</x-button>
<x-button variant="ghost">Ghost</x-button>
<x-button variant="shadow">Shadow</x-button>
```

## 색상

variant와 별개로 의미 색상을 선택합니다.

```blade preview name="button-colors"
<x-button color="default">Default</x-button>
<x-button color="primary">Primary</x-button>
<x-button color="secondary">Secondary</x-button>
<x-button color="success">Success</x-button>
<x-button color="warning">Warning</x-button>
<x-button color="danger">Danger</x-button>
```

## 아이콘과 함께 사용

버튼 텍스트 앞이나 뒤에 Solar 아이콘을 배치할 수 있습니다.

```blade preview name="button-with-icons"
<x-button>
    <x-icon name="diskette-linear" />
    저장
</x-button>

<x-button variant="bordered">
    다운로드
    <x-slot:after><x-icon name="download-minimalistic-linear" /></x-slot:after>
</x-button>
```

## 아이콘 버튼

텍스트가 없는 버튼에는 접근성 이름을 반드시 제공합니다.

```blade preview name="button-icon-only"
<x-button :icon-only="true" aria-label="설정">
    <x-icon name="settings-linear" />
</x-button>

<x-button variant="bordered" color="danger" :icon-only="true" aria-label="삭제">
    <x-icon name="trash-bin-trash-linear" />
</x-button>
```

## 처리 중 상태

진행 중에는 버튼을 비활성화하고 현재 상태를 알립니다.

```blade preview name="button-loading"
<x-button :disabled="true" aria-busy="true">
    <span class="app-ui-spinner" aria-hidden="true"></span>
    저장 중
</x-button>
```

## 크기

화면 밀도와 버튼의 중요도에 맞춰 크기를 선택합니다.

```blade preview name="button-sizes"
<x-button size="xs">Extra Small</x-button>
<x-button size="sm">Small</x-button>
<x-button size="md">Medium</x-button>
<x-button size="lg">Large</x-button>
<x-button size="xl">Extra Large</x-button>
```

## 비활성 상태

실행할 수 없는 작업은 disabled 상태로 표시합니다.

```blade preview name="button-disabled"
<x-button :disabled="true">Disabled</x-button>
<x-button variant="faded" color="secondary" :disabled="true">Disabled</x-button>
<x-button variant="bordered" color="danger" :disabled="true">Disabled</x-button>
```

## 전체 너비

`full-width`를 사용하면 버튼이 부모 영역의 너비를 모두 채웁니다.

```blade preview name="button-full-width"
<x-button color="primary" :full-width="true">계속</x-button>
```
