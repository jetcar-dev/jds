## 기본 사용법

라벨과 함께 사용해 설정의 켜짐과 꺼짐 상태를 즉시 바꿉니다.

```blade preview name="switch-default"
<x-switch name="notifications" value="1" label="알림 받기" checked />
```

## 크기

폼 밀도에 맞춰 크기를 선택합니다.

```blade preview name="switch-sizes"
<x-switch size="xs" aria-label="매우 작게" />
<x-switch size="sm" aria-label="작게" />
<x-switch size="md" aria-label="기본" />
<x-switch size="lg" aria-label="크게" />
<x-switch size="xl" aria-label="매우 크게" />
```

## 상태

켜짐, 꺼짐, 비활성 상태를 비교합니다.

```blade preview name="switch-states"
<x-switch checked aria-label="켜짐" />
<x-switch :checked="false" aria-label="꺼짐" />
<x-switch checked disabled aria-label="비활성" />
```

## 설정 목록

설정 이름과 설명을 왼쪽에 두고 즉시 변경할 값을 오른쪽에 배치합니다.

```blade preview name="switch-settings"
<div class="jds-example-surface" style="width: min(100%, 32rem);">
    <div class="jds-example-between">
        <span><strong>이메일 알림</strong><br><small>새 주문이 등록되면 알려줍니다.</small></span>
        <x-switch name="email_notifications" checked aria-label="이메일 알림" />
    </div>
    <div class="jds-example-between">
        <span><strong>자동 배차</strong><br><small>조건에 맞는 기사에게 자동 배정합니다.</small></span>
        <x-switch name="auto_dispatch" aria-label="자동 배차" />
    </div>
</div>
```
