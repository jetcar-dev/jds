## 사용법

Divider는 관련된 콘텐츠를 시각적으로 나눕니다. 기본 방향은 `horizontal`이며, 세로로 배치하려면 `orientation="vertical"`을 지정합니다.

```blade preview name="divider-basic"
<section style="width: 100%; max-width: 20rem;">
    <h3 style="margin: 0; font-size: 1rem;">JDS Components</h3>
    <p style="margin: .25rem 0 0; color: hsl(var(--default-500));">
        빠르고 일관된 Blade UI 컴포넌트입니다.
    </p>

    <x-divider style="margin-block: 1rem;" />

    <nav aria-label="관련 링크" style="display: flex; height: 1.25rem; align-items: center;">
        <x-link href="#">Blog</x-link>
        <x-divider orientation="vertical" style="margin-inline: 1rem;" />
        <x-link href="#">Docs</x-link>
        <x-divider orientation="vertical" style="margin-inline: 1rem;" />
        <x-link href="#">Source</x-link>
    </nav>
</section>
```

## 방향

가로 Divider는 부모의 전체 너비를 사용하고 높이는 `1px`입니다. 세로 Divider는 너비가 `1px`이며 부모가 제공하는 높이를 채웁니다.

```blade preview name="divider-orientations"
<div style="display: grid; width: 100%; gap: 1.5rem;">
    <div>
        <span>상단 콘텐츠</span>
        <x-divider style="margin-block: .75rem;" />
        <span>하단 콘텐츠</span>
    </div>

    <div style="display: flex; height: 1.25rem; align-items: center;">
        <span>왼쪽</span>
        <x-divider orientation="vertical" style="margin-inline: 1rem;" />
        <span>오른쪽</span>
    </div>
</div>
```

## 데이터 속성

루트에는 `data-ui-component="divider"`, `data-slot="base"`가 제공됩니다. `data-orientation`에는 현재 방향인 `horizontal` 또는 `vertical`이 반영됩니다.

## API

| 속성 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `orientation` | `horizontal` \| `vertical` | `horizontal` | 구분선의 방향을 지정합니다. |

## 접근성

루트에 `role="separator"`와 현재 방향을 나타내는 `aria-orientation`을 제공합니다. 가로 Divider는 실제 `<hr>`로, 세로 Divider는 접근 가능한 `<div role="separator">`로 렌더링됩니다.
