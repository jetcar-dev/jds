## 사용법

Range Calendar는 처음에는 선택값이 없습니다. `value`에는 `start`, `end` 키를 가진 배열을 전달합니다. 시작일을 선택한 뒤 다른 날짜로 포인터를 옮기면 확정 전 범위를 미리 보여주며, 두 번째 날짜를 선택하면 범위가 확정됩니다.

```blade preview name="range-calendar-basic"
<x-range-calendar
    label="휴가 기간"
    visible-month="2026-08-01"
/>

<x-range-calendar
    label="예약 기간"
    :value="['start' => '2026-08-11', 'end' => '2026-08-18']"
    visible-month="2026-08-01"
/>
```

## 비활성화

`disabled`를 사용하면 날짜와 이전·다음 버튼을 포커스하거나 실행할 수 없습니다.

```blade preview name="range-calendar-disabled"
<x-range-calendar
    :value="['start' => '2026-08-11', 'end' => '2026-08-18']"
    visible-month="2026-08-01"
    disabled
/>
```

## 읽기 전용

`read-only`는 범위를 변경하지 않지만 현재 범위를 확인하고 달을 이동할 수 있습니다.

```blade preview name="range-calendar-readonly"
<x-range-calendar
    :value="['start' => '2026-08-11', 'end' => '2026-08-18']"
    visible-month="2026-08-01"
    read-only
/>
```

## 최소 날짜와 최대 날짜

`min-value`, `max-value` 범위 밖의 날짜는 흐리게 표시되며 선택할 수 없습니다.

```blade preview name="range-calendar-bounds"
<x-range-calendar
    :value="['start' => '2026-08-12', 'end' => '2026-08-17']"
    visible-month="2026-08-01"
    min-value="2026-08-10"
    max-value="2026-08-20"
/>
```

## 선택할 수 없는 날짜

`unavailable-values`에 포함된 날짜는 취소선으로 표시되고 선택할 수 없습니다. 기본값에서는 선택 범위 안에도 포함할 수 없습니다.

```blade preview name="range-calendar-unavailable"
<x-range-calendar
    visible-month="2026-08-01"
    :unavailable-values="[
        '2026-08-08', '2026-08-09',
        '2026-08-15', '2026-08-16',
    ]"
/>
```

## 비연속 범위

`allows-non-contiguous-ranges`를 사용하면 선택할 수 없는 날짜가 사이에 있어도 시작일과 종료일을 확정할 수 있습니다. 해당 날짜는 범위 안에 포함되지만 선택 불가 표시는 그대로 유지됩니다.

```blade preview name="range-calendar-non-contiguous"
<x-range-calendar
    label="휴가 신청"
    visible-month="2026-08-01"
    :unavailable-values="[
        '2026-08-08', '2026-08-09',
        '2026-08-15', '2026-08-16',
    ]"
    allows-non-contiguous-ranges
/>
```

## 포커스 날짜

선택값과 별개로 처음 포커스할 날짜를 지정하려면 `default-focused-value`를 사용합니다. Controller의 `focus()`도 이 날짜를 기준으로 동작합니다.

```blade preview name="range-calendar-focused"
<x-range-calendar
    visible-month="2026-08-01"
    default-focused-value="2026-08-20"
    auto-focus
/>
```

## 오류 상태

선택한 범위가 업무 규칙에 맞지 않을 때 `invalid`와 `error-message`를 함께 사용합니다.

```blade preview name="range-calendar-invalid"
<x-range-calendar
    :value="['start' => '2026-08-08', 'end' => '2026-08-16']"
    visible-month="2026-08-01"
    invalid
    error-message="휴가 기간은 7일을 넘을 수 없습니다."
/>
```

## 월과 연도 선택

`show-month-and-year-pickers`를 사용하면 제목을 눌러 연도와 월을 빠르게 이동할 수 있습니다. 이 기능은 한 달을 표시할 때 사용할 수 있습니다.

```blade preview name="range-calendar-month-year"
<x-range-calendar
    :value="['start' => '2026-08-11', 'end' => '2026-08-18']"
    show-month-and-year-pickers
/>
```

## 여러 달 표시

`visible-months`는 한 번에 1~3개월을 표시합니다. `selection-alignment`는 선택 범위를 표시 영역의 `start`, `center`, `end` 중 어디에 맞출지 정합니다.

```blade preview name="range-calendar-visible-months"
<x-range-calendar
    :value="['start' => '2026-08-28', 'end' => '2026-09-08']"
    :visible-months="3"
    selection-alignment="center"
/>
```

## 주 시작 요일

기본값은 `locale`을 따릅니다. 직접 지정하려면 `sun`, `mon`, `tue`, `wed`, `thu`, `fri`, `sat` 중 하나를 사용합니다.

```blade preview name="range-calendar-week-start"
<x-range-calendar
    visible-month="2026-08-01"
    first-day-of-week="mon"
/>
```

## 페이지 이동 방식

여러 달을 표시할 때 기본 `visible`은 표시 중인 달 수만큼 이동하고, `single`은 이전·다음 버튼을 누를 때 한 달씩 이동합니다.

```blade preview name="range-calendar-page-behavior"
<x-range-calendar
    visible-month="2026-08-01"
    :visible-months="2"
    page-behavior="single"
/>
```

## 프리셋

프리셋은 표시명과 `start`, `end` 날짜를 가진 배열로 구성합니다. 버튼을 누르면 범위 전체가 한 번에 적용됩니다.

```blade preview name="range-calendar-presets"
<x-range-calendar
    visible-month="2026-08-01"
    :presets="[
        '이번 주' => ['start' => '2026-08-10', 'end' => '2026-08-16'],
        '다음 주' => ['start' => '2026-08-17', 'end' => '2026-08-23'],
        '월말' => ['start' => '2026-08-24', 'end' => '2026-08-31'],
    ]"
/>
```

## 위와 아래 콘텐츠

`topContent`, `bottomContent` named slot으로 안내 문구나 별도 작업을 배치할 수 있습니다.

```blade preview name="range-calendar-content"
<x-range-calendar visible-month="2026-08-01">
    <x-slot:topContent>
        <strong>출장 기간 선택</strong>
    </x-slot:topContent>

    <x-slot:bottomContent>
        시작일과 종료일을 차례로 선택하세요.
    </x-slot:bottomContent>
</x-range-calendar>
```

## 폼 전송

`name`을 지정하면 hidden input에 `{"start":"Y-m-d","end":"Y-m-d"}` 형식의 JSON 문자열이 저장됩니다. 값이 바뀌면 native `input`, `change`와 `app-ui:range-calendar:change` 이벤트가 발생합니다.

```blade preview name="range-calendar-form"
<form method="post" class="jds-example-stack">
    <x-range-calendar
        id="vacation-range"
        name="vacation_period"
        visible-month="2026-08-01"
    />
    <x-button type="submit" size="sm">신청</x-button>
</form>
```

## 슬롯

Range Calendar는 Calendar의 `base`, `top-content`, `bottom-content`, `preset-group`, `preset`, `content`, `prev-button`, `next-button`, `header-wrapper`, `header`, `title`, `grid-wrapper`, `grid`, `grid-header`, `grid-body`, `grid-body-row`, `cell`, `cell-button`, `picker-wrapper`, `helper-wrapper`, `error-message` 슬롯을 그대로 제공합니다.

## 이벤트와 Controller

```js
const calendar = document.querySelector('#vacation-range')
const controller = AppUI.get(calendar)

controller.setValue({
    start: '2026-08-11',
    end: '2026-08-18',
}, true)
```

Controller는 `getValue()`, `setValue()`, `next()`, `previous()`, `focus()`, `destroy()`를 제공합니다.

## 접근성

시작일을 선택한 뒤 방향키로 날짜를 이동하면 확정 전 범위를 확인할 수 있고 Enter 또는 Space로 종료일을 확정합니다. Home/End는 주의 처음과 끝, Page Up/Page Down은 이전·다음 달로 이동합니다. 범위 안의 모든 날짜는 선택 상태로 전달되고 시작일과 종료일은 별도로 구분됩니다.
