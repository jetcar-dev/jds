## 기본 사용법

`content`는 배지에 표시할 숫자나 짧은 문구입니다. 배지의 기준이 되는 요소는 기본 슬롯에 넣습니다.

```blade preview name="badge-basic"
<x-badge content="5" color="primary" aria-label="읽지 않은 알림 5개">
    <x-avatar name="J" color="primary" />
</x-badge>
```

배지 내용만으로 중요한 정보를 전달하지 마세요. 숫자의 의미를 알 수 있도록 루트에 `aria-label`을 함께 지정하는 편이 안전합니다.

## 크기

`size`는 `sm`, `md`, `lg`를 지원합니다.

```blade preview name="badge-sizes"
<div style="display:flex;align-items:center;gap:2rem;padding:.5rem">
    <x-badge content="5" size="sm" color="primary"><x-avatar name="S" size="sm" /></x-badge>
    <x-badge content="5" size="md" color="primary"><x-avatar name="M" /></x-badge>
    <x-badge content="5" size="lg" color="primary"><x-avatar name="L" size="lg" /></x-badge>
</div>
```

## 색상

의미에 맞춰 `default`, `primary`, `secondary`, `success`, `warning`, `danger`를 사용합니다.

```blade preview name="badge-colors"
<div style="display:flex;flex-wrap:wrap;gap:2rem;padding:.5rem">
    <x-badge content="5" color="default"><x-avatar name="D" /></x-badge>
    <x-badge content="5" color="primary"><x-avatar name="P" /></x-badge>
    <x-badge content="5" color="secondary"><x-avatar name="S" /></x-badge>
    <x-badge content="5" color="success"><x-avatar name="O" /></x-badge>
    <x-badge content="5" color="warning"><x-avatar name="W" /></x-badge>
    <x-badge content="5" color="danger"><x-avatar name="D" /></x-badge>
</div>
```

## 형태

`variant`는 `solid`, `flat`, `faded`, `shadow`를 지원합니다.

```blade preview name="badge-variants"
<div style="display:flex;flex-wrap:wrap;gap:2rem;padding:.5rem">
    <x-badge content="5" color="warning" variant="solid"><x-avatar name="S" /></x-badge>
    <x-badge content="5" color="warning" variant="flat"><x-avatar name="F" /></x-badge>
    <x-badge content="5" color="warning" variant="faded"><x-avatar name="F" /></x-badge>
    <x-badge content="5" color="warning" variant="shadow"><x-avatar name="S" /></x-badge>
</div>
```

## 위치

`placement`로 네 모서리 중 하나를 선택합니다.

```blade preview name="badge-placements"
<div style="display:flex;flex-wrap:wrap;gap:2rem;padding:.5rem">
    <x-badge content="5" placement="top-right" color="danger"><x-avatar name="TR" /></x-badge>
    <x-badge content="5" placement="bottom-right" color="danger"><x-avatar name="BR" /></x-badge>
    <x-badge content="5" placement="top-left" color="danger"><x-avatar name="TL" /></x-badge>
    <x-badge content="5" placement="bottom-left" color="danger"><x-avatar name="BL" /></x-badge>
</div>
```

## 기준 요소의 모양

원형 요소에는 `shape="circle"`, 사각형 요소에는 기본값인 `rectangle`을 사용하면 모서리 위치가 자연스럽게 보정됩니다.

```blade preview name="badge-shapes"
<div style="display:flex;align-items:center;gap:2rem;padding:.5rem">
    <x-badge content="5" shape="circle" color="primary"><x-avatar name="원" /></x-badge>
    <x-badge content="5" shape="rectangle" color="primary"><x-button icon-only aria-label="받은 편지함"><x-icon name="solar:inbox-linear" /></x-button></x-badge>
</div>
```

## 점과 짧은 콘텐츠

`dot`은 내용 없는 상태점, `one-char`는 한 글자 크기를 고정한 배지를 만듭니다.

```blade preview name="badge-content"
<div style="display:flex;align-items:center;gap:2rem;padding:.5rem">
    <x-badge dot color="success"><x-avatar name="온라인" /></x-badge>
    <x-badge content="N" one-char color="secondary"><x-avatar name="신규" /></x-badge>
    <x-badge content="new" color="danger"><x-avatar name="새 메시지" /></x-badge>
</div>
```

## 표시 여부와 외곽선

`invisible`로 자리를 유지한 채 배지를 숨길 수 있습니다. 기본 외곽선은 `show-outline="false"` 또는 `disable-outline`로 제거합니다.

```blade preview name="badge-states"
<div style="display:flex;align-items:center;gap:2rem;padding:.5rem">
    <x-badge content="5" invisible color="danger"><x-avatar name="숨김" /></x-badge>
    <x-badge content="5" :show-outline="false" color="danger"><x-avatar name="외곽선 없음" /></x-badge>
    <x-badge content="5" disable-outline disable-animation color="danger"><x-avatar name="애니메이션 없음" /></x-badge>
</div>
```

`AppUI.get(element).show()`와 `hide()`로 표시 상태를 바꿀 수 있으며 `getValue()`, `setValue(value)`로 내용도 읽고 바꿀 수 있습니다.

## 슬롯

- `base`: 기준 요소와 배지를 감싸는 루트
- `badge`: 배지 콘텐츠

## 접근성

배지는 보조적인 시각 정보입니다. 상태나 개수를 정확히 읽어야 한다면 기준 요소에 전체 의미가 담긴 `aria-label`을 제공합니다.

## API

| 속성 | 타입 | 기본값 |
| --- | --- | --- |
| `content` | string \| number | `null` |
| `variant` | `solid` \| `flat` \| `faded` \| `shadow` | `solid` |
| `color` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `default` |
| `size` | `sm` \| `md` \| `lg` | `md` |
| `shape` | `circle` \| `rectangle` | `rectangle` |
| `placement` | `top-right` \| `top-left` \| `bottom-right` \| `bottom-left` | `top-right` |
| `show-outline` | boolean | `true` |
| `disable-outline` | boolean | `false` |
| `disable-animation` | boolean | `false` |
| `invisible` | boolean | `false` |
| `one-char` | boolean | `false` |
| `dot` | boolean | `false` |
