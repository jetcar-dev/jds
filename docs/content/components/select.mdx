## 기본 사용법

기본 슬롯에 option을 넣어 브라우저 기본 선택 메뉴와 같은 방식으로 사용합니다.

```blade preview name="select-default"
<x-select
    name="status"
    value="active"
    placeholder="상태 선택"
    :options="['active' => '활성', 'inactive' => '비활성']"
    :full-width="true"
/>
```

## 배열로 항목 전달

value와 label 배열로 항목을 빠르게 구성합니다.

```blade preview name="select-options"
<x-select name="status" :options="['active' => '활성', 'inactive' => '비활성']" value="active" />
```

## 형태, 색상과 크기

모든 입력 컴포넌트와 동일한 공통 값을 사용합니다.

```blade preview name="select-appearance"
<x-select variant="flat" color="default" size="xs" :options="$options" />
<x-select variant="faded" color="success" size="md" :options="$options" />
<x-select variant="bordered" color="primary" size="sm" :options="$options" />
<x-select variant="light" color="secondary" size="md" :options="$options" />
<x-select variant="solid" color="primary" size="lg" :options="$options" />
<x-select variant="ghost" color="danger" size="lg" :options="$options" />
<x-select variant="shadow" color="warning" size="xl" :options="$options" />
```

## 여러 항목 선택

여러 항목을 선택해 배열로 제출합니다.

```blade preview name="select-multiple"
<x-select name="roles" :options="$roles" :value="['admin', 'manager']" :multiple="true" indicator="checkbox" />
```

## 상태

오류, 필수, 비활성 상태를 표시합니다.

```blade preview name="select-states"
<x-select name="required" :options="$options" :required="true" />
<x-select name="invalid" :options="$options" :invalid="true" />
<x-select name="disabled" :options="$options" :disabled="true" />
```
