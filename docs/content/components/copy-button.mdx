## 기본 사용법

value에 전달한 문자열을 클립보드에 복사하고 완료 상태를 알려 줍니다.

```blade preview name="copy-button-default"
<x-copy-button value="JETCAR-ERP-2026" label="코드 복사">
    코드 복사
</x-copy-button>
```

## 아이콘 버튼

좁은 영역에서는 아이콘만 표시합니다.

```blade preview name="copy-button-icon-only"
<x-copy-button value="ORD-2026-001" label="주문번호 복사" />
```

## 비활성 상태

복사할 수 없는 값은 비활성화합니다.

```blade preview name="copy-button-disabled"
<x-copy-button value="" label="복사 불가" :disabled="true">복사</x-copy-button>
```

## 값과 함께 배치

주문번호나 API 키처럼 읽기 전용 값을 보여 주는 영역에 복사 버튼을 함께 배치합니다.

```blade preview name="copy-button-inline-value"
<div class="jds-example-between jds-example-surface" style="max-width: 28rem;">
    <code>ORD-2026-000184</code>
    <x-copy-button value="ORD-2026-000184" label="주문번호 복사" />
</div>
```
