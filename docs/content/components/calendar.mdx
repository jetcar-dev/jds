## 사용법

Calendar는 기본적으로 오늘이 포함된 달을 보여주며 선택값은 없습니다. `value`로 초기 선택 날짜를 지정할 수 있습니다.

```blade preview name="calendar-basic"
<x-calendar label="예약일" visible-month="2026-08-01" />
<x-calendar label="결제일" value="2026-08-05" />
```

## 비활성화

`disabled` 상태에서는 날짜와 이전·다음 버튼을 포커스하거나 실행할 수 없습니다.

```blade preview name="calendar-disabled"
<x-calendar value="2026-08-05" disabled />
```

## 읽기 전용

`read-only`는 선택값을 변경하지 않지만 날짜 탐색과 키보드 포커스는 유지합니다.

```blade preview name="calendar-readonly"
<x-calendar value="2026-08-05" read-only />
```

## 색상

선택 날짜의 의미 색상은 `default`, `primary`, `secondary`, `success`, `warning`, `danger` 중에서 선택합니다.

```blade preview name="calendar-colors"
<x-calendar value="2026-08-05" color="primary" />
<x-calendar value="2026-08-05" color="success" />
<x-calendar value="2026-08-05" color="danger" />
```

## 최소 날짜와 최대 날짜

`min-value`, `max-value` 범위 밖의 날짜는 흐리게 표시되며 선택할 수 없습니다.

```blade preview name="calendar-bounds"
<x-calendar
    value="2026-08-15"
    min-value="2026-08-10"
    max-value="2026-08-20"
/>
```

## 선택할 수 없는 날짜

`unavailable-values`는 키보드 탐색에는 포함되지만 선택할 수 없는 날짜입니다. HeroUI와 동일하게 흐린 기본 색상과 취소선으로 표시됩니다.

```blade preview name="calendar-unavailable"
<x-calendar
    visible-month="2026-08-01"
    :unavailable-values="['2026-08-08', '2026-08-09', '2026-08-15', '2026-08-16']"
/>
```

## 오류 상태

애플리케이션 검증에서 선택값이 유효하지 않다면 `invalid`와 `error-message`를 함께 사용합니다.

```blade preview name="calendar-invalid"
<x-calendar
    value="2026-08-09"
    invalid
    error-message="주말은 예약할 수 없습니다."
/>
```

## 월과 연도 선택

`show-month-and-year-pickers`를 사용하면 제목을 눌러 월과 연도를 빠르게 이동할 수 있습니다. 여러 달을 표시할 때는 자동으로 비활성화됩니다.

```blade preview name="calendar-month-year"
<x-calendar
    value="2026-08-05"
    show-month-and-year-pickers
/>
```

## 여러 달 표시

`visible-months`는 한 번에 1~3개월을 표시합니다. 좁은 화면에서는 Calendar 내부만 가로로 스크롤됩니다.

```blade preview name="calendar-visible-months"
<x-calendar
    value="2026-08-05"
    :visible-months="3"
    selection-alignment="center"
/>
```

## 주 시작 요일

기본값은 `locale`에 따라 결정됩니다. 직접 지정하려면 `sun`, `mon`, `tue`, `wed`, `thu`, `fri`, `sat` 중 하나를 사용합니다.

```blade preview name="calendar-week-start"
<x-calendar
    visible-month="2026-08-01"
    first-day-of-week="mon"
/>
```

## 페이지 이동 방식

여러 달을 표시할 때 기본 `visible`은 표시 중인 달 수만큼 이동합니다. `single`은 이전·다음 버튼을 누를 때 한 달씩 이동합니다.

```blade preview name="calendar-page-behavior"
<x-calendar
    visible-month="2026-08-01"
    :visible-months="2"
    page-behavior="single"
/>
```

## 프리셋

`presets`에 `true`를 지정하면 오늘, 다음 주, 다음 달을 바로 선택할 수 있습니다. 표시명과 날짜를 직접 구성하려면 `표시명 => 날짜 규칙` 배열을 전달합니다. 날짜는 `Y-m-d`, `today`, `tomorrow`, `nextWeek`, `nextMonth`, `+3 days`, `+2 weeks`, `+1 month` 형식을 지원합니다.

### 지원값

| 값 | 선택되는 날짜 | 예시 |
| --- | --- | --- |
| `Y-m-d` | 지정한 날짜 | `2026-08-25` |
| `today` | 오늘 | `오늘 => today` |
| `tomorrow` | 내일 | `내일 => tomorrow` |
| `nextWeek` | 오늘부터 7일 뒤 | `다음 주 => nextWeek` |
| `nextMonth` | 오늘부터 한 달 뒤 | `다음 달 => nextMonth` |
| `+N days` | 오늘부터 N일 뒤 | `사흘 뒤 => +3 days` |
| `+N weeks` | 오늘부터 N주 뒤 | `2주 뒤 => +2 weeks` |
| `+N months` | 오늘부터 N개월 뒤 | `석 달 뒤 => +3 months` |

프리셋 버튼은 날짜를 적용하는 실행 버튼입니다. 클릭 후 선택 테두리나 강조 색상이 남지 않으며, 선택된 날짜는 달력 셀에서 확인합니다.

```blade preview name="calendar-presets"
<x-calendar :presets="true" />

<x-calendar
    visible-month="2026-08-01"
    :presets="[
        '오늘' => 'today',
        '사흘 뒤' => '+3 days',
        '급여일' => '2026-08-25',
    ]"
/>

<x-calendar
    :presets="['오늘' => 'today', '다음 달' => '+1 month']"
    preset-position="bottom"
/>
```

## 위와 아래 콘텐츠

`topContent`, `bottomContent` named slot에는 안내 문구, 버튼, 필터처럼 필요한 콘텐츠를 자유롭게 배치할 수 있습니다. 위쪽은 달력 헤더 위, 아래쪽은 날짜 그리드 아래의 가로 스크롤 영역에 렌더링됩니다. 프리셋과 함께 사용할 수도 있습니다.

```blade preview name="calendar-content-slots"
<x-calendar visible-month="2026-08-01" :presets="['오늘' => 'today', '마감일' => '2026-08-25']">
    <x-slot:topContent>
        <strong>예약일 빠른 선택</strong>
    </x-slot:topContent>

    <x-slot:bottomContent>
        휴무일은 선택할 수 없습니다.
    </x-slot:bottomContent>
</x-calendar>
```

위쪽과 아래쪽 모두 콘텐츠 너비가 달력보다 길어지면 해당 영역만 가로로 스크롤됩니다. 달력 전체 너비나 날짜 그리드는 늘어나지 않습니다.

```blade preview name="calendar-preset-overflow"
<x-calendar
    :presets="[
        '오늘' => 'today',
        '내일' => 'tomorrow',
        '다음 주' => 'nextWeek',
        '다음 달' => 'nextMonth',
        '90일 뒤' => '+90 days',
    ]"
/>

<x-calendar
    preset-position="bottom"
    :presets="[
        '오늘 날짜' => 'today',
        '내일 날짜' => 'tomorrow',
        '일주일 뒤' => '+1 week',
        '한 달 뒤' => '+1 month',
        '분기 마감일' => '2026-09-30',
    ]"
/>
```

## 폼 전송

`name`을 지정하면 실제 hidden input이 생성됩니다. 날짜를 선택할 때 native `input`, `change` 이벤트도 함께 발생합니다.

```blade preview name="calendar-form"
<form method="post" class="jds-example-stack">
    <x-calendar name="scheduled_at" value="2026-08-05" />
    <x-button type="submit" size="sm">예약</x-button>
</form>
```

## 슬롯

스타일을 확장할 때 `base`, `top-content`, `top-content-inner`, `bottom-content`, `bottom-content-inner`, `preset-group`, `preset`, `content`, `prev-button`, `next-button`, `header-wrapper`, `header`, `title`, `grid-wrapper`, `grid`, `grid-header`, `grid-header-row`, `grid-header-cell`, `grid-body`, `grid-body-row`, `cell`, `cell-button`, `picker-wrapper`, `picker-month-list`, `picker-year-list`, `helper-wrapper`, `error-message`의 안정적인 `data-slot`을 사용할 수 있습니다.

## 이벤트와 Controller

선택이 바뀌면 `app-ui:calendar:change`, 포커스 날짜가 바뀌면 `app-ui:calendar:focus-change`, 페이지가 바뀌면 `app-ui:calendar:page-change`가 발생합니다.

```js
const calendar = document.querySelector('#booking-calendar')
const controller = AppUI.get(calendar)

controller.setValue('2026-08-12', true)
controller.next()
controller.previous()
controller.focus()
```

Controller는 `getValue()`, `setValue()`, `next()`, `previous()`, `focus()`, `destroy()`를 제공합니다.

## 접근성

Calendar는 날짜 그리드와 실제 버튼을 렌더링합니다. 방향키는 하루 또는 한 주, Home/End는 주의 처음과 끝, Page Up/Page Down은 이전·다음 달로 이동합니다. 선택할 수 없는 날짜도 탐색할 수 있지만 실행되지 않으며, 비활성 날짜는 포커스 순서에서 제외됩니다.
