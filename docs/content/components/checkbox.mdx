## 기본 사용법

라벨을 눌러도 선택 상태가 바뀌며 폼 제출 시 지정한 값이 전달됩니다.

```blade preview name="checkbox-default"
<x-checkbox name="terms" value="1" label="이용약관에 동의합니다" checked />
```

## 상태

선택, 일부 선택, 비활성 상태를 비교합니다.

```blade preview name="checkbox-states"
<x-checkbox checked aria-label="선택됨" />
<x-checkbox indeterminate aria-label="일부 선택" />
<x-checkbox disabled aria-label="비활성" />
```

## 브라우저 기본 형태

JavaScript 없이 네이티브 체크박스로 사용합니다.

```blade preview name="checkbox-native"
<x-checkbox name="agree" value="yes" native />
```

## 권한 선택

실제 폼에서는 관련 권한을 세로 목록으로 묶어 사용합니다.

```blade preview name="checkbox-permissions"
<div class="jds-example-surface">
    <strong>직원 권한</strong>
    <x-checkbox name="permissions[]" value="orders" label="주문 관리" checked />
    <x-checkbox name="permissions[]" value="settlement" label="정산 조회" />
    <x-checkbox name="permissions[]" value="members" label="회원 관리" disabled />
</div>
```

## 박스형 선택

`variant="box"`를 사용하면 항목 전체가 선택 영역이 됩니다. 체크 표시를 숨겨 카드의 배경과 테두리만으로 상태를 표현하려면 `:show-indicator="false"`를 사용합니다.

```blade preview name="checkbox-box"
<x-checkbox-group
    variant="box"
    orientation="horizontal"
>
    <x-checkbox name="channels[]" value="email" label="이메일" description="중요 알림을 이메일로 받습니다." checked />
    <x-checkbox name="channels[]" value="sms" label="문자" description="긴급 알림을 문자로 받습니다." />
</x-checkbox-group>

<x-checkbox-group
    variant="box"
    :show-indicator="false"
>
    <x-checkbox name="reports[]" value="daily" label="일간 보고서" />
    <x-checkbox name="reports[]" value="weekly" label="주간 보고서" />
</x-checkbox-group>
```

그룹은 배치와 공통 상태만 담당합니다. 각 항목의 이름, 값, 라벨, 설명은 `x-checkbox`에 직접 작성하므로 필요한 항목을 자유롭게 구성할 수 있습니다.

```blade
<x-checkbox-group variant="box" orientation="horizontal">
    <x-checkbox name="roles[]" value="admin" label="관리자" />
    <x-checkbox name="roles[]" value="viewer" label="조회자" />
</x-checkbox-group>
```
