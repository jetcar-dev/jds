## 사용법

Date Input은 연도, 월, 일을 각각 편집할 수 있는 세그먼트로 표시합니다. `value`는 `Y-m-d` 형식을 사용하며 `name`을 지정하면 같은 값을 일반 폼으로 전송합니다.

```blade preview name="date-input-basic"
<x-date-input name="birth_date" label="생년월일" />
```

## 로케일과 구분자

날짜 순서와 구분자는 `locale`에 맞춰 브라우저가 생성합니다. 한국어는 `연도. 월. 일.`, 영어는 `월/일/연도` 순서이며 날짜와 시간 사이의 문자도 locale을 따릅니다.

```blade preview name="date-input-locales"
<x-date-input locale="ko-KR" label="한국어" value="2026-08-05" />
<x-date-input locale="en-US" label="English" value="2026-08-05" />
```

## 비활성화

`disabled`는 포커스와 폼 전송을 모두 막고 전체 컴포넌트를 흐리게 표시합니다.

```blade preview name="date-input-disabled"
<x-date-input label="생년월일" value="2026-08-05" disabled />
```

## 읽기 전용

`read-only`는 값을 그대로 보여주지만 세그먼트를 수정할 수 없습니다. 비활성 상태와 달리 일반 색상과 폼 값은 유지됩니다.

```blade preview name="date-input-readonly"
<x-date-input name="confirmed_at" label="확정일" value="2026-08-05" read-only />
```

## 필수 입력

`required`를 사용하면 라벨 옆에 필수 표시가 나타나고 각 세그먼트에 필수 입력 상태가 전달됩니다.

```blade preview name="date-input-required"
<x-date-input name="contract_date" label="계약일" value="2026-08-05" required />
```

## 형태

HeroUI와 같은 `flat`, `bordered`, `underlined`, `faded` 형태를 지원합니다. 기본값은 `flat`입니다.

```blade preview name="date-input-variants"
<x-date-input variant="flat" label="Flat" />
<x-date-input variant="bordered" label="Bordered" />
<x-date-input variant="underlined" label="Underlined" />
<x-date-input variant="faded" label="Faded" />
```

## 라벨 위치

`label-placement`는 `inside`, `outside`, `outside-left`, `outside-top`을 지원합니다. 라벨이 있으면 기본값은 `inside`입니다.

```blade preview name="date-input-label-placements"
<x-date-input label="생년월일" label-placement="inside" description="inside" />
<x-date-input label="생년월일" label-placement="outside" description="outside" />
<x-date-input label="생년월일" label-placement="outside-left" description="outside-left" />
<x-date-input label="생년월일" label-placement="outside-top" description="outside-top" />
```

## 시작과 끝 콘텐츠

`startContent`, `endContent` named slot으로 아이콘이나 단위를 입력 영역 양쪽에 배치합니다. 콘텐츠 크기는 Date Input의 글자 크기를 따릅니다.

```blade preview name="date-input-content"
<x-date-input label="정비 예정일" value="2026-08-05" label-placement="outside">
    <x-slot:startContent>
        <x-icon name="solar:calendar-linear" />
    </x-slot:startContent>
</x-date-input>

<x-date-input label="기준일" value="2026-08-05" label-placement="outside">
    <x-slot:endContent>
        <x-icon name="solar:calendar-linear" />
    </x-slot:endContent>
</x-date-input>
```

## 설명

`description`은 입력 아래에 보조 설명을 표시합니다.

```blade preview name="date-input-description"
<x-date-input
    label="생년월일"
    description="본인 확인에 사용할 날짜를 입력하세요."
/>
```

## 오류 메시지

`invalid`와 `error-message`를 함께 사용하면 라벨, 날짜 세그먼트, 배경과 오류 문구가 danger 상태로 바뀝니다. 실제로 존재하지 않는 날짜나 `min-value`, `max-value` 범위를 벗어난 완성값도 자동으로 invalid 처리됩니다.

```blade preview name="date-input-invalid"
<x-date-input
    label="생년월일"
    value="2026-08-05"
    invalid
    error-message="유효한 날짜를 입력해 주세요."
/>
```

## 크기

크기는 `sm`, `md`, `lg`를 지원합니다. 크기에 따라 입력 높이, 내부 라벨 패딩과 글자 크기가 함께 바뀝니다.

```blade preview name="date-input-sizes"
<x-date-input size="sm" label="Small" value="2026-08-05" />
<x-date-input size="md" label="Medium" value="2026-08-05" />
<x-date-input size="lg" label="Large" value="2026-08-05" />
```

## 모서리

`radius`는 크기와 별도로 `none`, `sm`, `md`, `lg`, `full`을 지정할 수 있습니다. 지정하지 않으면 현재 크기에 맞는 radius가 사용됩니다.

```blade preview name="date-input-radius"
<x-date-input radius="none" label="None" />
<x-date-input radius="sm" label="Small" />
<x-date-input radius="md" label="Medium" />
<x-date-input radius="lg" label="Large" />
<x-date-input radius="full" label="Full" />
```

## 색상

색상은 `default`, `primary`, `secondary`, `success`, `warning`, `danger`를 지원합니다. 색상은 hover와 focus 상태에도 이어집니다.

```blade preview name="date-input-colors"
<x-date-input color="default" label="Default" />
<x-date-input color="primary" label="Primary" />
<x-date-input color="secondary" label="Secondary" />
<x-date-input color="success" label="Success" />
<x-date-input color="warning" label="Warning" />
<x-date-input color="danger" label="Danger" />
```

## 최소 날짜와 최대 날짜

완성된 값이 `min-value`와 `max-value` 범위를 벗어나면 오류 상태가 됩니다.

```blade preview name="date-input-bounds"
<x-date-input
    label="운행일"
    value="2026-08-10"
    min-value="2026-08-10"
    max-value="2026-08-20"
    error-message="8월 10일부터 20일 사이로 입력하세요."
/>
```

## 플레이스홀더 날짜

`placeholder-value`를 지정하면 값은 비어 있는 상태를 유지하면서 날짜 형식의 안내 값을 보여줍니다. 사용자가 세그먼트를 입력하기 시작하면 해당 안내 값이 실제 값으로 교체됩니다.

```blade preview name="date-input-placeholder"
<x-date-input
    name="appointment_date"
    label="예약일"
    placeholder-value="2026-08-05"
/>
```

## 시간 세그먼트

`granularity`를 `hour`, `minute`, `second`로 지정하면 날짜 뒤에 해당 시간 단위까지 표시합니다. `hour-cycle`은 `12` 또는 `24`이며, `time-zone`을 지정하면 축약 시간대가 끝에 표시됩니다. 폼 값은 `Y-m-dTH:i[:s]` 형식입니다.

```blade preview name="date-input-granularity"
<x-date-input
    label="방문 일시"
    value="2026-08-05T15:45"
    granularity="minute"
    :hour-cycle="24"
/>

<x-date-input
    label="점검 일시"
    value="2026-08-05T09:30:22"
    granularity="second"
    :hour-cycle="12"
    time-zone="Asia/Seoul"
/>
```

## 날짜 지우기

`clearable`을 사용하면 끝에 지우기 버튼이 나타납니다. 값을 지우면 native 이벤트와 `app-ui:date-input:change`가 함께 발생합니다.

```blade preview name="date-input-clearable"
<x-date-input label="출고일" name="released_at" value="2026-08-05" clearable />
```

## 폼 전송

세그먼트를 모두 입력해 유효한 날짜가 완성되면 hidden input에 `Y-m-d` 값이 기록됩니다. 별도의 연결 코드는 필요하지 않습니다.

```blade preview name="date-input-form"
<form method="post" class="jds-example-stack">
    <x-date-input name="started_at" label="시작일" required />
    <x-button type="submit" size="sm">전송</x-button>
</form>
```

## 키보드 사용

- 숫자를 입력하면 현재 세그먼트가 바뀌고 값이 완성되면 다음 세그먼트로 이동합니다.
- `Arrow Up`, `Arrow Down`으로 값을 1씩 조정합니다.
- `Arrow Left`, `Arrow Right`로 이전·다음 세그먼트로 이동합니다.
- `Home`, `End`로 해당 세그먼트의 최소·최대값을 입력합니다.
- `Backspace`, `Delete`로 현재 세그먼트를 비웁니다.

## 이벤트와 Controller

값이 바뀌면 폼 input에서 native `input`, `change` 이벤트가 발생하고 루트에서 `app-ui:date-input:change`가 발생합니다. 포커스와 키보드 상태는 `app-ui:date-input:focus`, `app-ui:date-input:blur`, `app-ui:date-input:focus-change`, `app-ui:date-input:key-down`, `app-ui:date-input:key-up`으로 확인할 수 있습니다.

```js
const dateInput = document.querySelector('#delivery-date')
const controller = AppUI.get(dateInput)

controller.setValue('2026-08-12', true)
controller.clear()
controller.focus()
```

Controller는 `getValue()`, `setValue(value, notify)`, `clear()`, `focus()`, `destroy()`를 제공합니다.

## API

| 속성 | 타입 | 기본값 |
| --- | --- | --- |
| `name` | string | `null` |
| `value`, `default-value` | `Y-m-d` 또는 날짜·시간 문자열 | 빈 값 |
| `placeholder-value` | `Y-m-d` 또는 날짜·시간 문자열 | `null` |
| `label` | string | `null` |
| `variant` | `flat` \| `bordered` \| `underlined` \| `faded` | `flat` |
| `color` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `default` |
| `size` | `sm` \| `md` \| `lg` | `md` |
| `radius` | `none` \| `sm` \| `md` \| `lg` \| `full` | 현재 `size` 기준 |
| `label-placement` | `inside` \| `outside` \| `outside-left` \| `outside-top` | 라벨이 있으면 `inside` |
| `granularity` | `day` \| `hour` \| `minute` \| `second` | `day` |
| `hour-cycle` | `12` \| `24` | locale 기준 |
| `time-zone` | IANA 시간대 문자열 | `null` |
| `min-value`, `max-value` | 날짜 또는 날짜·시간 문자열 | `null` |
| `disabled`, `read-only`, `required`, `invalid` | boolean | `false` |
| `clearable`, `auto-focus`, `disable-animation` | boolean | `false` |
| `should-force-leading-zeros` | boolean | `true` |

## 접근성

각 편집 단위는 `spinbutton` 역할과 최소·최대값을 제공하며 라벨, 설명, 오류 메시지를 함께 읽습니다. 포커스된 세그먼트만 강조하고 Date Input 전체에 별도의 파란 테두리를 추가하지 않습니다.
