## 기본 사용법

트리거에는 어떤 버튼도 넣을 수 있고 Content 안의 본문 구조도 자유롭게 구성합니다.

```blade preview name="modal-default"
<x-modal backdrop-variant="blur">
    <x-modal-trigger>
        <x-button variant="bordered">회원 추가</x-button>
    </x-modal-trigger>
    <x-modal-content>
        <x-modal-header>
            <x-modal-title>회원 추가</x-modal-title>
            <x-modal-description>새 회원 정보를 입력하세요.</x-modal-description>
        </x-modal-header>
        <x-modal-body>
            <x-input name="name" placeholder="회원명" full-width />
        </x-modal-body>
        <x-modal-footer>
            <x-button variant="bordered" data-modal-close>취소</x-button>
            <x-button type="submit">저장</x-button>
        </x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 닫기 동작

배경 클릭과 Escape 키의 닫기 동작을 각각 제어합니다.

```blade preview name="modal-dismiss"
<x-modal :is-dismissable="false" is-keyboard-dismiss-disabled>
    <x-modal-trigger><x-button>중요 작업</x-button></x-modal-trigger>
    <x-modal-content>
        <x-modal-header><x-modal-title>삭제 확인</x-modal-title></x-modal-header>
        <x-modal-body>명시적인 버튼으로만 닫을 수 있습니다.</x-modal-body>
        <x-modal-footer><x-button data-modal-close>확인</x-button></x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 여러 버튼으로 같은 모달 열기

Modal에 id를 지정하고 각 Trigger의 for에 같은 값을 전달하면 화면의 서로 다른 위치에 있는 버튼들이 하나의 모달을 열 수 있습니다.

```blade preview name="modal-multiple-triggers"
<div class="jds-example-row">
    <x-modal-trigger for="member-modal">
        <x-button>회원 추가</x-button>
    </x-modal-trigger>

    <x-modal-trigger for="member-modal">
        <x-button variant="bordered">담당자 선택</x-button>
    </x-modal-trigger>
</div>

<x-modal id="member-modal" backdrop-variant="blur">
    <x-modal-content>
        <x-modal-header>
            <x-modal-title>회원 선택</x-modal-title>
            <x-modal-description>어느 버튼에서 열어도 같은 모달을 사용합니다.</x-modal-description>
        </x-modal-header>
        <x-modal-body>
            <x-input name="member" placeholder="회원명" full-width />
        </x-modal-body>
        <x-modal-footer>
            <x-button variant="bordered" data-modal-close>취소</x-button>
            <x-button>선택</x-button>
        </x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 전체 화면과 위치

Content에서 전체 화면이나 표시 위치를 지정합니다.

```blade preview name="modal-advanced"
<x-modal :is-dismissable="false">
    <x-modal-trigger><x-button>열기</x-button></x-modal-trigger>
    <x-modal-content fullscreen>
        <x-modal-header><x-modal-title>전체 화면</x-modal-title></x-modal-header>
        <x-modal-body>원하는 복합 레이아웃</x-modal-body>
    </x-modal-content>
</x-modal>
```

## 긴 본문 스크롤

`scroll="inside"`는 헤더와 푸터를 유지한 채 본문만 스크롤합니다. `scroll="outside"`는 모달 전체를 하나의 영역으로 스크롤합니다. 기본값은 `inside`입니다.

```blade preview name="modal-scroll"
<x-modal scroll="inside" backdrop-variant="blur">
    <x-modal-trigger><x-button variant="bordered">긴 약관 보기</x-button></x-modal-trigger>
    <x-modal-content>
        <x-modal-header>
            <x-modal-title>서비스 이용 약관</x-modal-title>
            <x-modal-description>본문만 스크롤되는 예제입니다.</x-modal-description>
        </x-modal-header>
        <x-modal-body>
            @foreach(range(1, 12) as $section)
                <p><strong>{{ $section }}조</strong> 약관의 상세 내용을 확인해 주세요. 필요한 설명과 안내 문구가 이 영역에 표시됩니다.</p>
            @endforeach
        </x-modal-body>
        <x-modal-footer>
            <x-button variant="bordered" data-modal-close>닫기</x-button>
            <x-button>동의</x-button>
        </x-modal-footer>
    </x-modal-content>
</x-modal>
```

```blade preview name="modal-scroll-outside"
<x-modal scroll="outside" backdrop-variant="blur">
    <x-modal-trigger><x-button variant="bordered">전체 스크롤 보기</x-button></x-modal-trigger>
    <x-modal-content>
        <x-modal-header>
            <x-modal-title>개인정보 처리방침</x-modal-title>
            <x-modal-description>모달 전체가 스크롤되는 예제입니다.</x-modal-description>
        </x-modal-header>
        <x-modal-body>
            <p><strong>1항</strong> 수집하는 개인정보 항목을 확인해 주세요.</p>
            <p><strong>2항</strong> 개인정보의 수집 목적을 확인해 주세요.</p>
            <p><strong>3항</strong> 개인정보의 이용 범위를 확인해 주세요.</p>
            <p><strong>4항</strong> 개인정보의 보관 기간을 확인해 주세요.</p>
            <p><strong>5항</strong> 개인정보의 파기 절차를 확인해 주세요.</p>
            <p><strong>6항</strong> 개인정보 처리 위탁 내용을 확인해 주세요.</p>
            <p><strong>7항</strong> 제삼자 제공 기준을 확인해 주세요.</p>
            <p><strong>8항</strong> 정보 주체의 권리를 확인해 주세요.</p>
            <p><strong>9항</strong> 권리 행사 방법을 확인해 주세요.</p>
            <p><strong>10항</strong> 안전성 확보 조치를 확인해 주세요.</p>
            <p><strong>11항</strong> 개인정보 보호 책임자를 확인해 주세요.</p>
            <p><strong>12항</strong> 처리방침 변경 안내를 확인해 주세요.</p>
        </x-modal-body>
        <x-modal-footer>
            <x-button data-modal-close>확인</x-button>
        </x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 위험 작업 확인

삭제처럼 되돌릴 수 없는 작업은 위험 설명과 명확한 취소·실행 버튼을 함께 제공합니다.

```blade preview name="modal-danger-confirmation"
<x-modal backdrop-variant="opaque">
    <x-modal-trigger><x-button color="danger" variant="faded">차량 삭제</x-button></x-modal-trigger>
    <x-modal-content>
        <x-modal-header>
            <x-modal-title>차량을 삭제할까요?</x-modal-title>
            <x-modal-description>12가 3456의 운행 기록 연결이 해제됩니다. 이 작업은 되돌릴 수 없습니다.</x-modal-description>
        </x-modal-header>
        <x-modal-footer>
            <x-button variant="ghost" data-modal-close>취소</x-button>
            <x-button color="danger">삭제</x-button>
        </x-modal-footer>
    </x-modal-content>
</x-modal>
```
