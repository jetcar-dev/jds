## 기본 사용법

증감 버튼과 검증을 포함한 숫자를 입력받습니다.

```blade preview name="number-input-basic"
<x-number-input name="quantity" label="수량" value="1" min="1" max="10" />
```

## 형태와 색상

컴포넌트가 제공하는 `variant`와 의미 색상은 용도에 맞게 조합합니다. 지원 값과 기본값은 아래 API 표에서 확인할 수 있습니다.

```blade preview name="number-input-appearance"
<x-number-input variant="flat" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input variant="bordered" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input variant="faded" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input variant="underlined" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input color="default" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input color="primary" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input color="secondary" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input color="success" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input color="warning" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input color="danger" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input size="sm" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input size="md" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input size="lg" name="quantity" label="수량" value="1" min="1" max="10" />
```

## 크기와 상태

`sm`, `md`, `lg` 크기와 disabled, invalid, selected, loading 상태는 컴포넌트 성격에 맞게 사용합니다. 상태는 루트의 안정적인 `data-*` 속성에도 반영됩니다.

```blade preview name="number-input-states"
<x-number-input invalid error-message="입력값을 확인하세요" name="quantity" label="수량" value="1" min="1" max="10" />
<x-number-input disabled name="quantity" label="수량" value="1" min="1" max="10" />
```

## 폼 전송

입력 컴포넌트는 실제 input 또는 hidden input을 렌더링합니다. 표시 전용 컴포넌트는 폼 안에서도 값 전송에 관여하지 않습니다.

```blade preview name="number-input-form"
<form method="post"><x-number-input name="quantity" label="수량" value="1" min="1" max="10" /><x-button type="submit" size="sm">전송</x-button></form>
```

## 슬롯

기본 슬롯과 컴포넌트별 named slot을 사용해 아이콘, 설명, 사용자 정의 콘텐츠를 배치합니다. 목록형 컴포넌트는 배열보다 명시적인 하위 컴포넌트를 기본으로 사용합니다.

## 이벤트와 Controller

값 변경 시 native `input/change`와 `app-ui:number-input:change` 이벤트가 발생합니다. `AppUI.get(element)`로 controller를 가져와 지원되는 `getValue`, `setValue`, `open`, `close`, `focus`, `destroy`를 호출할 수 있습니다.

## 접근성

접근 가능한 이름을 제공하고 키보드 탐색, focus-visible, reduced motion을 보존합니다. 아이콘만 있는 작업에는 반드시 `aria-label`을 지정합니다.
