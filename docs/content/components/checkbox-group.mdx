## 기본 사용법

`x-checkbox-group` 안에 `x-checkbox` 항목을 직접 넣습니다. 그룹에 `name`을 지정하면 각 Checkbox가 자동으로 같은 배열 이름을 사용합니다.

```blade preview name="checkbox-group-basic"
<x-checkbox-group
    name="cities"
    label="방문할 도시를 선택하세요"
    :default-value="['buenos-aires', 'london']"
>
    <x-checkbox value="buenos-aires">Buenos Aires</x-checkbox>
    <x-checkbox value="sydney">Sydney</x-checkbox>
    <x-checkbox value="san-francisco">San Francisco</x-checkbox>
    <x-checkbox value="london">London</x-checkbox>
    <x-checkbox value="tokyo">Tokyo</x-checkbox>
</x-checkbox-group>
```

## 비활성화

그룹에 `disabled`를 지정하면 모든 하위 Checkbox가 함께 비활성화됩니다. 개별 항목에만 `disabled`를 지정할 수도 있습니다.

```blade preview name="checkbox-group-disabled"
<x-checkbox-group label="방문할 도시를 선택하세요" disabled>
    <x-checkbox value="buenos-aires" checked>Buenos Aires</x-checkbox>
    <x-checkbox value="sydney">Sydney</x-checkbox>
    <x-checkbox value="san-francisco">San Francisco</x-checkbox>
    <x-checkbox value="london">London</x-checkbox>
    <x-checkbox value="tokyo">Tokyo</x-checkbox>
</x-checkbox-group>
```

## 가로 배치

`orientation="horizontal"`을 사용하면 항목이 가로로 배치되고 공간이 부족할 때 다음 줄로 넘어갑니다. 기본값은 `vertical`입니다.

```blade preview name="checkbox-group-horizontal"
<x-checkbox-group label="관심 분야" orientation="horizontal">
    <x-checkbox value="design">디자인</x-checkbox>
    <x-checkbox value="development">개발</x-checkbox>
    <x-checkbox value="planning">기획</x-checkbox>
    <x-checkbox value="marketing">마케팅</x-checkbox>
</x-checkbox-group>
```

## 크기와 모서리

그룹의 `size`와 `radius`는 하위 Checkbox 전체에 전달됩니다. 크기는 `sm`, `md`, `lg`, 모서리는 `none`, `sm`, `md`, `lg`, `full`을 지원합니다.

```blade preview name="checkbox-group-sizes"
<div style="display:flex;flex-wrap:wrap;gap:2rem">
    <x-checkbox-group size="sm" radius="sm" label="Small">
        <x-checkbox value="one">첫 번째</x-checkbox><x-checkbox value="two">두 번째</x-checkbox>
    </x-checkbox-group>
    <x-checkbox-group size="md" radius="md" label="Medium">
        <x-checkbox value="one">첫 번째</x-checkbox><x-checkbox value="two">두 번째</x-checkbox>

        <x-checkbox value="one">첫 번째</x-checkbox><x-checkbox value="two">두 번째</x-checkbox>
    </x-checkbox-group>
</div>
```

## 값 제어

`AppUI.get()`으로 현재 선택 배열을 읽고 `setValue()`로 변경할 수 있습니다. 변경 시 `app-ui:checkbox-group:change` 이벤트의 `detail.value`에 선택된 값 배열이 전달됩니다.

```blade preview name="checkbox-group-controlled"
<div style="display:grid;gap:1rem">
    <x-checkbox-group id="controlled-cities" label="방문할 도시를 선택하세요">
        <x-checkbox value="buenos-aires">Buenos Aires</x-checkbox>
        <x-checkbox value="sydney">Sydney</x-checkbox>
        <x-checkbox value="san-francisco">San Francisco</x-checkbox>
    </x-checkbox-group>
    <div style="display:flex;gap:.5rem">
        <x-button type="button" size="sm" onclick="AppUI.get(document.getElementById('controlled-cities')).setValue(['buenos-aires','sydney'])">도시 선택</x-button>
        <x-button type="button" size="sm" variant="light" onclick="AppUI.get(document.getElementById('controlled-cities')).setValue([])">초기화</x-button>
    </div>
</div>
```

## 오류 상태

`invalid`와 `error-message`로 그룹 전체의 오류 상태를 표시합니다. 설명은 `description`으로 제공합니다.

```blade preview name="checkbox-group-invalid"
<x-checkbox-group
    name="travel-cities"
    label="방문할 도시를 선택하세요"
    description="한 곳 이상 선택해 주세요."
    error-message="방문할 도시를 선택해야 합니다."
    invalid
>
    <x-checkbox value="buenos-aires">Buenos Aires</x-checkbox>
    <x-checkbox value="sydney">Sydney</x-checkbox>
    <x-checkbox value="san-francisco">San Francisco</x-checkbox>
    <x-checkbox value="london">London</x-checkbox>
    <x-checkbox value="tokyo">Tokyo</x-checkbox>
</x-checkbox-group>
```

## 폼과 유효성

`name`은 자동으로 `name[]` 형태로 각 native Checkbox에 연결됩니다. `required`는 그룹에서 한 항목 이상 선택하도록 검사하며, `readonly`는 현재 값을 유지한 채 변경만 막습니다.

```blade preview name="checkbox-group-form"
<form onsubmit="event.preventDefault()" style="display:grid;gap:1rem">
    <x-checkbox-group name="notifications" label="알림 수신 방법" required>
        <x-checkbox value="email">이메일</x-checkbox>
        <x-checkbox value="sms">문자 메시지</x-checkbox>
        <x-checkbox value="push">앱 푸시</x-checkbox>
    </x-checkbox-group>
    <x-button type="submit" size="sm">저장</x-button>
</form>
```

## 슬롯

- `base`: Checkbox Group의 루트 `fieldset`
- `label`: 그룹의 접근 가능한 이름인 `legend`
- `description`: 선택 방법을 안내하는 설명
- `wrapper`: 모든 하위 Checkbox를 감싸는 영역
- `error-message`: 오류 메시지

## 상태 속성

루트에는 `data-orientation`, `data-color`, `data-size`, `data-radius`, `data-selected`, `data-value`, `data-required`, `data-readonly`, `data-disabled`, `data-invalid`가 반영됩니다.

## 이벤트와 Controller

하위 항목은 실제 Checkbox이므로 native `input`, `change` 이벤트가 발생합니다. 그룹 값이 바뀌면 `app-ui:checkbox-group:change`도 발생합니다.

```js
const group = document.querySelector('[data-ui-component="checkbox-group"]');
const controller = AppUI.get(group);

controller.getValue();
controller.setValue(['email', 'push']);
controller.focus();
```

## 접근성

그룹은 native `fieldset`과 `legend`를 사용합니다. 각 항목은 실제 Checkbox input이므로 `Tab`으로 이동하고 `Space`로 선택할 수 있습니다. 그룹의 `disabled`, `readonly`, `required`, `invalid` 상태는 하위 입력과 ARIA 상태에 함께 반영됩니다.
