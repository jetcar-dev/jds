## 사용법

Link는 실제 `<a>` 요소를 렌더링합니다. `href`와 기본 슬롯만 지정하면 됩니다.

```blade preview name="link-basic"
<x-link href="/components/button">Button 문서 보기</x-link>
```

## 비활성 상태

`disabled`를 지정하면 링크 이동과 포인터·키보드 입력을 막고 `aria-disabled="true"`를 제공합니다.

```blade preview name="link-disabled"
<x-link href="/components/button" disabled>사용할 수 없는 링크</x-link>
```

## 크기

`size`는 `sm`, `md`, `lg`를 지원하며 기본값은 `md`입니다.

```blade preview name="link-sizes"
<div class="jds-example-row">
    <x-link size="sm" href="#">Small</x-link>
    <x-link size="md" href="#">Medium</x-link>
    <x-link size="lg" href="#">Large</x-link>
</div>
```

## 색상

`foreground`, `primary`, `secondary`, `success`, `warning`, `danger` 중에서 의미에 맞는 색상을 선택합니다.

```blade preview name="link-colors"
<div class="jds-example-row">
    <x-link color="foreground" href="#">Foreground</x-link>
    <x-link color="primary" href="#">Primary</x-link>
    <x-link color="secondary" href="#">Secondary</x-link>
    <x-link color="success" href="#">Success</x-link>
    <x-link color="warning" href="#">Warning</x-link>
    <x-link color="danger" href="#">Danger</x-link>
</div>
```

## 밑줄

`underline`은 `none`, `hover`, `always`, `active`, `focus`를 지원합니다. HeroUI v2와 동일하게 기본값은 `none`입니다.

```blade preview name="link-underlines"
<div class="jds-example-row">
    <x-link underline="none" href="#">None</x-link>
    <x-link underline="hover" href="#">Hover</x-link>
    <x-link underline="always" href="#">Always</x-link>
    <x-link underline="active" href="#">Active</x-link>
    <x-link underline="focus" href="#">Focus</x-link>
</div>
```

## 외부 링크

`external`은 새 탭으로 안전하게 열도록 `target="_blank"`와 `rel="noopener noreferrer"`를 추가합니다. 아이콘은 자동으로 붙지 않으며 `show-anchor-icon`을 함께 지정할 때 표시됩니다.

```blade preview name="link-external"
<div class="jds-example-row">
    <x-link href="https://v2.heroui.com" external>HeroUI</x-link>
    <x-link href="https://v2.heroui.com" external show-anchor-icon>HeroUI 문서</x-link>
</div>
```

## 사용자 정의 이동 아이콘

`anchorIcon` slot으로 기본 이동 아이콘을 원하는 아이콘으로 교체할 수 있습니다.

```blade preview name="link-custom-icon"
<x-link href="/components/button">
    Button 문서
    <x-slot:anchorIcon><x-icon name="solar:arrow-right-linear" /></x-slot:anchorIcon>
</x-link>
```

## 블록 링크

`block`은 링크에 안쪽 여백과 색상별 hover 배경을 추가합니다. 문장 안의 링크가 아니라 독립적인 탐색 항목에 사용합니다.

```blade preview name="link-block"
<div class="jds-example-row">
    <x-link block show-anchor-icon color="foreground" href="#">Foreground</x-link>
    <x-link block show-anchor-icon color="primary" href="#">Primary</x-link>
    <x-link block show-anchor-icon color="secondary" href="#">Secondary</x-link>
    <x-link block show-anchor-icon color="success" href="#">Success</x-link>
    <x-link block show-anchor-icon color="warning" href="#">Warning</x-link>
    <x-link block show-anchor-icon color="danger" href="#">Danger</x-link>
</div>
```

## HTML 속성

`download`, `target`, `rel`, `referrerpolicy` 같은 일반 `<a>` 속성도 그대로 전달할 수 있습니다.

```blade preview name="link-html-attributes"
<x-link href="/files/manual.pdf" download="JDS-manual.pdf" show-anchor-icon>
    사용 설명서 다운로드
</x-link>
```

## 슬롯

- `base`: 링크 루트
- `anchor-icon`: 기본 또는 사용자 정의 이동 아이콘

## 상태와 이벤트

루트에는 `data-hover`, `data-focus`, `data-focus-visible`, `data-pressed`, `data-disabled` 상태가 반영됩니다. 링크는 브라우저의 native `click` 이벤트를 사용하며 `AppUI.get(link).focus()`로 포커스를 이동할 수 있습니다.

## 접근성

실제 `<a>` 요소를 사용하므로 Enter 키로 실행할 수 있습니다. 키보드 포커스에는 focus-visible 링만 표시하며 비활성 링크는 탭 순서에서 제외됩니다.
