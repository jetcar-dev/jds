## 사용법

기본 라벨 위치는 `inside`이며, 입력 내용에 맞춰 높이가 자동으로 늘어납니다.

```blade preview name="textarea-basic"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea label="설명" placeholder="설명을 입력하세요" />
</div>
```

## 비활성화

`disabled`를 지정하면 입력과 포커스를 모두 막습니다.

```blade preview name="textarea-disabled"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea
        disabled
        label="설명"
        label-placement="outside"
        placeholder="설명을 입력하세요"
        value="현재 수정할 수 없는 내용입니다."
    />
</div>
```

## 읽기 전용

`read-only`는 내용을 선택하거나 복사할 수 있지만 수정은 허용하지 않습니다.

```blade preview name="textarea-readonly"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea
        read-only
        variant="bordered"
        label="설명"
        label-placement="outside"
        placeholder="설명을 입력하세요"
        value="읽기 전용으로 제공되는 내용입니다."
    />
</div>
```

## 필수 입력

`required`를 사용하면 라벨 뒤에 danger 색상의 별표가 표시되고 실제 폼 검증에도 반영됩니다.

```blade preview name="textarea-required"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea required name="summary" label="설명" label-placement="outside" placeholder="설명을 입력하세요" />
</div>
```

## 지우기 버튼

`clearable`을 지정하면 값이 있을 때 우측 상단에 지우기 버튼이 나타납니다. 버튼을 누르면 포커스를 유지한 채 값을 비웁니다.

```blade preview name="textarea-clearable"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea
        clearable
        variant="bordered"
        label="설명"
        placeholder="설명"
        value="버튼을 눌러 이 내용을 지울 수 있습니다."
    />
</div>
```

## 자동 높이

기본적으로 내용에 맞춰 높이가 변합니다. `min-rows`와 `max-rows`로 자동 확장 범위를 제한합니다.

```blade preview name="textarea-autosize"
<div style="display:grid;width:100%;grid-template-columns:repeat(auto-fit,minmax(12rem,1fr));gap:1rem">
    <x-textarea label="기본" placeholder="기본 3줄" />
    <x-textarea min-rows="2" label="최소 2줄" placeholder="내용을 입력하세요" />
    <x-textarea min-rows="2" max-rows="3" label="최대 3줄" placeholder="세 줄 이후에는 내부가 스크롤됩니다" />
</div>
```

## 자동 높이 끄기

`disable-autosize`를 지정하면 자동 높이를 끄고 브라우저의 세로 크기 조절 손잡이를 사용합니다.

```blade preview name="textarea-disable-autosize"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea disable-autosize min-rows="2" variant="bordered" label="설명" placeholder="직접 높이를 조절하세요" />
</div>
```

## 형태

HeroUI v2와 같은 `flat`, `bordered`, `faded`, `underlined` 형태를 제공합니다.

```blade preview name="textarea-variants"
<div style="display:grid;width:100%;grid-template-columns:repeat(auto-fit,minmax(15rem,1fr));gap:1rem">
    <x-textarea variant="flat" label="Flat" placeholder="설명을 입력하세요" />
    <x-textarea variant="bordered" label="Bordered" placeholder="설명을 입력하세요" />
    <x-textarea variant="faded" label="Faded" placeholder="설명을 입력하세요" />
    <x-textarea variant="underlined" label="Underlined" placeholder="설명을 입력하세요" />
</div>
```

## 색상

`color`는 형태의 배경, 테두리, 라벨과 포커스 상태에 함께 적용됩니다.

```blade preview name="textarea-colors"
<div style="display:grid;width:100%;grid-template-columns:repeat(auto-fit,minmax(12rem,1fr));gap:1rem">
    <x-textarea color="default" label="Default" placeholder="내용 입력" />
    <x-textarea color="primary" label="Primary" placeholder="내용 입력" />
    <x-textarea color="secondary" label="Secondary" placeholder="내용 입력" />
    <x-textarea color="success" label="Success" placeholder="내용 입력" />
    <x-textarea color="warning" label="Warning" placeholder="내용 입력" />
    <x-textarea color="danger" label="Danger" placeholder="내용 입력" />
</div>
```

## 오류 메시지

`invalid`와 `error-message`를 함께 사용하면 오류 색상과 접근성 속성이 적용됩니다.

```blade preview name="textarea-invalid"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea
        invalid
        label="설명"
        value="내용이 너무 짧습니다."
        error-message="설명은 30자 이상 입력해 주세요."
    />
</div>
```

## 도움말

`description`은 입력 조건처럼 사용자가 미리 알아야 할 내용을 표시합니다.

```blade preview name="textarea-description"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea label="설명" placeholder="설명을 입력하세요" description="업무 내용을 간결하게 작성해 주세요." />
</div>
```

## 라벨 위치

`label-placement`는 `inside`, `outside`, `outside-left`를 지원합니다.

```blade preview name="textarea-label-placement"
<div class="jds-example-stack" style="width:min(100%,28rem)">
    <x-textarea label-placement="inside" label="내부 라벨" placeholder="내용 입력" />
    <x-textarea label-placement="outside" label="상단 라벨" placeholder="내용 입력" />
    <x-textarea label-placement="outside-left" label="왼쪽 라벨" placeholder="내용 입력" />
</div>
```

## 시작과 끝 콘텐츠

`startContent`, `endContent` named slot으로 아이콘이나 단위를 입력 영역 양쪽에 배치합니다.

```blade preview name="textarea-content"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea label="메모" placeholder="내용을 입력하세요">
        <x-slot:startContent><x-icon name="solar:pen-bold" /></x-slot:startContent>
        <x-slot:endContent><span>500자</span></x-slot:endContent>
    </x-textarea>
</div>
```

## 폼 전송과 Controller

실제 `<textarea>`를 렌더링하므로 별도 연결 없이 폼으로 제출됩니다. 값 변경 시 native `input/change`와 `app-ui:textarea:change` 이벤트가 발생합니다.

```blade preview name="textarea-form"
<form method="post" class="jds-example-stack" style="width:min(100%,20rem)">
    <x-textarea required name="memo" label="메모" placeholder="내용을 입력하세요" />
    <x-button type="submit">저장</x-button>
</form>
```

```js
const textarea = document.querySelector('[data-ui-component="textarea"]');
const controller = AppUI.get(textarea);

controller.getValue();
controller.setValue('새로운 내용');
controller.focus();
controller.clear();
```

## 슬롯

- `base`: 전체 필드
- `label`: 라벨
- `input-wrapper`: 라벨과 입력 영역을 감싸는 컨테이너
- `inner-wrapper`: textarea와 시작·끝 콘텐츠 컨테이너
- `input`: 실제 `<textarea>`
- `start-content`, `end-content`: 사용자 정의 콘텐츠
- `clear-button`: 지우기 버튼
- `helper-wrapper`: 도움말 또는 오류 메시지 컨테이너
- `description`: 도움말
- `error-message`: 오류 메시지

## 접근성

라벨과 도움말, 오류 메시지를 실제 textarea에 연결합니다. `required`, `disabled`, `read-only`, `invalid` 상태는 native 속성과 ARIA 속성에 함께 반영됩니다.
