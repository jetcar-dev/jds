title: 컴포넌트
icon: Box
description: JDS v3 컴포넌트 레퍼런스
---

[Button](/docs/components/button)으로 저장, 삭제, 양식 제출 같은 동작을 실행합니다.

[Card](/docs/components/card)로 관련 내용과 동작을 한 영역에 묶습니다.

[Checkbox](/docs/components/checkbox)로 항목을 선택하거나 선택을 해제합니다.

[Input](/docs/components/input)으로 이름, 이메일, 숫자 같은 한 줄 값을 받습니다.

[Label](/docs/components/label)로 입력 필드에 이름을 붙입니다.

[Separator](/docs/components/separator)로 내용이나 항목 사이를 나눕니다.

[Surface](/docs/components/surface)로 영역의 배경과 글자색을 정합니다.

[TextArea](/docs/components/text-area)로 메모나 설명처럼 여러 줄의 텍스트를 받습니다.
