JDS v3는 Laravel 애플리케이션에서 공통 UI를 구성하기 위한 Blade 컴포넌트 라이브러리입니다. 현재 문서에서는 디자인 기준과 컴포넌트 레퍼런스의 구성을 확인할 수 있습니다.

## 설계 방향

- **공통 테마** — 색상과 상태를 의미 기반 토큰으로 표현하고, 라이트·다크 테마에서 같은 이름을 사용합니다.
- **Blade 구성** — 루트와 하위 요소를 필요한 순서로 조합하고, 슬롯으로 콘텐츠를 전달합니다.
- **상호작용** — 컴포넌트를 설계할 때 키보드 탐색, 포커스, 모션 감소 설정을 함께 고려합니다.

## 문서 둘러보기

- [디자인 원칙](/docs/getting-started/design-principles)에서 Blade 컴포넌트를 설계할 때 적용하는 기준을 확인할 수 있습니다.
- [디자인 시스템](/docs/design)에서 색상, 테마, 스타일링, 애니메이션과 구성 가이드를 확인할 수 있습니다.
- [컴포넌트](/docs/components)는 Blade 컴포넌트의 사용법과 API를 정리할 레퍼런스입니다.
