icon: Palette
description: CSS 변수와 BEM 클래스로 JDS의 색상과 컴포넌트 스타일을 조정하는 방법
---

JDS의 테마는 CSS 변수와 BEM 클래스로 색상부터 컴포넌트 스타일을 조정합니다. 이 문서는 Blade 레이아웃과 일반 CSS로 구성하는 테마 예제를 제공합니다.

## 동작 방식

기본 테마는 `:root`에 정의하고, `data-theme`으로 모드별 값을 지정합니다. Blade가 출력하는 BEM 클래스는 해당 영역의 CSS 변수를 참조합니다. 기본 스타일, 테마, 컴포넌트, 앱 재정의의 우선순위는 CSS 레이어로 정합니다.

- `--accent`, `--surface`처럼 접미사가 없는 색상 변수는 배경에 사용합니다.
- `--accent-foreground`, `--surface-foreground`처럼 `-foreground`로 끝나는 변수는 해당 배경 위의 텍스트와 아이콘에 사용합니다.
- `-hover`와 `-soft` 등 상태와 강조 강도는 테마의 기본 색상에서 파생할 수 있습니다.

## 빠른 시작

**테마 적용하기**

Blade 레이아웃의 `<html>`에 `data-theme`를 지정합니다. 다음은 서버에서 전달한 값이 `dark`인 경우 다크 테마를 적용하는 예입니다.

```blade
<!doctype html>
<html lang="ko" data-theme="{{ ($theme ?? 'light') === 'dark' ? 'dark' : 'light' }}">
    <body class="app-shell">
        {{ $slot }}
    </body>
</html>
```

```css
.app-shell {
  background-color: var(--background);
  color: var(--foreground);
}
```

**모드 전환하기**

```html
<!-- Light -->
<html lang="ko" data-theme="light">

<!-- Dark -->
<html lang="ko" data-theme="dark">
```

**브라우저에서 전환하기**

앱에서 제공하는 전환 버튼을 클릭하면 루트의 `data-theme`를 바꿀 수 있습니다. 서버에서 선택값을 관리한다면 다음 렌더링에도 같은 값이 전달되게 합니다.

```html
<button type="button" id="theme-toggle">Light / Dark 전환</button>
```

```js
const root = document.documentElement;

document.querySelector('#theme-toggle')?.addEventListener('click', () => {
  root.dataset.theme = root.dataset.theme === 'dark' ? 'light' : 'dark';
});
```

**색상 덮어쓰기**

기본 테마를 불러온 뒤 앱에서 필요한 색상을 지정합니다. 배경을 바꾸면 기존 전경색과의 대비를 확인합니다. 다른 토큰은 [색상](/docs/getting-started/colors)에서 확인할 수 있습니다.

```css
:root {
  --accent: oklch(0.7 0.25 260);
  --success: oklch(0.65 0.15 155);
}
```

**새 테마 불러오기**

```css
@layer base, theme, components, overrides;

@import "./themes/default.css" layer(theme);
@import "./themes/ocean.css" layer(theme);
```

**새 테마 적용하기**

```html
<!-- Ocean Light -->
<html lang="ko" data-theme="ocean">

<!-- Ocean Dark -->
<html lang="ko" data-theme="ocean-dark">
```

`color-scheme`에 따라 브라우저 기본 폼 컨트롤과 스크롤바도 각 모드에 맞게 표시됩니다.

## 컴포넌트 사용자 정의

여러 컴포넌트가 함께 쓰는 값은 테마 변수에서 바꾸고, 특정 컴포넌트만 바꿀 때는 BEM 클래스에 규칙을 추가합니다. 아래 클래스는 기본 블록, 변형, 하위 요소를 각각 수정하는 예입니다.

```css
@layer overrides {
  .jds-button {
    font-weight: 600;
  }

  .jds-button--primary {
    background-color: var(--accent);
    color: var(--accent-foreground);
  }

  .jds-button--primary:hover {
    background-color: var(--accent-hover);
  }

  .jds-accordion__trigger {
    font-size: 1.125rem;
    font-weight: 700;
  }
}
```

## CSS 불러오기

다음은 앱에서 CSS 파일을 구성하는 예시입니다. 상대 경로는 앱의 파일 위치에 맞춰 지정합니다.

**전체 불러오기**

모든 스타일을 묶은 진입 파일을 사용합니다.

```css
@import "./styles/index.css";
```

**선택 불러오기**

기본 스타일과 테마에 필요한 컴포넌트만 추가합니다. 앱에서 바꿀 규칙은 같은 순서로 선언된 `overrides` 레이어에 둡니다.

```css
/* app.css */
@layer base, theme, components, overrides;

@import "./base.css" layer(base);
@import "./themes/default.css" layer(theme);
@import "./components/button.css" layer(components);
@import "./components/accordion.css" layer(components);
```

**컴포넌트 스타일 직접 정의하기 (Headless)**

```css
@layer base, theme, components;

@import "./base.css" layer(base);
@import "./themes/default.css" layer(theme);

@layer components {
  .jds-button {
    border-radius: var(--radius);
    background-color: var(--default);
    color: var(--default-foreground);
  }
}
```

## 사용자 정의 색상 추가

새 색상 역할은 라이트·다크 각각에 배경과 전경을 함께 정의합니다. Blade에서 출력하는 클래스는 테마에 관계없이 동일합니다.

```css
:root,
[data-theme="light"] {
  --info: oklch(0.6 0.15 210);
  --info-foreground: oklch(0.98 0 0);
}

[data-theme="dark"] {
  --info: oklch(0.7 0.12 210);
  --info-foreground: oklch(0.15 0 0);
}

.notice--info {
  background-color: var(--info);
  color: var(--info-foreground);
}
```

```blade
<p class="notice--info">{{ $message }}</p>
```

## 변수 레퍼런스

| 구분 | 예시 | 역할 |
| --- | --- | --- |
| 기본 변수 | `--white`, `--black`, `--spacing`, `--radius` | 공통 색상과 스타일 단위 |
| 테마 변수 | `--background`, `--surface`, `--field-background`, `--scrollbar-thumb` | 모드별 배경, 컨테이너, 입력 필드, 스크롤바 |
| 파생 변수 | `--accent-hover`, `--accent-soft`, `--separator-secondary` | 기본 토큰을 조합해 만든 상태와 대비 단계 |

<details className="docs-code-details">
<summary>CSS 변수 연결 예제 보기</summary>

```css
[data-theme="light"] {
  --field-background: var(--white);
  --field-foreground: var(--foreground);
  --field-border: transparent;
  --field-hover: color-mix(in oklab, var(--field-background) 90%, var(--field-foreground));
  --field-focus: var(--field-background);
}

.jds-input {
  background-color: var(--field-background);
  color: var(--field-foreground);
  border-color: var(--field-border);
}

.jds-input:hover {
  background-color: var(--field-hover);
}

.jds-input:focus-visible {
  background-color: var(--field-focus);
  outline: 2px solid var(--focus);
}
```

</details>

입력 필드의 배경, 테두리, hover, focus를 조정할 때는 `--field-*` 변수를 사용합니다. 카드 같은 컨테이너는 `--surface`를 참조합니다. 토큰의 이름과 역할은 [색상](/docs/getting-started/colors)에 정리되어 있습니다.

## 스크롤바

테이블, 팝오버, 드로어의 스크롤 영역에 같은 스타일을 적용할 수 있습니다. `data-scrollbar`는 문서 루트, 컴포넌트 루트, 개별 스크롤 영역에 지정할 수 있습니다. CSS 변수를 상속받는 스크롤 영역에 해당 설정이 적용됩니다.

| 값 | 동작 |
| --- | --- |
| `thin` 또는 생략 | 테마 색을 사용하는 얇은 스크롤바 |
| `default` | 브라우저 기본 스크롤바 |
| `none` | 스크롤바를 숨기고 스크롤 동작은 유지 |

```html
<html data-scrollbar="default">
  <body>
    <main data-scrollbar="thin">
      <div class="scroll-area">...</div>
      <div class="scroll-area" data-scrollbar="none">...</div>
    </main>
  </body>
</html>
```

**테마 변수**

| 변수 | 역할과 기본값 |
| --- | --- |
| `--scrollbar-thumb` | 손잡이 색상. `--foreground`를 투명색에 15% 섞은 값 |
| `--scrollbar-track` | 트랙 색상. 기본값은 `transparent` |
| `--scrollbar-gutter` | 스크롤바 공간. 기본값은 `auto` |
| `--scrollbar-width` | 스크롤바 너비. 기본값은 `thin` |
| `--scrollbar-color` | 손잡이와 트랙 색상 쌍 |

**전역 설정과 개별 스크롤 영역**

`:root` 또는 각 테마에서 기본값을 정하고, 직접 만든 스크롤 영역에 `.scroll-area`를 적용합니다.

```css
:root {
  --scrollbar-thumb: color-mix(in oklch, var(--foreground) 15%, transparent);
  --scrollbar-track: transparent;
  --scrollbar-width: thin;
  --scrollbar-gutter: auto;
  --scrollbar-color: var(--scrollbar-thumb) var(--scrollbar-track);
}

.scroll-area {
  overflow: auto;
  scrollbar-width: var(--scrollbar-width);
  scrollbar-color: var(--scrollbar-color);
  scrollbar-gutter: var(--scrollbar-gutter);
}

[data-scrollbar="thin"] {
  --scrollbar-width: thin;
  --scrollbar-color: var(--scrollbar-thumb) var(--scrollbar-track);
  --scrollbar-gutter: auto;
}

[data-scrollbar="default"],
[data-scrollbar="none"] {
  --scrollbar-color: auto;
  --scrollbar-gutter: auto;
}

[data-scrollbar="default"] {
  --scrollbar-width: auto;
}

[data-scrollbar="none"] {
  --scrollbar-width: none;
}
```

`none`을 선택할 때는 키보드와 터치로 내용을 계속 탐색할 수 있는지 확인합니다. 레이아웃이 스크롤바 등장으로 흔들릴 때는 `--scrollbar-gutter: stable`을 적용할 수 있습니다.

## Vibrant Palette

기본 Soft 전경은 상태색과 기본 전경색을 섞어 대비를 높입니다. 문서 루트에 `data-vibrant-palette="true"`를 지정하면 아래 CSS가 Accent, Success, Warning, Danger의 Soft 전경에 상태색을 92%씩 적용합니다.

```html
<html lang="ko" data-vibrant-palette="true">
```

```css
[data-vibrant-palette="true"] {
  --accent-soft-foreground: color-mix(in oklab, var(--accent) 92%, var(--foreground));
  --success-soft-foreground: color-mix(in oklab, var(--success) 92%, var(--foreground));
  --warning-soft-foreground: color-mix(in oklab, var(--warning) 92%, var(--foreground));
  --danger-soft-foreground: color-mix(in oklab, var(--danger) 92%, var(--foreground));
}
```

| 모드 | Soft 전경을 만드는 방식 |
| --- | --- |
| 기본 | 테마와 상태색에 따라 혼합 비율을 조정해 대비 확보 |
| Vibrant | 상태색 92%와 기본 전경색 8%를 혼합 |

> Vibrant Palette는 색상을 더 선명하게 표현하는 만큼 일부 조합의 대비를 낮출 수 있습니다. 특히 밝은 Accent를 쓸 때는 라이트·다크 양쪽에서 Soft 배경과 텍스트의 대비를 확인합니다.
