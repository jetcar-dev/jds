컴포넌트는 루트와 하위 요소에 스타일과 동작을 연결해 구성합니다. JDS는 HeroUI v3의 BEM 구조와 상태 규칙을 따르고 공개 클래스에는 `jds-`를 붙입니다. 이 페이지의 앱 컴포넌트와 PHP 클래스는 사용 예제입니다.

## 프레임워크에 독립적인 스타일

같은 CSS를 로드하면 Blade가 출력한 마크업과 일반 HTML에서 동일한 BEM 클래스로 스타일을 적용할 수 있습니다. Button의 기본 변형은 `primary`, 기본 크기는 `md`입니다.

```html
<button type="button" class="jds-button jds-button--primary jds-button--md">
  저장
</button>
```

스타일을 공유할 때는 [테마](/docs/getting-started/theming)의 레이어 순서로 불러옵니다. 컴포넌트의 키보드 동작과 접근성은 HTML 요소와 필요한 브라우저 로직으로 연결합니다.

## 여러 요소에 스타일 적용하기

**링크에 버튼 스타일 적용하기**

페이지 이동에는 `href`가 있는 `a`를 사용하고, 폼 제출과 명령 실행에는 `button`을 사용합니다. 두 요소에 같은 버튼 클래스를 붙일 수 있습니다.

```blade
<a href="{{ url('/about') }}" class="jds-button jds-button--primary jds-button--md">
    소개
</a>

<a href="{{ $externalUrl }}" class="jds-button jds-button--secondary jds-button--lg">
    외부 링크
</a>
```

**루트와 하위 요소 직접 조합하기**

링크 루트를 앱에서 직접 렌더링하면 루트의 `.jds-link`와 아이콘 슬롯의 `.jds-link__icon`을 각각 붙입니다. 아래 `$externalLinkIcon`은 앱에서 준비한 Blade 슬롯입니다.

```blade
<a href="{{ $externalUrl }}" class="jds-link" data-slot="link">
    외부 문서
    <span class="jds-link__icon" data-slot="link-icon" aria-hidden="true">
        {{ $externalLinkIcon }}
    </span>
</a>
```

## BEM 클래스 직접 적용하기

하나의 스타일을 적용할 때는 필요한 클래스를 마크업에 직접 지정합니다. Button 클래스는 HeroUI v3의 변형, 크기, 옵션 이름에 `jds-`를 붙여 사용합니다.

```blade
<a href="{{ url('/') }}" class="jds-button jds-button--tertiary jds-button--md">
    홈으로
</a>

<button type="submit" class="jds-button jds-button--primary jds-button--md">
    저장
</button>
```

| 구분 | 클래스 |
| --- | --- |
| 기본 | `.jds-button` |
| 변형 | `.jds-button--primary`, `.jds-button--secondary`, `.jds-button--tertiary`, `.jds-button--danger`, `.jds-button--danger-soft`, `.jds-button--ghost`, `.jds-button--outline` |
| 크기 | `.jds-button--sm`, `.jds-button--md`, `.jds-button--lg` |
| 옵션 | `.jds-button--icon-only`, `.jds-button--full-width` |

## 변형 값으로 클래스 선택하기

변형과 크기를 여러 Blade 화면에서 전달받는다면 공개 BEM 이름으로 매핑하는 로직을 공유합니다. 아래는 앱에서 만드는 PHP 헬퍼 예제입니다. 기본 변형과 크기는 HeroUI v3 Button의 기본값을 따릅니다.

```php
<?php

namespace App\Support;

final class ButtonClasses
{
    public static function make(
        string $variant = 'primary',
        string $size = 'md',
        bool $iconOnly = false,
        bool $fullWidth = false,
    ): string {
        $variants = ['primary', 'secondary', 'tertiary', 'danger', 'danger-soft', 'ghost', 'outline'];
        $sizes = ['sm', 'md', 'lg'];

        $variant = in_array($variant, $variants, true) ? $variant : 'primary';
        $size = in_array($size, $sizes, true) ? $size : 'md';

        return implode(' ', array_filter([
            'jds-button',
            'jds-button--'.$variant,
            'jds-button--'.$size,
            $iconOnly ? 'jds-button--icon-only' : null,
            $fullWidth ? 'jds-button--full-width' : null,
        ]));
    }
}
```

```blade
<a href="{{ url('/dashboard') }}"
   class="{{ \App\Support\ButtonClasses::make(variant: 'primary', size: 'md') }}">
    대시보드
</a>
```

Link의 슬롯은 별도 변형 값 없이 루트의 `.jds-link`와 아이콘의 `.jds-link__icon`을 사용합니다.

## 복합 컴포넌트

HeroUI v3 Alert는 Root, Indicator, Content, Title, Description으로 구성됩니다. Title의 기본 HTML 요소는 `p`이고 Description은 `span`입니다. 앱에서는 이 구조를 익명 Blade 컴포넌트에 담고, 이름 있는 슬롯으로 일부를 교체할 수 있습니다.

```blade
{{-- resources/views/components/order-alert.blade.php --}}
<div {{ $attributes->class(['jds-alert', 'jds-alert--success']) }} data-slot="alert-root">
    @isset($indicator)
        <div class="jds-alert__indicator" data-slot="alert-indicator" aria-hidden="true">
            {{ $indicator }}
        </div>
    @endisset

    <div class="jds-alert__content" data-slot="alert-content">
        @isset($title)
            <p class="jds-alert__title" data-slot="alert-title">{{ $title }}</p>
        @endisset

        <span class="jds-alert__description" data-slot="alert-description">{{ $slot }}</span>
    </div>
</div>
```

```blade
<x-order-alert>
    <x-slot:indicator>{{ $successIcon }}</x-slot:indicator>
    <x-slot:title>저장 완료</x-slot:title>
    변경 사항이 저장되었습니다.
</x-order-alert>
```

앱에서 제목이나 표시 영역을 생략하면 예제는 해당 요소도 생략합니다. 루트는 출력을 담당하고, 전달한 속성은 루트 요소에 적용됩니다. JDS 패키지의 Blade 태그는 `x-jds::` 네임스페이스를 사용합니다. 아래는 Button의 태그 이름을 보여주는 예제입니다.

```blade
<x-jds::button>저장</x-jds::button>
```

## 여러 컴포넌트의 스타일 조합하기

링크의 아이콘 슬롯과 버튼의 기본 클래스·크기를 한 요소에서 조합할 수 있습니다. 루트에서 `.jds-link`와 `.jds-button`을 함께 적용하면 두 블록이 설정한 배경, 색상, 크기가 CSS 레이어와 선택자 우선순위에 따라 결정됩니다.

```blade
<a href="{{ $externalUrl }}"
   class="jds-link {{ \App\Support\ButtonClasses::make(variant: 'tertiary') }}"
   data-slot="link">
    외부 문서
    <span class="jds-link__icon" data-slot="link-icon" aria-hidden="true">
        {{ $externalLinkIcon }}
    </span>
</a>
```

## 앱 컴포넌트 만들기

**링크 버튼**

다음 앱 컴포넌트는 버튼 변형을 링크에 적용합니다. 호출자가 추가한 클래스·ID·ARIA 속성은 실제 링크에 전달됩니다.

```blade
{{-- resources/views/components/link-button.blade.php --}}
@props(['variant' => 'primary', 'size' => 'md'])

<a {{ $attributes->class(\App\Support\ButtonClasses::make($variant, $size)) }}>
    {{ $slot }}
</a>
```

```blade
<x-link-button href="{{ url('/dashboard') }}" variant="secondary" size="lg">
    대시보드
</x-link-button>
```

**툴팁이 있는 아이콘 버튼**

버튼의 접근성 이름은 `aria-label`로 제공합니다. 브라우저 컨트롤러가 hover와 키보드 포커스에 반응해 툴팁을 표시하고, 표시 중에는 트리거의 `aria-describedby`를 툴팁 ID에 연결합니다. Escape나 포커스 이동으로 닫히는 동작도 연결합니다. HeroUI v3 기본 테마의 포인터 지연은 `--tooltip-delay: 1500ms`와 `--tooltip-close-delay: 500ms`입니다.

```blade
<button type="button" aria-label="설정"
        class="jds-tooltip__trigger {{ \App\Support\ButtonClasses::make(iconOnly: true) }}"
        data-slot="tooltip-trigger" data-tooltip-id="{{ $tooltipId }}">
    <span aria-hidden="true">{{ $settingsIcon }}</span>
</button>

<div id="{{ $tooltipId }}" class="jds-tooltip" data-slot="tooltip-root" role="tooltip" hidden>
    설정
</div>
```

예시의 `data-tooltip-id`는 앱 컨트롤러에 연결할 식별자입니다. 반복 렌더링할 때 `$tooltipId`는 문서 안에서 고유한 값을 사용합니다.

## 사용자 정의 변형

앱 전용 변형은 v3 Button 클래스 위에 추가합니다. 아래 예제는 원본 가이드처럼 기본 반경을 `full`로 지정하고 `sm`, `md`, `lg`, `xl`에 앱 전용 크기와 여백을 적용합니다. 실제 Button의 기본 크기와 색상은 v3 스타일을 따릅니다.

```blade
<button type="button"
        class="jds-button jds-button--primary jds-button--md app-button app-button--radius-full app-button--size-md"
        aria-busy="{{ $pending ? 'true' : 'false' }}"
        @if($pending) data-pending="true" @endif>
    저장
</button>
```

```css
@layer overrides {
  .app-button {
    font-weight: 600;
    box-shadow: 0 4px 6px -1px rgb(0 0 0 / 10%), 0 2px 4px -2px rgb(0 0 0 / 10%);
    text-shadow: 0 1px 2px rgb(0 0 0 / 10%), 0 3px 2px rgb(0 0 0 / 10%), 0 4px 8px rgb(0 0 0 / 10%);
  }

  .app-button--radius-sm { border-radius: 0.25rem; }
  .app-button--radius-md { border-radius: 0.375rem; }
  .app-button--radius-lg { border-radius: 0.5rem; }
  .app-button--radius-full { border-radius: 9999px; }
  .app-button--size-sm { height: 2.5rem; padding-inline: 1rem; }
  .app-button--size-md { height: 2.75rem; padding-inline: 1.5rem; }
  .app-button--size-lg { height: 3rem; padding-inline: 2rem; }
  .app-button--size-xl { height: 3.25rem; padding-inline: 2.5rem; }

  .app-button[data-pending="true"] {
    opacity: 0.4;
  }

  .app-button.jds-button--primary {
    color: var(--white);
  }

  [data-theme="dark"] .app-button.jds-button--primary {
    --button-bg: color-mix(in oklab, var(--white) 10%, transparent);
    --button-bg-hover: color-mix(in oklab, var(--white) 15%, transparent);
  }
}
```

PHP 헬퍼나 Blade 속성에서 허용할 값과 기본값을 명시하면 앱 전용 변형이 기본 컴포넌트 전체로 퍼지는 것을 막을 수 있습니다. 예시의 `xl`은 앱에서 추가한 크기입니다.

## DOM 요소 직접 렌더링하기

루트 렌더링을 바꾸더라도 컴포넌트가 기대하는 HTML 요소, 단일 루트, 전달 속성을 유지합니다. 버튼에는 `button`, 이동 링크에는 `a`를 사용하고 `$attributes`를 실제 상호작용 요소에 합칩니다.

```blade
{{-- resources/views/components/press-preview.blade.php --}}
<button {{ $attributes
    ->class([\App\Support\ButtonClasses::make(), 'press-preview'])
    ->merge(['type' => 'button']) }}>
    {{ $slot }}
</button>
```

```css
@layer overrides {
  .press-preview:not(:disabled, [aria-disabled="true"]):is(:active, [data-pressed="true"]) {
    transform: scale(0.9);
  }
}
```

0.9배는 이 사용자 정의 예제의 값입니다. [기본 버튼 눌림과 모션 감소](/docs/getting-started/animation)는 애니메이션 문서에서 확인합니다.

## Laravel에서 사용하기

**이름 있는 라우트**

Laravel 라우트가 URL을 만들고 Blade가 실제 `href`를 렌더링합니다. 라우트 이름은 앱에 등록한 값을 사용합니다.

```blade
<x-link-button :href="route('dashboard')" variant="primary">
    대시보드
</x-link-button>
```

**일반 HTML이나 다른 템플릿과 공유하기**

같은 스타일시트를 사용하면 서버에서 어떤 템플릿으로 렌더링하더라도 같은 클래스가 적용됩니다.

```html
<a class="jds-button jds-button--primary jds-button--md" href="/dashboard">
  대시보드
</a>
```
