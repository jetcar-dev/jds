JDS는 색이 전달하는 역할에 따라 색상 토큰을 선택합니다. Blade 마크업은 같은 의미의 토큰을 사용하고, 테마에서 라이트·다크 모드의 값을 지정합니다. 호버나 옅은 배경은 기본색과 전경색을 기준으로 파생할 수 있습니다.

각 섹션의 견본에서 라이트·다크 모드의 색을 비교할 수 있습니다. 견본에 마우스를 올리거나 키보드로 포커스하면 토큰 이름과 값이 표시됩니다. 견본을 누르면 색상 값을 복사할 수 있습니다.

## Accent

`--accent`는 주요 동작, 선택 상태, 강조에 사용합니다. 예를 들어 주문 편집 화면의 `primary` 저장 버튼은 `--accent`를 배경으로, `--accent-foreground`를 텍스트와 아이콘에 사용합니다. 덜 강한 강조에는 `--accent-soft`와 `--accent-soft-foreground`를 사용하고, 호버는 해당 `-hover` 토큰을 적용합니다.

<ColorSectionSideBySide palette="accent" label="Accent" />

## Default (neutrals)

`--default`는 강조가 필요 없는 컨트롤에 사용합니다. 그 위의 글자와 아이콘에는 `--default-foreground`, 가리켰을 때는 `--default-hover`를 사용합니다.

<ColorSectionSideBySide palette="default" label="Default" />

## Success

`--success`는 저장 완료나 입력 검증 성공을 나타냅니다. 진한 배경에는 `--success-foreground`를, 알림이나 배지처럼 가볍게 표시할 때는 `--success-soft`와 `--success-soft-foreground`를 짝지어 사용합니다.

<ColorSectionSideBySide palette="success" label="Success" />

## Warning

`--warning`은 계약 만료 임박처럼 사용자가 확인해야 하는 상태에 사용합니다. `--warning-foreground`를 짝지어 사용하고, 옅은 배경에서는 `--warning-soft`와 `--warning-soft-foreground`를 사용합니다.

<ColorSectionSideBySide palette="warning" label="Warning" />

## Danger

`--danger`는 심각한 오류나 삭제처럼 되돌리기 어려운 동작에 사용합니다. `--danger-foreground`를 짝지어 사용하고, 옅은 오류 안내에는 `--danger-soft`와 `--danger-soft-foreground`를 사용합니다. 상태를 전달할 때는 색상과 함께 오류 메시지나 동작 이름을 표시합니다.

<ColorSectionSideBySide palette="danger" label="Danger" />

## Foreground

본문과 아이콘에는 `--foreground`, 부가 설명에는 `--muted`, 링크에는 `--link`를 사용합니다. 카드나 오버레이처럼 전용 배경을 가진 영역에서는 해당 `-foreground`를 사용해 배경과 콘텐츠의 대비를 함께 조정합니다.

<ColorSectionStacked palette="foreground" />

## Background

`--background`는 화면의 기본 바탕입니다. 영역을 층으로 구분할 때는 `--background-secondary`와 `--background-tertiary`, 기본 배경과 명암을 뒤집는 영역에는 `--background-inverse`를 사용합니다.

<ColorSectionStacked palette="background" />

## Surface

카드와 패널에는 `--surface`와 `--surface-foreground`를 사용합니다. 표면 안에서 영역을 한 단계 더 구분할 때는 `--surface-secondary`와 `--surface-tertiary`를 사용합니다. 메뉴나 대화상자처럼 위에 떠 있는 요소에는 `--overlay`와 `--overlay-foreground`를 사용합니다.

<ColorSectionStacked palette="surface" />

## Form Field

입력 배경은 `--field-background`, 입력값은 `--field-foreground`, 자리 표시자는 `--field-placeholder`로 표현합니다. `--field-hover`와 `--field-focus`는 배경 상태, `--field-border-hover`와 `--field-border-focus`는 테두리 상태를 지정합니다.

키보드 포커스 링에는 `--focus`를 사용합니다.

<ColorSectionFormField />

## Separator

내용 사이를 나눌 때는 `--separator`를 사용합니다. 더 명확한 경계가 필요할 때는 `--separator-secondary`나 `--separator-tertiary`를 사용합니다. 컴포넌트의 외곽선은 `--border`로 구분합니다.

<ColorSectionStacked palette="separator" />

## Other

`--border`는 요소의 외곽선, `--backdrop`은 모달 뒤를 덮는 색입니다. `--overlay`는 화면 위에 뜨는 요소에, `--segment`는 세그먼트 컨트롤의 선택 영역에 사용합니다.

<ColorSectionStacked palette="other" />

## Primitive

`--white`, `--black`, `--snow`, `--eclipse`는 모드와 관계없이 같은 값을 유지하는 원시 토큰입니다. 테마가 이 값들을 조합해 배경과 전경을 정의하고, Blade 템플릿에는 역할이 정해진 토큰을 적용합니다.

<ColorSectionPrimitive />

## 색상 사용법

애플리케이션에서 Tailwind v4를 사용한다면 테마 토큰을 연결해 애플리케이션의 Blade 템플릿에서 유틸리티로 사용할 수 있습니다.

```blade
<section class="bg-surface p-4 text-surface-foreground">
    <h2>{{ $title }}</h2>
    <button type="submit" class="bg-accent text-accent-foreground hover:bg-accent-hover">
        저장
    </button>
</section>
```

CSS에서는 변수를 직접 사용할 수 있습니다.

```css
.settings-panel {
  background-color: var(--surface);
  color: var(--surface-foreground);
  border: 1px solid var(--border);
}
```

## 기본 테마 구성

라이트는 `:root`에서 정의하고, 다크는 `.dark` 또는 `[data-theme="dark"]`에서 같은 토큰을 재정의합니다. 호버 토큰은 각 테마의 기본색을 기준으로 계산합니다. 아래는 화면 배경과 강조를 설정하는 일부 예시입니다.

```css
@layer base {
  :root {
    color-scheme: light;
    --snow: oklch(0.9911 0 0);
    --eclipse: oklch(0.2103 0.0059 285.89);
    --background: oklch(0.9702 0 0);
    --foreground: var(--eclipse);
    --accent: oklch(0.6204 0.195 253.83);
    --accent-foreground: var(--snow);
  }

  :root,
  .dark,
  [data-theme="dark"] {
    --accent-hover: color-mix(in oklab, var(--accent) 90%, var(--accent-foreground));
  }

  .dark,
  [data-theme="dark"] {
    color-scheme: dark;
    --background: oklch(12% 0.005 285.823);
    --foreground: var(--snow);
  }
}
```

## 색상 사용자 정의

브랜드의 강조색을 바꿀 때는 각 모드의 `--accent`와 `--accent-foreground`를 함께 확인합니다. 새로운 색상 역할을 추가하는 경우에도 배경과 전경을 짝으로 정의합니다. Tailwind 유틸리티가 필요하면 `@theme inline`에서 CSS 변수를 연결합니다.

```css
:root {
  --info: oklch(0.94 0.04 235);
  --info-foreground: oklch(0.32 0.1 240);
}

.dark,
[data-theme="dark"] {
  --info: oklch(0.29 0.05 240);
  --info-foreground: oklch(0.9 0.05 235);
}

@theme inline {
  --color-info: var(--info);
  --color-info-foreground: var(--info-foreground);
}
```

검수할 때는 같은 Blade 마크업을 두 모드에서 확인합니다. 배경과 전경의 대비, 기본·호버·포커스 상태, 색상 없이도 식별할 수 있는 성공·경고·위험 메시지를 함께 확인합니다.
