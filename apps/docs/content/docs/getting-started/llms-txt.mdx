JDS는 코딩 에이전트가 Blade 컴포넌트의 구조, 공개 클래스, 상태와 접근성 기준을 읽을 수 있도록 [LLMs.txt](https://llmstxt.org/) 형식의 문서를 제공합니다.

## 사용 가능한 파일

**기본 문서**

- [`/llms.txt`](/llms.txt) — 문서 제목, 설명, 링크를 정리한 인덱스입니다. 필요한 주제를 찾을 때 사용합니다.
- [`/llms-full.txt`](/llms-full.txt) — 소개, 디자인 원칙, 가이드와 코드 예제를 하나로 모은 문서입니다.

**디자인 기준과 작업 지침**

- [`/DESIGN.md`](/DESIGN.md) — 색상, 테마, 스타일링, 애니메이션, 구성 가이드로 연결되는 JDS 디자인 기준입니다.
- [`/AGENTS.md`](/AGENTS.md) — JDS 저장소에서 구현과 검수에 적용하는 작업 지침입니다.

## 연동

다음 예시는 로컬 문서 서버의 주소를 사용합니다. 원격 에이전트에는 해당 환경에서 접근할 수 있는 문서 URL이나 필요한 Markdown 내용을 전달합니다.

**Claude Code**

작업 요청에 문서 주소와 확인할 기준을 적습니다. 반복해서 쓰는 지시라면 프로젝트의 `CLAUDE.md`에 넣을 수 있습니다. [Claude Code 프로젝트 지침](https://code.claude.com/docs/en/memory)

```text
http://localhost:3403/llms.txt에서 JDS v3 문서를 찾아줘.
Blade 컴포넌트를 수정할 때는 디자인 원칙과 관련 가이드를 확인해줘.
```

**Cursor**

작업에 필요한 문서 URL을 요청과 함께 전달합니다. 저장소가 열려 있으면 관련 MDX 파일을 함께 지정할 수 있습니다.

```text
http://localhost:3403/llms-full.txt의 스타일링과 구성 섹션을 참고해서
이 Blade 화면의 공개 클래스와 슬롯 사용을 검토해줘.
```

**Windsurf**

Cascade에 문서 주소와 검토할 항목을 전달합니다.

```text
http://localhost:3403/DESIGN.md를 읽고 JDS의 테마와 접근성 기준을 확인해줘.
이 작업과 관련된 가이드는 http://localhost:3403/llms.txt에서 찾아줘.
```

**기타 AI 도구**

여러 가이드가 필요한 작업에는 `/llms-full.txt`를, 한 부분만 확인할 때는 `/llms.txt`와 확인할 주제를 전달합니다. 예를 들어 컴포넌트 마크업을 검토할 때는 디자인 원칙과 구성 섹션을 함께 지정합니다.

## 개선에 참여하기

AI가 생성한 코드와 JDS 문서가 다르면 사용한 문서 주소, 관련 섹션, 기대한 Blade 마크업이나 동작을 기록합니다. 출력 내용을 고칠 때는 저장소의 `apps/docs/content/docs/`에서 해당 MDX 원본을 수정합니다. 문서 인덱스와 Markdown 출력은 같은 원본에서 생성됩니다.
