## Usage

내용을 나눌 위치에 `<x-jds::separator />`를 넣으세요. 기본 구분선은 너비를 채우는 1px 가로선입니다.

### Vertical

한 줄에 나란히 배치한 항목 사이에는 `orientation="vertical"`을 사용하세요. Flex 행 안에서는 구분선이 행의 높이만큼 늘어납니다.

### With Content

제목과 설명이 있는 항목은 한 덩어리로 유지하고, 항목 사이에 구분선을 넣으세요.

### Decorative

날짜와 상태 사이처럼 보이는 선만 추가하려면 `is-decorative`를 지정하세요. 구분선은 화면에 보이고 스크린 리더에는 읽히지 않습니다.

<SeparatorExample name="decorative" label="날짜와 상태 사이의 장식용 구분선" />

### Custom Element

다른 HTML 요소가 필요한 경우 `element-type`을 지정하세요. `class`, `id`, `data-*` 같은 속성은 실제 구분선 요소에 적용됩니다.

<SeparatorExample name="custom-styles" label="강조색을 적용한 구분선" />

### Global CSS

앱 전체의 Separator 스타일은 `jds-components`보다 뒤에 선언한 CSS 레이어에서 조정할 수 있습니다.

```css
@layer jds-theme, jds-components, app-components;

@layer app-components {
  .jds-separator {
    background-color: var(--accent);
  }

  .jds-separator--horizontal {
    height: 2px;
  }

  .jds-separator--vertical {
    width: 2px;
  }
}
```

## Styling Reference

### CSS Classes

#### Base & Orientation Classes

- `.jds-separator` — 구분선의 공통 스타일
- `.jds-separator--horizontal` — 전체 너비, 높이 1px
- `.jds-separator--vertical` — 너비 1px, 최소 높이 8px (`--spacing` 기본값 기준)

#### Variant Classes

- `.jds-separator--default` — `--separator`
- `.jds-separator--secondary` — `--separator-secondary`
- `.jds-separator--tertiary` — `--separator-tertiary`

## API Reference

### Separator

| 속성 | 사용법과 기본값 |
| --- | --- |
| `orientation` | 기본값은 `horizontal`입니다. `vertical`로 세로선을 표시합니다. |
| `variant` | 기본값은 `default`입니다. `secondary`, `tertiary`를 선택할 수 있습니다. |
| `is-decorative` | 기본값은 `false`입니다. 지정하면 보조 기술에서 구분선을 숨깁니다. |
| `element-type` | 생략하면 방향과 용도에 따라 정해집니다. `hr`, `div`, `span`을 지정할 수 있습니다. |
| `class` | 구분선의 기본 클래스에 CSS 클래스를 추가합니다. |

가로 구분선은 `<hr>`, 세로 구분선과 장식용 구분선은 기본적으로 `<div>`로 렌더링됩니다. 세로에서 `element-type="hr"`를 지정하면 `<div>`가 렌더링됩니다.

### HTML Attributes

기본 `data-slot`은 `separator`이고, `data-orientation`에는 가로·세로 방향이 표시됩니다. 의미 있는 구분선에는 `role="separator"`가 적용되며 세로 구분선은 `aria-orientation="vertical"`을 함께 사용합니다. 장식용 구분선에는 `role="presentation"`과 `aria-hidden="true"`가 적용됩니다.

Separator는 내용 사이에 넣는 요소이므로 자체 슬롯 없이 사용합니다.
