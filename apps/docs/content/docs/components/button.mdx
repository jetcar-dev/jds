### Icon Only

### Loading

`is-pending`을 지정하면 스피너를 표시하고 클릭과 키보드 실행을 막습니다. 이미 버튼에 있던 포커스는 유지됩니다.

작업을 시작할 때 `button.isPending = true`, 끝날 때 `button.isPending = false`를 설정하세요. 아래 버튼을 누르면 2초 동안 스피너와 `Uploading...` 문구가 표시됩니다. 문구는 Blade에서 `loading-text`로 지정합니다.

## Customization

버튼 하나의 스타일을 바꿀 때는 `class`를 추가하고, 여러 버튼에 같은 변경을 적용할 때는 CSS 레이어를 사용하세요.

### Adding custom variants

앱에서 Button을 감싸고 확장 속성을 추가 클래스에 매핑할 수 있습니다. 예제의 반경은 기존 Button의 `variant`와 함께 사용할 수 있습니다.

### Custom CSS

버튼에 사용자 클래스를 전달해 그라데이션, 테두리, 그림자, 상태 전환을 변경합니다.

<ButtonExample name="custom-styles" label="사용자 정의 스타일 버튼" />

### Global CSS

JDS 스타일보다 뒤에 선언되는 CSS 레이어에서 공개 클래스를 재정의합니다.

```css
@layer jds-theme, jds-components, app-components;

@layer app-components {
  .jds-button {
    --jds-button-bg: oklch(0.63 0.23 304);
    --jds-button-bg-hover: oklch(0.56 0.25 302);
    --jds-button-fg: var(--white);
  }

  .jds-button--icon-only {
    border-radius: var(--radius);
    --jds-button-bg: oklch(0.62 0.21 260);
  }
}
```

## Styling Reference

버튼의 변형과 크기는 `.jds-button`의 BEM 클래스로, 브라우저에서 바뀌는 상태는 `data-*` 속성으로 선택할 수 있습니다.

### CSS Classes

#### Base & Size Classes

- `.jds-button` — 기본 스타일
- `.jds-button--sm` · `.jds-button--md` · `.jds-button--lg` — 크기

#### Variant Classes

- `.jds-button--primary` · `.jds-button--secondary` · `.jds-button--tertiary`
- `.jds-button--outline` · `.jds-button--ghost`
- `.jds-button--danger` · `.jds-button--danger-soft`

#### Modifier Classes

- `.jds-button--icon-only` — 아이콘 전용. 크기에 따라 너비와 높이가 함께 바뀝니다.
- `.jds-button--full-width` — 컨테이너 전체 너비

### Interactive States

- **Hover** — `:hover`, `[data-hovered="true"]`
- **Active / Pressed** — `:active`, `[data-pressed="true"]`
- **Focus** — `:focus-visible:not([data-focused])`, `[data-focus-visible="true"]`
- **Disabled** — `:disabled`, `[aria-disabled="true"]`
- **Pending** — `[data-pending="true"]`

누름 배율은 `sm` 0.98, `md` 0.97, `lg` 0.96입니다. `transform` 전환은 250ms, 배경색과 포커스 그림자는 100ms입니다. 시스템에서 모션 감소를 선택하면 전환을 생략합니다.

## API Reference

### Button

| 속성 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `variant` | 문자열 | `primary` | 스타일 변형 |
| `size` | 문자열 | `md` | 버튼 크기 |
| `full-width` | 불리언 | `false` | 영역 너비 채움 |
| `is-disabled` | 불리언 | `false` | 버튼 비활성화 |
| `is-pending` | 불리언 | `false` | 로딩 상태 |
| `loading-text` | 문자열 | `null` | 로딩 문구 |
| `is-icon-only` | 불리언 | `false` | 아이콘 전용 |
| `type` | 문자열 | `button` | HTML 유형 |
| `class` | 문자열 | — | CSS 클래스 |
| 기본 슬롯 | Blade | — | 버튼 안의 내용 |

`variant`에는 `primary`, `secondary`, `tertiary`, `outline`, `ghost`, `danger`, `danger-soft`를 사용할 수 있습니다. `size`에는 `sm`, `md`, `lg`를 지정합니다. `type`은 일반 동작에 `button`, 폼 제출에 `submit`, 초기화에 `reset`을 사용합니다.

아이콘만 들어가는 버튼에는 `aria-label`이나 `aria-labelledby`로 이름을 붙이세요. 로딩 상태는 브라우저에서 [JavaScript 속성](#javascript)으로 바꿀 수 있습니다.

`true`와 `false`를 조건에 따라 전달하려면 `:is-disabled="$disabled"`처럼 속성 앞에 `:`을 붙이세요.

### Slots

기본 슬롯에 텍스트, SVG 아이콘 등 Blade 콘텐츠를 넣습니다. 아이콘은 슬롯에 적은 순서대로 배치됩니다.

직접 만든 스피너를 쓰려면 `loading-text`를 생략하고 기본 슬롯에 `data-slot="spinner"` 요소를 넣으세요. 로딩 중 이 요소에 `hidden`이 없으면 기본 스피너는 생략됩니다.

### HTML Attributes

Blade의 추가 속성은 렌더링된 `<button>`에 적용됩니다. `class`는 JDS 클래스에 합쳐집니다.

| 속성 | 설명 |
| --- | --- |
| `id`, `class`, `tabindex` | 버튼 식별자, 추가 CSS 클래스, 포커스 순서 |
| `disabled` | HTML Boolean 속성. `is-disabled`와 같은 비활성 상태 적용 |
| `name`, `value`, `form` | 폼 연결과 버튼의 제출 값 |
| `formaction`, `formenctype`, `formmethod`, `formnovalidate`, `formtarget` | 이 버튼으로 폼을 제출할 때 적용할 설정 |
| `aria-*`, `data-*` | 접근성 정보와 사용자 정의 데이터. `data-slot`의 기본값은 `button` |
| `data-jds-ripple="true"` | JDS 브라우저 스크립트로 클릭 시 리플 효과 적용 |

### Events

마우스로 클릭하거나 포커스된 버튼에서 Enter 또는 Space를 누르면 `click` 이벤트가 발생합니다. 폼은 제출 시 `submit`, 초기화 시 `reset` 이벤트를 받습니다. 로딩 중에는 버튼의 `type`이 `button`으로 바뀌어 제출이나 초기화를 막습니다.

### JavaScript

앱의 JavaScript 번들에 `vendor/jetcar/jds-blade/index.js`를 한 번 포함합니다.

#### `button.isPending`

`button.isPending = true`로 로딩을 켜고 `button.isPending = false`로 끕니다. 값은 HTML의 `is-pending` 속성과 연동되며 스피너와 접근성 상태도 함께 바뀝니다. Blade의 `onclick`에서는 `this.isPending`으로 같은 버튼을 제어할 수 있습니다. [Loading State 예제](#loading-state)

### Render States

아래 속성은 해당 상태에서 값이 `true`가 됩니다. CSS에서 상태를 선택하거나 JavaScript에서 읽을 수 있습니다.

| 속성 | 상태 |
| --- | --- |
| `data-pending` | 로딩 중 |
| `data-pressed` | 누르는 중 |
| `data-hovered` | 포인터가 올라감 |
| `data-focused` | 포커스됨 |
| `data-focus-visible` | 포커스 표시가 보임 |
| `data-disabled` | 네이티브 `disabled`가 적용됨 |

로딩 중에는 `aria-busy="true"`와 `aria-disabled="true"`가 함께 적용됩니다.
