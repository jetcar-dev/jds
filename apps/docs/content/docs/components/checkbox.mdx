## Usage

<CheckboxExample name="usage" label="기본 체크박스" />

클릭하거나 포커스를 둔 상태에서 `Space`를 누르면 선택이 바뀝니다.

## Anatomy

기본 슬롯에 레이블 텍스트를 넣으면 컨트롤과 체크 표시를 자동으로 렌더링합니다. `content` 슬롯을 사용하면 컨트롤과 텍스트의 배치를 지정할 수 있습니다. `description`과 `error`는 레이블 아래에 표시됩니다.

```blade
<x-jds::checkbox name="terms" required>
    <x-slot:content>
        <x-jds::checkbox.control>
            <x-jds::checkbox.indicator />
        </x-jds::checkbox.control>
        Accept terms
    </x-slot:content>
    <x-slot:description>Read the terms before continuing.</x-slot:description>
    <x-slot:error>Accept the terms to continue.</x-slot:error>
</x-jds::checkbox>
```

### Indeterminate

`is-indeterminate`는 목록에서 일부 항목만 선택된 상태를 표시할 때 사용합니다. 사용자가 체크박스를 조작하면 브라우저가 부분 선택 상태를 해제합니다. JavaScript로 다시 설정하려면 `.indeterminate`를 바꾸고 `input` 이벤트를 보내세요.

### Global CSS

전체 Checkbox에 같은 스타일을 적용하려면 `jds-components` 뒤에 앱 레이어를 선언하세요.

```css

  .jds-checkbox__control {
    width: 1.25rem;
    height: 1.25rem;
  }

  .jds-checkbox__content {
    gap: .75rem;
  }
}
```

## Styling Reference

### CSS Classes

| 클래스 | 적용 요소 |
| --- | --- |
| `.jds-checkbox` | 필드 컨테이너 |
| `.jds-checkbox--primary`, `.jds-checkbox--secondary` | 필드 변형 |
| `.jds-checkbox__content` | 클릭 가능한 레이블 |
| `.jds-checkbox__control` | 체크박스 모양 |
| `.jds-checkbox__indicator` | 체크 또는 부분 선택 표시 |

### Interactive States

- **Selected** — 입력의 `:checked`가 컨트롤에 반영됩니다. 필드와 레이블에 `data-selected="true"`가 표시됩니다.
- **Indeterminate** — `data-indeterminate="true"`일 때 기본 가로선이 표시됩니다.
- **Invalid** — `data-invalid="true"`일 때 오류 색상과 메시지가 적용됩니다. 실제 입력에는 `aria-invalid`가 표시됩니다.
- **Focus** — 입력의 `:focus-visible`이 컨트롤에 포커스 링을 표시합니다.
- **Hover / Pressed** — `:hover`, `:active`와 레이블의 `data-hovered`, `data-pressed`를 사용합니다.
- **Disabled** — `data-disabled="true"`일 때 컨트롤과 설명을 흐리게 표시합니다.

## API Reference

### Checkbox

| 속성 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `variant` | `primary \| secondary` | `primary` | 배경과 그림자를 지정합니다. |
| `checked` | `boolean` | `false` | 초기 선택 상태입니다. |
| `disabled` | `boolean` | `false` | 선택과 포커스를 비활성화하고 폼 제출에서 제외합니다. |
| `required` | `boolean` | `false` | 브라우저 검증에서 선택을 요구합니다. |
| `is-read-only` | `boolean` | `false` | 포커스와 폼 제출을 유지하면서 사용자 조작에 의한 값 변경을 막습니다. |
| `is-indeterminate` | `boolean` | `false` | 초기 부분 선택 상태를 지정합니다. |
| `is-invalid` | `boolean` | `false` | 오류 스타일을 적용하고 연결된 오류 메시지를 표시합니다. |
| `id` | `string` | — | 실제 입력에 적용합니다. 외부 레이블이나 JavaScript에서 사용할 수 있습니다. |
| `name` | `string` | — | 폼 제출에 사용할 필드 이름입니다. |
| `value` | `string` | `on` | 선택했을 때 제출할 값입니다. |
| `form` | `string` | — | 소속 폼의 `id`입니다. |
| `onchange` | `string` | — | 선택 상태가 바뀔 때 실행합니다. `this.checked`로 값을 읽을 수 있습니다. |
| `class` | `string` | — | 바깥 필드에 추가할 클래스입니다. |

기본 선택, 키보드 조작과 폼 제출은 네이티브 입력이 처리합니다. `is-indeterminate`, `is-read-only`와 동적 `data-*` 상태에는 패키지의 브라우저 스크립트가 필요합니다.

### Slots

| 슬롯 | 내용 |
| --- | --- |
| 기본 슬롯 | 레이블 텍스트입니다. 컨트롤과 기본 표시가 함께 렌더링됩니다. |
| `content` | 클릭 가능한 레이블의 내용입니다. `checkbox.control`과 텍스트를 직접 배치합니다. 슬롯의 속성은 레이블에 적용됩니다. |
| `description` | 레이블 아래의 설명입니다. |
| `error` | 유효하지 않을 때 표시할 메시지입니다. |
