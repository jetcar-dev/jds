## Usage

JDS 스타일시트를 불러오면 기본 Card의 배경, 여백, 모서리, 그림자가 적용됩니다.

<CardExample name="usage" label="주행 리워드 카드" />

## Anatomy

카드의 각 부분을 필요한 순서로 배치하세요. 사용하지 않는 영역은 생략할 수 있습니다.

```blade
<x-jds::card>
    <x-jds::card.header>
        <x-jds::card.title>예약 내역</x-jds::card.title>
        <x-jds::card.description>다음 이용 일정을 확인하세요.</x-jds::card.description>
    </x-jds::card.header>
    <x-jds::card.content>금요일 오전 10시 · 서울역</x-jds::card.content>
    <x-jds::card.footer>
        <a href="/reservations">예약 상세 보기</a>
    </x-jds::card.footer>
</x-jds::card>
```

## Customization

### Custom CSS

한 카드에만 테두리나 그라데이션을 적용하려면 `class`로 스타일을 연결하세요.

<CardExample name="custom-styles" label="그라데이션을 적용한 카드" />

### Global CSS

앱 전체의 카드 스타일은 `jds-components`보다 뒤에 선언한 CSS 레이어에서 조정하세요.

```css
@layer jds-theme, jds-components, app-components;

@layer app-components {
  .jds-card--secondary {
    background-image: linear-gradient(to bottom right, var(--surface), var(--surface-secondary));
  }

  .jds-card__title {
    font-weight: 700;
  }
}
```

## Styling Reference

### CSS Classes

#### Base Classes

- `.jds-card` — 세로 레이아웃, 안쪽 여백 16px, 영역 사이 간격 12px, 기본 모서리 반경 24px
- `.jds-card__header` — 제목과 설명을 세로로 배치
- `.jds-card__title` — 14px 제목, 굵기 500
- `.jds-card__description` — 14px 보조 텍스트, `--muted` 색상
- `.jds-card__content` — 남는 공간을 채우는 본문, 내부 간격 4px
- `.jds-card__footer` — 동작을 가로로 배치하고 세로 중앙에 정렬

#### Variant Classes

- `.jds-card--default` — `--surface` 배경
- `.jds-card--secondary` — `--surface-secondary` 배경
- `.jds-card--tertiary` — `--surface-tertiary` 배경
- `.jds-card--transparent` — 투명 배경, 그림자 없음

표면의 그림자는 `--surface-shadow`를 따릅니다. 기본 라이트 테마에는 얕은 그림자가 있고, 다크 테마의 그림자는 투명합니다.

## API Reference

### Card

| 속성 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `variant` | 문자열 | `default` | 카드의 표면 변형 |
| `element-type` | 문자열 | `div` | 카드의 HTML 태그 |
| `class` | 문자열 | — | 추가 CSS 클래스 |
| 기본 슬롯 | Blade | — | 카드 안의 내용 |

`variant`에는 `transparent`, `default`, `secondary`, `tertiary`를 사용할 수 있습니다. `element-type`에는 `div`, `article`, `section`, `aside`, `a`를 지정할 수 있습니다.

루트와 하위 컴포넌트에 전달한 `id`, `class`, `aria-*`, `data-*`는 각 HTML 요소에 적용됩니다.

## Accessibility

독립적인 콘텐츠는 `<article>`로 표시하고 `aria-labelledby`에 제목의 `id`를 연결하세요. 스크린 리더가 카드를 제목으로 식별할 수 있습니다.

```blade
<x-jds::card element-type="article" aria-labelledby="booking-title">
    <x-jds::card.header>
        <x-jds::card.title id="booking-title">예약이 확정되었습니다</x-jds::card.title>
    </x-jds::card.header>
</x-jds::card>
```

카드 전체가 예약 상세 페이지로 이동한다면 `element-type="a"`와 `href`를 지정하세요. 키보드로도 카드 링크에 포커스를 두고 열 수 있습니다.

```blade
<x-jds::card element-type="a" href="/reservations/123">
    <x-jds::card.title>서울역 예약 상세 보기</x-jds::card.title>
</x-jds::card>
```
