## Usage

<SurfaceExample name="usage" label="기본 표면" />

Surface는 `variant`에 따라 배경과 글자색을 적용합니다. 위 예제는 CSS로 안쪽 여백 24px, 모서리 반경 24px, 콘텐츠 간격 12px을 지정합니다.

## Examples

### Variants

화면에서 콘텐츠를 얼마나 강조할지에 따라 표면을 선택하세요.

- **`default`** — 기본 표면 `--surface`
- **`secondary`** — 한 단계 강조한 표면 `--surface-secondary`
- **`tertiary`** — 더 강조한 표면 `--surface-tertiary`
- **`transparent`** — 테두리 없이 뒤의 배경이 그대로 보이는 투명 표면

Transparent 예제는 영역을 구분하기 위해 CSS로 1px 테두리를 추가합니다.

## Customization

### Custom CSS

`class`를 전달해 한 영역에만 안쪽 여백, 테두리, 그라데이션을 적용할 수 있습니다.

<SurfaceExample name="custom-styles" label="그라데이션을 적용한 표면" />

### Global CSS

앱 전체의 표면 스타일은 `jds-components`보다 뒤에 선언한 CSS 레이어에서 조정하세요.

```css
@layer jds-theme, jds-components, app-components;

@layer app-components {
  .jds-surface {
    border: 1px solid var(--border);
    border-radius: calc(var(--radius) * 2);
  }

  .jds-surface--secondary {
    background-image: linear-gradient(to bottom right, var(--surface), var(--surface-secondary));
  }
}
```

## Styling Reference

### CSS Classes

#### Base Classes

- `.jds-surface` — `position: relative`와 기본 글자색 `--foreground`

#### Variant Classes

- `.jds-surface--default` — `--surface`와 `--surface-foreground`
- `.jds-surface--secondary` — `--surface-secondary`와 `--surface-secondary-foreground`
- `.jds-surface--tertiary` — `--surface-tertiary`와 `--surface-tertiary-foreground`
- `.jds-surface--transparent` — 투명 배경과 기본 글자색

## API Reference

### Surface

| 속성 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `variant` | 문자열 | `default` | 표면의 변형 |
| `element-type` | 문자열 | `div` | 표면의 HTML 태그 |
| `class` | 문자열 | — | 추가 CSS 클래스 |
| 기본 슬롯 | Blade | — | 표면 안의 내용 |

`variant`에는 `default`, `secondary`, `tertiary`, `transparent`를 사용할 수 있습니다. `element-type`에는 `div`, `article`, `section`, `aside`, `a`를 지정할 수 있습니다.

루트에는 `data-slot="surface"`가 적용됩니다. 전달한 `id`, `class`, `aria-*`, `data-*`도 루트에 전달됩니다.

## Context API

### Surface Variant

`data-surface-variant`에는 현재 표면의 변형이 표시됩니다. 중첩된 구조에서는 가장 가까운 표면의 값을 읽을 수 있습니다. Card도 이 속성을 제공하며, 투명 Card 안에서는 바깥 표면의 값이 사용됩니다.

```js
const field = document.querySelector('#feedback');
const variant = field?.closest('[data-surface-variant]')?.dataset.surfaceVariant;
```
