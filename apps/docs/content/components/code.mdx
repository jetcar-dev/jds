## 기본 사용법

본문 흐름 안에서 명령어, 속성명처럼 짧은 코드를 강조합니다. 기본 크기는 `sm`, 색상은 `default`, 모서리는 `sm`입니다.

```blade preview name="code-basic"
<x-code>npm install @jetcar/jds</x-code>
```

## 크기

`sm`, `md`, `lg` 세 가지 크기를 제공합니다. 글자 크기뿐 아니라 줄 높이도 함께 조절됩니다.

```blade preview name="code-sizes"
<div class="jds-example-row">
    <x-code size="sm">npm install @jetcar/jds</x-code>
    <x-code size="md">npm install @jetcar/jds</x-code>
    <x-code size="lg">npm install @jetcar/jds</x-code>
</div>
```

## 색상

`default`, `primary`, `secondary`, `success`, `warning`, `danger` 의미 색상을 지원합니다. 각 색상은 연한 배경과 읽기 쉬운 전경색을 함께 적용합니다.

```blade preview name="code-colors"
<div class="jds-example-row">
    <x-code color="default">default</x-code>
    <x-code color="primary">primary</x-code>
    <x-code color="secondary">secondary</x-code>
    <x-code color="success">success</x-code>
    <x-code color="warning">warning</x-code>
    <x-code color="danger">danger</x-code>
</div>
```

## 모서리

`none`, `sm`, `md`, `lg`, `full`로 모서리 둥글기를 선택할 수 있습니다.

```blade preview name="code-radius"
<div class="jds-example-row">
    <x-code radius="none">none</x-code>
    <x-code radius="sm">sm</x-code>
    <x-code radius="md">md</x-code>
    <x-code radius="lg">lg</x-code>
    <x-code radius="full">full</x-code>
</div>
```

## 슬롯

기본 슬롯에 표시할 코드 문자열이나 인라인 마크업을 넣습니다. 루트에는 `base` 슬롯이 제공됩니다.

## 접근성

실제 `<code>` 요소로 렌더링되므로 보조 기술이 코드 조각으로 인식합니다. 여러 줄 코드나 복사 기능이 필요한 경우에는 Snippet을 사용합니다.
