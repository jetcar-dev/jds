## 사용법

필드 안에서 시작일과 종료일을 직접 입력하거나 달력 버튼을 눌러 범위를 선택합니다. 기본 달력은 한 달을 표시하며 범위 구분자는 `~`입니다.

```blade preview name="date-range-picker-basic"
<x-date-range-picker
    name="period"
    label="숙박 기간"
/>
```

## 비활성화

`disabled`는 입력, 달력 열기, 폼 전송을 모두 비활성화합니다.

```blade preview name="date-range-picker-disabled"
<x-date-range-picker
    disabled
    label="예약 기간"
    :value="['start' => '2026-08-05', 'end' => '2026-08-12']"
/>
```

## 읽기 전용과 필수 입력

`read-only`는 값을 표시하되 수정하지 못하게 하고, `required`는 시작일과 종료일을 필수 값으로 처리합니다.

```blade preview name="date-range-picker-readonly-required"
<x-date-range-picker read-only label="정산 기간" :value="['start' => '2026-08-01', 'end' => '2026-08-31']" />
<x-date-range-picker required label="출장 기간" description="시작일과 종료일을 모두 입력하세요." />
```

## 형태

`flat`, `bordered`, `underlined`, `faded`를 지원합니다.

```blade preview name="date-range-picker-variants"
<x-date-range-picker variant="flat" label="Flat" :value="['start' => '2026-08-05', 'end' => '2026-08-12']" />
<x-date-range-picker variant="bordered" label="Bordered" :value="['start' => '2026-08-05', 'end' => '2026-08-12']" />
<x-date-range-picker variant="underlined" label="Underlined" :value="['start' => '2026-08-05', 'end' => '2026-08-12']" />
<x-date-range-picker variant="faded" label="Faded" :value="['start' => '2026-08-05', 'end' => '2026-08-12']" />
```

## 색상과 크기

색상은 `default`, `primary`, `secondary`, `success`, `warning`, `danger`, 크기는 `sm`, `md`, `lg`를 지원합니다.

```blade preview name="date-range-picker-colors-sizes"
<x-date-range-picker color="primary" size="sm" label="Primary" :value="['start' => '2026-08-05', 'end' => '2026-08-12']" />
<x-date-range-picker color="secondary" size="md" label="Secondary" :value="['start' => '2026-08-05', 'end' => '2026-08-12']" />
<x-date-range-picker color="success" size="lg" label="Success" :value="['start' => '2026-08-05', 'end' => '2026-08-12']" />
```

## 표시할 달 수

`visible-months`에는 `1`, `2`, `3`을 지정할 수 있습니다. 여러 달일 때 `page-behavior="visible"`은 표시 중인 달 수만큼, `single`은 한 달씩 이동합니다.

```blade preview name="date-range-picker-visible-months"
<x-date-range-picker
    label="프로젝트 기간"
    :visible-months="2"
    page-behavior="visible"
    :value="['start' => '2026-08-05', 'end' => '2026-09-12']"
/>
```

## 라벨 위치와 설명

`label-placement`는 `inside`, `outside`, `outside-top`, `outside-left`를 지원합니다.

```blade preview name="date-range-picker-label-placements"
<x-date-range-picker label="기간" label-placement="inside" />
<x-date-range-picker label="기간" label-placement="outside" description="조회할 기간을 선택하세요." />
<x-date-range-picker label="기간" label-placement="outside-left" />
```

## 오류

`invalid`와 `error-message`를 함께 사용합니다. 시작일이 종료일보다 늦어져도 자동으로 오류 상태가 됩니다.

```blade preview name="date-range-picker-invalid"
<x-date-range-picker
    invalid
    variant="bordered"
    label="예약 기간"
    error-message="올바른 날짜 범위를 선택하세요."
    :value="['start' => '2026-08-20', 'end' => '2026-08-12']"
/>
```

## 월·연도 선택

`show-month-and-year-pickers`를 사용하면 달력 제목을 눌러 연도와 월을 빠르게 이동할 수 있습니다. 연도 목록을 먼저, 월 목록을 뒤에 표시합니다. `visible-months`가 `2` 이상이면 이 기능은 비활성화됩니다.

```blade preview name="date-range-picker-month-year"
<x-date-range-picker
    label="휴가 기간"
    :value="['start' => '2026-08-05', 'end' => '2026-08-12']"
    show-month-and-year-pickers
/>
```

## 선택 범위 제한

`min-value`, `max-value`, `disabled-values`, `unavailable-values`로 입력 및 달력에서 선택할 수 있는 날짜를 제한합니다.

```blade preview name="date-range-picker-bounds"
<x-date-range-picker
    label="예약 가능 기간"
    min-value="2026-07-01"
    max-value="2027-08-31"
    :unavailable-values="['2026-08-15', '2026-08-16']"
/>
```

## 시간 입력

`granularity`를 `hour`, `minute`, `second` 중 하나로 지정하면 달력 아래에 시작 시간과 종료 시간 입력이 표시됩니다.

```blade preview name="date-range-picker-time"
<x-date-range-picker
    name="meeting"
    label="회의 기간"
    granularity="minute"
    :visible-months="2"
    page-behavior="single"
    :hour-cycle="12"
    :value="['start' => '2026-08-28T09:30', 'end' => '2026-09-03T11:00']"
/>
```

## 프리셋과 달력 콘텐츠

`presets`는 이름과 날짜 범위를 연결한 배열입니다. `calendarTopContent`, `calendarBottomContent`, `selectorIcon` 슬롯으로 달력을 확장할 수 있습니다.

```blade preview name="date-range-picker-presets"
<x-date-range-picker
    label="보고 기간"
    :presets="[
        '이번 주' => ['start' => '2026-08-10', 'end' => '2026-08-16'],
        '이번 달' => ['start' => '2026-08-01', 'end' => '2026-08-31'],
    ]"
>
    <x-slot:calendarBottomContent>
        <small>마감일을 포함해 선택합니다.</small>
    </x-slot:calendarBottomContent>
</x-date-range-picker>
```

## 세밀도

`granularity`는 입력할 최소 시간 단위를 결정합니다. `day`가 기본값이며 `hour`, `minute`, `second`를 지원합니다.

```blade preview name="date-range-picker-granularity"
<x-date-range-picker
    label="시간 단위"
    granularity="hour"
    :value="['start' => '2026-08-05T09:00', 'end' => '2026-08-05T11:00']"
/>
<x-date-range-picker
    label="초 단위"
    granularity="second"
    :value="['start' => '2026-08-05T09:30:15', 'end' => '2026-08-05T11:00:30']"
/>
```

## 시간대

`time-zone`을 지정하면 해당 시간대를 기준으로 값을 표시합니다. `hide-time-zone`으로 시간대 이름만 숨길 수 있습니다.

```blade preview name="date-range-picker-time-zones"
<x-date-range-picker
    label="서울 일정"
    granularity="minute"
    time-zone="Asia/Seoul"
    :value="['start' => '2026-08-05T09:30+09:00[Asia/Seoul]', 'end' => '2026-08-05T11:00+09:00[Asia/Seoul]']"
/>
```

## 달력 버튼 아이콘

`selectorIcon` 슬롯으로 기본 달력 아이콘을 교체할 수 있습니다.

```blade preview name="date-range-picker-selector-icon"
<x-date-range-picker label="여행 기간">
    <x-slot:selectorIcon>
        <x-icon name="solar:calendar-search-linear" />
    </x-slot:selectorIcon>
</x-date-range-picker>
```

## 달력 버튼 위치

`selector-button-placement`는 `start` 또는 `end`를 지원합니다.

```blade preview name="date-range-picker-selector-placement"
<x-date-range-picker label="시작 배치" selector-button-placement="start" />
<x-date-range-picker label="끝 배치" selector-button-placement="end" />
```

## 시작과 끝 콘텐츠

`startContent`, `endContent` 슬롯은 날짜 범위 양쪽에 아이콘이나 짧은 보조 정보를 배치합니다. 긴 문장 대신 아이콘 또는 `KST`처럼 짧은 텍스트를 사용합니다.

```blade preview name="date-range-picker-content"
<x-date-range-picker label="출장 기간">
    <x-slot:startContent><x-icon name="solar:map-point-linear" /></x-slot:startContent>
    <x-slot:endContent>KST</x-slot:endContent>
</x-date-range-picker>
```

## 국제화

`locale`에 따라 날짜 순서, 구분자, 월과 요일 표기가 자동으로 바뀝니다.

```blade preview name="date-range-picker-locales"
<x-date-range-picker locale="ko-KR" label="한국어" />
<x-date-range-picker locale="en-US" label="English" />
<x-date-range-picker locale="ja-JP" label="日本語" />
```

## 선택할 수 없는 날짜

`unavailable-values`의 날짜는 취소선으로 표시되고 선택할 수 없습니다. 범위 중간에 선택 불가 날짜를 허용하려면 `allows-non-contiguous-ranges`를 추가합니다.

```blade preview name="date-range-picker-unavailable"
<x-date-range-picker
    label="배송 기간"
    :unavailable-values="['2026-08-08', '2026-08-09']"
    :value="['start' => '2026-08-05', 'end' => '2026-08-12']"
/>
<x-date-range-picker
    label="비연속 범위"
    :unavailable-values="['2026-08-08', '2026-08-09']"
    allows-non-contiguous-ranges
/>
```

## 폼 전송

`name="period"`를 지정하면 `period[start]`, `period[end]`가 실제 폼 값으로 전송됩니다.

```blade preview name="date-range-picker-form"
<form method="post" novalidate>
    <x-date-range-picker name="period" label="조회 기간" required />
    <x-button type="submit" size="sm">조회</x-button>
</form>
```

## 이벤트와 Controller

값이 변경되면 각 날짜 input의 native `input`, `change`와 루트의 `app-ui:date-range-picker:change` 이벤트가 발생합니다. 이벤트의 `detail.value`는 `{start, end}`입니다.

```javascript
const picker = document.querySelector('[data-ui-component="date-range-picker"]')
const controller = AppUI.get(picker)

controller.setValue({start: '2026-08-05', end: '2026-08-12'}, true)
controller.open()
controller.close()
```

## 접근성

날짜의 각 부분은 키보드로 편집할 수 있습니다. 달력 안에서는 방향키, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`를 사용하고 `Escape`로 닫습니다. 팝오버가 닫히면 달력 버튼으로 포커스가 돌아옵니다.
