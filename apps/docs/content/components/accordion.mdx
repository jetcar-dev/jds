## 사용법

`Accordion` 안에 `AccordionItem`을 넣습니다. 기본값은 한 번에 하나의 항목을 여는 `single` 선택 방식입니다.

```blade preview name="accordion-basic"
<x-accordion>
    <x-accordion-item value="one" title="Accordion 1">첫 번째 항목의 내용입니다.</x-accordion-item>
    <x-accordion-item value="two" title="Accordion 2">두 번째 항목의 내용입니다.</x-accordion-item>
    <x-accordion-item value="three" title="Accordion 3">세 번째 항목의 내용입니다.</x-accordion-item>
</x-accordion>
```

## 부제목

`subtitle`은 제목 아래에 보조 설명을 표시합니다.

```blade preview name="accordion-subtitle"
<x-accordion>
    <x-accordion-item value="payment" title="결제 정보" subtitle="카드와 현금영수증 정보를 관리합니다.">
        등록된 결제 수단은 주문 화면에서 선택할 수 있습니다.
    </x-accordion-item>
    <x-accordion-item value="delivery" title="배송 정보" subtitle="기본 배송지와 연락처를 관리합니다.">
        배송지는 여러 개 저장할 수 있습니다.
    </x-accordion-item>
    <x-accordion-item value="notification" title="알림 설정" subtitle="업무 알림의 수신 방법을 선택합니다.">
        이메일과 문자 알림을 설정할 수 있습니다.
    </x-accordion-item>
</x-accordion>
```

## 여러 항목 펼치기

`selection-mode="multiple"`을 사용하면 여러 항목을 동시에 펼칠 수 있습니다.

```blade preview name="accordion-multiple"
<x-accordion selection-mode="multiple">
    <x-accordion-item value="profile" title="프로필">이름과 연락처를 관리합니다.</x-accordion-item>
    <x-accordion-item value="security" title="보안">비밀번호와 로그인 기록을 관리합니다.</x-accordion-item>
    <x-accordion-item value="notification" title="알림">수신할 알림을 선택합니다.</x-accordion-item>
</x-accordion>
```

## 간결한 형태

`compact`를 사용하면 제목과 본문의 세로 여백이 절반으로 줄어듭니다.

```blade preview name="accordion-compact"
<x-accordion compact>
    <x-accordion-item value="one" title="Accordion 1">첫 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="two" title="Accordion 2">두 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="three" title="Accordion 3">세 번째 내용입니다.</x-accordion-item>
</x-accordion>
```

## 형태

Accordion은 `light`, `shadow`, `bordered`, `splitted` 네 가지 형태를 제공합니다.

### Light

배경과 외곽선 없이 구분선만 사용합니다. 기본 형태입니다.

```blade preview name="accordion-variant-light"
<x-accordion variant="light">
    <x-accordion-item value="one" title="Accordion 1">첫 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="two" title="Accordion 2">두 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="three" title="Accordion 3">세 번째 내용입니다.</x-accordion-item>
</x-accordion>
```

### Shadow

하나의 표면과 그림자로 전체 항목을 묶습니다.

```blade preview name="accordion-variant-shadow"
<x-accordion variant="shadow">
    <x-accordion-item value="one" title="Accordion 1">첫 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="two" title="Accordion 2">두 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="three" title="Accordion 3">세 번째 내용입니다.</x-accordion-item>
</x-accordion>
```

### Bordered

전체 항목을 하나의 외곽선으로 감쌉니다.

```blade preview name="accordion-variant-bordered"
<x-accordion variant="bordered">
    <x-accordion-item value="one" title="Accordion 1">첫 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="two" title="Accordion 2">두 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="three" title="Accordion 3">세 번째 내용입니다.</x-accordion-item>
</x-accordion>
```

### Splitted

각 항목을 간격이 있는 독립적인 표면으로 표시합니다.

```blade preview name="accordion-variant-splitted"
<x-accordion variant="splitted">
    <x-accordion-item value="one" title="Accordion 1">첫 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="two" title="Accordion 2">두 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="three" title="Accordion 3">세 번째 내용입니다.</x-accordion-item>
</x-accordion>
```

## 처음 펼칠 항목

`default-expanded-keys`에 처음 펼칠 항목의 `value`를 배열로 전달합니다.

```blade preview name="accordion-default-expanded"
<x-accordion :default-expanded-keys="['two']">
    <x-accordion-item value="one" title="Accordion 1">첫 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="two" title="Accordion 2">두 번째 항목이 처음부터 펼쳐집니다.</x-accordion-item>
    <x-accordion-item value="three" title="Accordion 3">세 번째 내용입니다.</x-accordion-item>
</x-accordion>
```

## 비활성화된 항목

`disabled-keys`에 선택할 수 없는 항목의 `value`를 전달합니다.

```blade preview name="accordion-disabled-keys"
<x-accordion :disabled-keys="['two']">
    <x-accordion-item value="one" title="Accordion 1">첫 번째 내용입니다.</x-accordion-item>
    <x-accordion-item value="two" title="Accordion 2">이 항목은 열 수 없습니다.</x-accordion-item>
    <x-accordion-item value="three" title="Accordion 3">세 번째 내용입니다.</x-accordion-item>
</x-accordion>
```

## 시작 콘텐츠

`startContent` 슬롯에 아이콘, Avatar 또는 원하는 HTML을 넣을 수 있습니다.

```blade preview name="accordion-start-content"
<x-accordion>
    <x-accordion-item value="vehicle" title="차량 정보" subtitle="등록 차량 3대">
        <x-slot:startContent><x-icon name="ph:car-light" /></x-slot:startContent>
        차량번호, 모델, 출고일을 확인할 수 있습니다.
    </x-accordion-item>
    <x-accordion-item value="location" title="영업소 정보" subtitle="운영 중인 영업소 5곳">
        <x-slot:startContent><x-icon name="solar:buildings-linear" /></x-slot:startContent>
        영업소 주소와 담당자를 확인할 수 있습니다.
    </x-accordion-item>
</x-accordion>
```

## 사용자 정의 Indicator

`indicator` 슬롯으로 기본 화살표를 교체하거나 `hide-indicator`로 숨길 수 있습니다.

```blade preview name="accordion-custom-indicator"
<x-accordion>
    <x-accordion-item value="custom" title="사용자 정의 아이콘">
        <x-slot:indicator><x-icon name="lucide:plus" /></x-slot:indicator>
        원하는 아이콘을 사용할 수 있습니다.
    </x-accordion-item>
    <x-accordion-item value="hidden" title="Indicator 숨김" hide-indicator>
        Indicator 없이 사용할 수도 있습니다.
    </x-accordion-item>
</x-accordion>
```

## 애니메이션

기본적으로 높이와 투명도가 함께 자연스럽게 전환됩니다. 효과가 필요 없다면 `disable-animation`을 사용합니다. 화살표 회전만 끄려면 `disable-indicator-animation`을 사용합니다.

```blade preview name="accordion-animation"
<x-accordion disable-indicator-animation>
    <x-accordion-item value="one" title="Indicator 회전 없음">본문은 애니메이션으로 열립니다.</x-accordion-item>
    <x-accordion-item value="two" title="모든 애니메이션 없음" disable-animation>즉시 열리고 닫힙니다.</x-accordion-item>
</x-accordion>
```

## 선택 유지

`disallow-empty-selection`은 마지막으로 열린 항목이 다시 닫히지 않도록 합니다.

```blade preview name="accordion-required-selection"
<x-accordion disallow-empty-selection :default-expanded-keys="['available']">
    <x-accordion-item value="available" title="항상 하나는 열림">마지막 항목은 닫히지 않습니다.</x-accordion-item>
    <x-accordion-item value="another" title="다른 항목">이 항목을 열면 기존 항목이 닫힙니다.</x-accordion-item>
</x-accordion>
```

## 슬롯

`AccordionItem`은 기본 본문 슬롯과 `startContent`, `indicator` named slot을 제공합니다. DOM에는 `accordion`, `base`, `heading`, `trigger`, `startContent`, `titleWrapper`, `title`, `subtitle`, `indicator`, `content` `data-slot`이 제공됩니다.

## 이벤트와 Controller

선택이 바뀌면 `app-ui:accordion:change` 이벤트가 발생하며 `event.detail.keys`로 열린 항목의 값 배열을 전달합니다.

`AppUI.get(accordion)`은 `getValue()`, `setValue(keys)`, `open(key)`, `close(key)`, `toggle(key)`, `focus()`, `destroy()`를 제공합니다.

## 접근성

각 제목은 실제 heading과 button으로 렌더링됩니다. `aria-expanded`, `aria-controls`, `aria-labelledby`, `aria-disabled`가 자동 연결되며 Enter, Space, 방향키, Home, End를 지원합니다. `prefers-reduced-motion` 환경에서는 애니메이션을 자동으로 생략합니다.
