## 사용법

실제 checkbox input을 사용하므로 이름과 값이 일반 HTML 폼으로 전송됩니다.

```blade preview name="switch-basic"
<x-switch name="notifications" aria-label="자동 업데이트" checked />
```

## 라벨

기본 슬롯 또는 `label` 속성으로 클릭 가능한 라벨을 제공합니다. `description`은 라벨 아래의 보조 설명입니다.

```blade preview name="switch-label"
<div class="jds-example-stack">
    <x-switch name="marketing">마케팅 알림</x-switch>
    <x-switch name="security" label="보안 알림" description="새로운 로그인과 중요 변경을 알려드립니다." checked />
</div>
```

## 비활성과 읽기 전용

`disabled`는 포커스와 폼 입력을 비활성화합니다. `readonly`는 현재 값을 폼에 유지하면서 사용자의 변경만 막습니다.

```blade preview name="switch-disabled"
<div class="jds-example-row">
    <x-switch disabled>비활성</x-switch>
    <x-switch disabled checked>선택된 비활성</x-switch>
    <x-switch readonly checked>읽기 전용</x-switch>
</div>
```

## 크기

HeroUI v2 기준으로 `sm`은 40×24px, `md`는 48×28px, `lg`는 56×32px입니다.

```blade preview name="switch-sizes"
<div class="jds-example-row">
    <x-switch size="sm" checked>Small</x-switch>
    <x-switch size="md" checked>Medium</x-switch>
    <x-switch size="lg" checked>Large</x-switch>
</div>
```

## 색상

선택된 track에 `default`, `primary`, `secondary`, `success`, `warning`, `danger` 색상을 적용합니다.

```blade preview name="switch-colors"
<div class="jds-example-row">
    <x-switch color="default" checked>Default</x-switch>
    <x-switch color="primary" checked>Primary</x-switch>
    <x-switch color="secondary" checked>Secondary</x-switch>
    <x-switch color="success" checked>Success</x-switch>
    <x-switch color="warning" checked>Warning</x-switch>
    <x-switch color="danger" checked>Danger</x-switch>
</div>
```

## Thumb 아이콘

`thumbIcon`은 항상 표시할 아이콘에 사용합니다. 선택 상태에 따라 아이콘을 바꾸려면 `thumbIconOn`과 `thumbIconOff`를 함께 사용합니다.

```blade preview name="switch-thumb-icon"
<div class="jds-example-row">
    <x-switch checked aria-label="화면 테마">
        <x-slot:thumbIconOn><x-icon name="solar:sun-bold" /></x-slot:thumbIconOn>
        <x-slot:thumbIconOff><x-icon name="solar:moon-bold" /></x-slot:thumbIconOff>
    </x-switch>
    <x-switch aria-label="자동 실행">
        <x-slot:thumbIcon><x-icon name="solar:bolt-bold" /></x-slot:thumbIcon>
    </x-switch>
</div>
```

## 시작과 끝 아이콘

`startContent`는 선택됐을 때, `endContent`는 선택되지 않았을 때 track 안에 표시됩니다.

```blade preview name="switch-content-icons"
<x-switch checked aria-label="화면 테마">
    <x-slot:startContent><x-icon name="solar:sun-bold" /></x-slot:startContent>
    <x-slot:endContent><x-icon name="solar:moon-bold" /></x-slot:endContent>
</x-switch>
```

## 폼과 Controller

값 변경 시 native `input/change`와 `app-ui:switch:change`가 발생합니다. Controller는 `getValue()`, `setValue(value, notify)`, `focus()`, `destroy()`를 제공합니다.

```blade preview name="switch-form"
<form class="jds-example-stack" method="post">
    <x-switch name="notifications" value="enabled" required>공지 수신</x-switch>
    <x-button type="submit" color="primary">저장</x-button>
</form>
```

```js
const root = document.querySelector('[data-ui-component="switch"]');
const controller = AppUI.get(root);
controller.setValue(true, true);
```

## 슬롯

- `base`: Switch 루트 label
- `hidden-input`: 실제 checkbox input
- `wrapper`: track, 콘텐츠와 thumb를 감싸는 영역
- `thumb`: 움직이는 원
- `thumb-icon`: thumb 내부 아이콘
- `thumb-icon-selected`: 선택됐을 때 표시되는 thumb 아이콘
- `thumb-icon-unselected`: 선택되지 않았을 때 표시되는 thumb 아이콘
- `start-content`: 선택 상태의 track 아이콘
- `end-content`: 미선택 상태의 track 아이콘
- `label`: 보이는 라벨
- `description`: 보조 설명

## 접근성

실제 input에 `role="switch"`를 사용합니다. Tab으로 포커스하고 Space로 상태를 전환할 수 있으며 키보드 포커스에만 focus-visible 링이 표시됩니다.
