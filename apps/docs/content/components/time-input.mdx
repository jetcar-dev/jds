## 사용법

Time Input은 시간을 시·분·초 세그먼트로 나눠 표시합니다. 각 세그먼트에 숫자를 입력하거나 위·아래 방향키를 사용해 값을 변경할 수 있습니다. `value`가 없으면 현재 locale과 hour cycle에 맞는 placeholder를 표시합니다.

```blade preview name="time-input-basic"
<x-time-input name="event_time" label="행사 시간" />
<x-time-input name="meeting_time" label="회의 시간" value="11:45" />
```

## 필수 입력

`required`는 라벨에 필수 표시를 추가하고 실제 폼 input에도 필수 조건을 적용합니다.

```blade preview name="time-input-required"
<x-time-input name="start_time" label="시작 시간" required />
```

## 비활성화

`disabled` 상태에서는 모든 시간 세그먼트가 비활성화되고 폼 값도 전송되지 않습니다.

```blade preview name="time-input-disabled"
<x-time-input label="행사 시간" value="11:45" disabled />
```

## 읽기 전용

`read-only`는 값을 변경할 수 없지만 세그먼트에 포커스할 수 있어 내용을 읽고 복사할 수 있습니다.

```blade preview name="time-input-readonly"
<x-time-input label="확정 시간" value="11:45" read-only />
```

## 라벨 없이 사용

라벨을 생략하면 입력 높이는 기본 `md` 크기인 40px가 됩니다. 접근 가능한 이름은 기본값인 `시간`으로 제공됩니다.

```blade preview name="time-input-without-label"
<x-time-input name="time" value="11:45" />
```

## 설명

`description`은 입력 아래에 시간 선택에 필요한 안내를 표시합니다.

```blade preview name="time-input-description"
<x-time-input
    label="회의 시간"
    description="업무 시간인 09:00부터 18:00 사이로 입력하세요."
/>
```

## 오류 메시지

`invalid`와 `error-message`를 사용하면 입력 배경, 라벨, 세그먼트와 안내 문구가 danger 상태로 바뀝니다.

```blade preview name="time-input-invalid"
<x-time-input
    label="행사 시간"
    value="07:30"
    invalid
    error-message="유효한 시간을 입력해 주세요."
/>
```

## 라벨 위치

`label-placement`는 `inside`, `outside`, `outside-left`, `outside-top`을 지원합니다. 라벨이 있으면 기본값은 `inside`, 라벨이 없으면 `outside`입니다.

```blade preview name="time-input-label-placements"
<x-time-input label="행사 시간" value="11:45" label-placement="inside" />
<x-time-input label="행사 시간" value="11:45" label-placement="outside" />
<x-time-input label="행사 시간" value="11:45" label-placement="outside-left" />
<x-time-input label="행사 시간" value="11:45" label-placement="outside-top" />
```

## 시작과 끝 콘텐츠

`startContent`, `endContent` named slot에 아이콘이나 시간 단위처럼 입력을 보조하는 콘텐츠를 배치합니다.

```blade preview name="time-input-content"
<x-time-input label="출근 시간" value="09:00">
    <x-slot:startContent><x-icon name="solar:clock-circle-linear" /></x-slot:startContent>
</x-time-input>

<x-time-input label="마감 시간" value="18:00" :hour-cycle="24">
    <x-slot:endContent>KST</x-slot:endContent>
</x-time-input>
```

## 형태

`flat`, `bordered`, `faded`, `underlined` 형태를 지원합니다.

```blade preview name="time-input-variants"
<x-time-input label="Flat" value="11:45" variant="flat" />
<x-time-input label="Bordered" value="11:45" variant="bordered" />
<x-time-input label="Faded" value="11:45" variant="faded" />
<x-time-input label="Underlined" value="11:45" variant="underlined" />
```

## 색상

색상은 focused segment와 각 variant의 배경·테두리·라벨에 함께 적용됩니다.

```blade preview name="time-input-colors"
<x-time-input label="Default" value="11:45" color="default" />
<x-time-input label="Primary" value="11:45" color="primary" />
<x-time-input label="Secondary" value="11:45" color="secondary" />
<x-time-input label="Success" value="11:45" color="success" />
<x-time-input label="Warning" value="11:45" color="warning" />
<x-time-input label="Danger" value="11:45" color="danger" />
```

## 크기

`sm`, `md`, `lg`는 각각 라벨, 세그먼트 글자 크기와 입력 높이를 함께 조절합니다.

```blade preview name="time-input-sizes"
<x-time-input label="Small" value="11:45" size="sm" />
<x-time-input label="Medium" value="11:45" size="md" />
<x-time-input label="Large" value="11:45" size="lg" />
```

## 모서리

`radius`는 `none`, `sm`, `md`, `lg`, `full`을 지원합니다. 생략하면 현재 size에 맞는 radius를 사용합니다.

```blade preview name="time-input-radius"
<x-time-input value="11:45" radius="none" />
<x-time-input value="11:45" radius="sm" />
<x-time-input value="11:45" radius="md" />
<x-time-input value="11:45" radius="lg" />
<x-time-input value="11:45" radius="full" />
```

## 표시 단위

`granularity`는 가장 작은 시간 단위를 결정합니다. 기본값은 `minute`이며 `hour`, `minute`, `second`를 지원합니다.

```blade preview name="time-input-granularity"
<x-time-input label="시" value="15" granularity="hour" />
<x-time-input label="분" value="15:45" granularity="minute" />
<x-time-input label="초" value="15:45:22" granularity="second" />
```

## 최소값과 최대값

`min-value`, `max-value` 범위를 벗어난 완성 값은 invalid 상태가 됩니다.

```blade preview name="time-input-bounds"
<x-time-input
    label="예약 시간"
    value="08:00"
    min-value="09:00"
    max-value="18:00"
    error-message="09:00부터 18:00 사이로 입력하세요."
/>
```

## Placeholder 기준값

`placeholder-value`는 빈 세그먼트에 보여줄 기준 시간을 지정합니다. 실제 폼 값은 사용자가 편집하기 전까지 비어 있습니다.

```blade preview name="time-input-placeholder"
<x-time-input label="회의 시간" placeholder-value="09:30" />
```

## 12시간제와 24시간제

기본 hour cycle은 locale에서 결정됩니다. `hour-cycle="12"`는 AM/PM 세그먼트를 표시하고 `hour-cycle="24"`는 00부터 23까지 입력합니다.

```blade preview name="time-input-hour-cycle"
<x-time-input label="12시간제" value="15:45" :hour-cycle="12" locale="en-US" />
<x-time-input label="24시간제" value="15:45" :hour-cycle="24" />
```

## 시간대

`time-zone`을 지정하면 locale에 맞는 시간대 이름을 끝에 표시합니다. `hide-time-zone`으로 화면에서만 숨길 수 있습니다.

```blade preview name="time-input-time-zone"
<x-time-input label="서울" value="15:45+09:00[Asia/Seoul]" time-zone="Asia/Seoul" />
<x-time-input label="서울" value="15:45+09:00[Asia/Seoul]" time-zone="Asia/Seoul" hide-time-zone />
```

## 폼 전송

실제 `input`을 렌더링하므로 별도 연결 코드 없이 `HH:mm` 또는 `HH:mm:ss` 문자열을 전송합니다. `required`, native validation과 form reset도 지원합니다.

```blade preview name="time-input-form"
<form method="post" class="jds-example-stack">
    <x-time-input name="delivery_time" label="배송 시간" required />
    <x-button type="submit" size="sm">전송</x-button>
</form>
```

## 슬롯

| 슬롯 | 용도 |
| --- | --- |
| `base` | 상태와 전체 배치를 관리하는 루트 |
| `label` | 안쪽 또는 바깥쪽 라벨 |
| `input-wrapper` | 라벨과 inner wrapper를 감싸는 시각적 입력 영역 |
| `inner-wrapper` | 시간 세그먼트와 시작·끝 콘텐츠 영역 |
| `input` | 시간 세그먼트 그룹 |
| `segment` | 시, 분, 초, AM/PM, 시간대 단위 |
| `helper-wrapper` | 설명과 오류 메시지 영역 |
| `description`, `error-message` | 안내 문구와 오류 문구 |
| `startContent`, `endContent` | 입력 양쪽의 사용자 콘텐츠 |

## 이벤트와 Controller

값이 변경되면 실제 input에서 native `input`, `change` 이벤트가 발생하고 루트에서는 `app-ui:time-input:change`가 발생합니다.

```js
const timeInput = document.querySelector('#meeting-time')
const controller = AppUI.get(timeInput)

controller.setValue('13:30', true)
controller.getValue()
controller.focus()
controller.clear()
```

Controller는 `getValue()`, `setValue(value, notify)`, `focus()`, `clear()`, `destroy()`를 제공합니다. `focus`, `blur`, `focus-change`, `key-down`, `key-up` 이벤트도 `app-ui:time-input:*` 이름으로 발생합니다.

## API

| 속성 | 타입 | 기본값 |
| --- | --- | --- |
| `name` | string | `null` |
| `value`, `default-value` | `HH:mm[:ss]` | 빈 값 |
| `placeholder-value` | `HH:mm[:ss]` | 빈 값 |
| `variant` | `flat` \| `bordered` \| `faded` \| `underlined` | `flat` |
| `color` | `default` \| `primary` \| `secondary` \| `success` \| `warning` \| `danger` | `default` |
| `size` | `sm` \| `md` \| `lg` | `md` |
| `radius` | `none` \| `sm` \| `md` \| `lg` \| `full` | 현재 size 기준 |
| `label-placement` | `inside` \| `outside` \| `outside-left` \| `outside-top` | 라벨이 있으면 `inside` |
| `granularity` | `hour` \| `minute` \| `second` | `minute` |
| `hour-cycle` | `12` \| `24` | locale 기준 |
| `time-zone` | IANA time zone | `null` |
| `hide-time-zone` | boolean | `false` |
| `min-value`, `max-value` | `HH:mm[:ss]` | `null` |
| `disabled`, `read-only`, `required`, `invalid` | boolean | `false` |
| `auto-focus`, `disable-animation` | boolean | `false` |
| `should-force-leading-zeros` | boolean | `true` |
| `full-width` | boolean | `true` |

## 접근성

각 단위는 독립적인 spinbutton으로 제공됩니다. 숫자 입력, 위·아래 방향키 증감, 좌·우 방향키 이동, Home/End, Delete를 지원합니다. locale에 따라 세그먼트 순서와 AM/PM 문구가 바뀌며, 읽기 전용 세그먼트도 키보드 포커스를 유지합니다.
