## 기본 사용법

`x-radio-group` 안에 `x-radio` 항목을 직접 넣습니다. 그룹의 `name`이 모든 native Radio에 자동으로 연결됩니다.

```blade preview name="radio-group-basic"
<x-radio-group name="city" label="가장 좋아하는 도시를 선택하세요">
    <x-radio value="buenos-aires">Buenos Aires</x-radio>
    <x-radio value="sydney">Sydney</x-radio>
    <x-radio value="san-francisco">San Francisco</x-radio>
    <x-radio value="london">London</x-radio>
    <x-radio value="tokyo">Tokyo</x-radio>
</x-radio-group>
```

## 비활성화

그룹에 `disabled`를 지정하면 모든 항목이 비활성화됩니다. 특정 `x-radio`에만 `disabled`를 지정할 수도 있습니다.

```blade preview name="radio-group-disabled"
<x-radio-group name="disabled-city" label="가장 좋아하는 도시를 선택하세요" default-value="london" disabled>
    <x-radio value="buenos-aires">Buenos Aires</x-radio>
    <x-radio value="sydney">Sydney</x-radio>
    <x-radio value="san-francisco">San Francisco</x-radio>
    <x-radio value="london">London</x-radio>
    <x-radio value="tokyo">Tokyo</x-radio>
</x-radio-group>
```

## 기본 선택값

`default-value`로 처음 선택할 항목을 지정합니다. 각 항목에 `checked`를 직접 지정하는 방법도 지원합니다.

```blade preview name="radio-group-default-value"
<x-radio-group name="default-city" label="가장 좋아하는 도시를 선택하세요" default-value="london">
    <x-radio value="buenos-aires">Buenos Aires</x-radio>
    <x-radio value="sydney">Sydney</x-radio>
    <x-radio value="san-francisco">San Francisco</x-radio>
    <x-radio value="london">London</x-radio>
    <x-radio value="tokyo">Tokyo</x-radio>
</x-radio-group>
```

## 항목 설명

각 `x-radio`의 `description`으로 선택지에 대한 보조 설명을 제공합니다.

```blade preview name="radio-group-descriptions"
<x-radio-group name="capital" label="수도를 선택하세요">
    <x-radio value="buenos-aires" label="Buenos Aires" description="아르헨티나의 수도" />
    <x-radio value="canberra" label="Canberra" description="호주의 수도" />
    <x-radio value="london" label="London" description="영국의 수도" />
    <x-radio value="tokyo" label="Tokyo" description="일본의 수도" />
</x-radio-group>
```

## 가로 배치

`orientation="horizontal"`을 사용하면 항목이 가로로 배치되고 공간이 부족할 때 다음 줄로 넘어갑니다.

```blade preview name="radio-group-horizontal"
<x-radio-group name="contact" label="연락 방법" orientation="horizontal" default-value="email">
    <x-radio value="email">이메일</x-radio>
    <x-radio value="sms">문자 메시지</x-radio>
    <x-radio value="phone">전화</x-radio>
</x-radio-group>
```

## 값 제어

`AppUI.get()`으로 선택값을 읽고 `setValue()`로 바꿀 수 있습니다. 값이 바뀌면 `app-ui:radio-group:change` 이벤트가 발생합니다.

```blade preview name="radio-group-controlled"
<div style="display:grid;gap:1rem">
    <x-radio-group id="controlled-plan" name="controlled-plan" label="요금제를 선택하세요" default-value="pro">
        <x-radio value="free">Free</x-radio>
        <x-radio value="pro">Pro</x-radio>
        <x-radio value="enterprise">Enterprise</x-radio>
    </x-radio-group>
    <div style="display:flex;gap:.5rem">
        <x-button type="button" size="sm" onclick="AppUI.get(document.getElementById('controlled-plan')).setValue('enterprise')">Enterprise 선택</x-button>
        <x-button type="button" size="sm" variant="light" onclick="AppUI.get(document.getElementById('controlled-plan')).setValue('')">선택 해제</x-button>
    </div>
</div>
```

## 오류 상태

`invalid`, `description`, `error-message`로 그룹의 안내와 오류를 표시합니다.

```blade preview name="radio-group-invalid"
<x-radio-group
    name="invalid-plan"
    label="요금제를 선택하세요"
    description="계속하려면 하나를 선택해야 합니다."
    error-message="요금제를 선택해 주세요."
    invalid
>
    <x-radio value="free">Free</x-radio>
    <x-radio value="pro">Pro</x-radio>
    <x-radio value="enterprise">Enterprise</x-radio>
</x-radio-group>
```

## 커스텀 스타일

공개된 Group과 Radio의 `data-slot`을 이용해 카드형 선택 항목처럼 꾸밀 수 있습니다. 선택 상태는 각 Radio 루트의 `data-selected`로 구분합니다.

```blade preview name="radio-group-custom-styles"
<style>
    .plan-radio-group > [data-slot="wrapper"] {
        display: grid;
        gap: .75rem;
    }

    .plan-radio {
        width: min(100%, 28rem);
        max-width: none;
        margin: 0;
        padding: 1rem;
        border: 2px solid hsl(var(--divider));
        border-radius: var(--radius-large);
        background: hsl(var(--content1));
        transition: border-color 150ms ease, background-color 150ms ease;
    }

    .plan-radio:hover { background: hsl(var(--content2)); }
    .plan-radio[data-selected="true"] { border-color: hsl(var(--primary)); }
    .plan-radio [data-slot="label-wrapper"] { flex: 1; }
    .plan-radio [data-slot="label"] { font-weight: 600; }
</style>

<x-radio-group class="plan-radio-group" name="pricing" label="Plans" default-value="pro" description="선택한 요금제는 언제든 변경할 수 있습니다.">
    <x-radio class="plan-radio" value="free" label="Free" description="최대 20개 항목" />
    <x-radio class="plan-radio" value="pro" label="Pro" description="무제한 항목 · 월 10,000원" />
    <x-radio class="plan-radio" value="enterprise" label="Enterprise" description="24시간 지원 · 별도 문의" />
</x-radio-group>
```

## 폼과 유효성

각 항목은 같은 `name`을 가진 실제 Radio input으로 렌더링됩니다. `required`는 그룹에서 반드시 한 항목을 선택하도록 브라우저 기본 유효성 검사를 사용합니다.

```blade preview name="radio-group-form"
<form onsubmit="event.preventDefault()" style="display:grid;gap:1rem">
    <x-radio-group name="delivery" label="배송 방법" required>
        <x-radio value="standard" label="일반 배송" description="2~3영업일" />
        <x-radio value="express" label="빠른 배송" description="다음 영업일" />
        <x-radio value="pickup" label="직접 수령" description="매장에서 수령" />
    </x-radio-group>
    <x-button type="submit" size="sm">주문 계속하기</x-button>
</form>
```

## 슬롯

Radio Group 슬롯:

- `base`: Group 루트 `fieldset`
- `label`: Group의 접근 가능한 이름인 `legend`
- `description`: Group 설명
- `wrapper`: 모든 Radio를 감싸는 영역
- `error-message`: 오류 메시지

Radio 슬롯:

- `base`: Radio 전체 클릭 영역
- `hidden-input`: 실제 native Radio input
- `wrapper`: 원형 선택 표시 영역
- `control`: 선택 시 나타나는 내부 원
- `label-wrapper`: 라벨과 설명 영역
- `label`: 항목 라벨
- `description`: 항목 설명

## 상태 속성

Group 루트에는 `data-orientation`, `data-color`, `data-size`, `data-selected`, `data-value`, `data-required`, `data-readonly`, `data-disabled`, `data-invalid`가 반영됩니다. 각 Radio에는 `data-selected`, `data-hover`, `data-focus`, `data-focus-visible`, `data-pressed`, `data-readonly`, `data-disabled`, `data-invalid`가 반영됩니다.

## 이벤트와 Controller

선택 시 native `input`, `change` 이벤트와 `app-ui:radio:change`, `app-ui:radio-group:change` 이벤트가 발생합니다.

```js
const group = document.querySelector('[data-ui-component="radio-group"]');
const controller = AppUI.get(group);

controller.getValue();
controller.setValue('pro');
controller.focus();
```

## 접근성

Group은 native `fieldset`과 `legend`, 항목은 native `<input type="radio">`를 사용합니다. `Tab`으로 Group에 진입하고 방향키로 항목을 이동·선택할 수 있으며, 폼 자동완성과 브라우저 기본 유효성 검사를 지원합니다.
