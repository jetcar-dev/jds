## 사용법

`Listbox` 안에 `ListboxItem`을 넣습니다. 단순 작업 목록은 선택 상태를 유지하지 않는 `selection-mode="none"`이 기본입니다.

```blade preview name="listbox-basic"
<div class="jds-listbox-frame">
    <x-listbox label="파일 작업">
        <x-listbox-item value="new">새 파일</x-listbox-item>
        <x-listbox-item value="copy">링크 복사</x-listbox-item>
        <x-listbox-item value="edit">파일 편집</x-listbox-item>
        <x-listbox-item value="delete" color="danger">파일 삭제</x-listbox-item>
    </x-listbox>
</div>
```

## 동적 항목

서버나 API에서 받은 데이터는 Blade의 반복문으로 명시적인 항목을 렌더링합니다.

```blade preview name="listbox-dynamic"
@php
    $actions = [
        ['key' => 'new', 'label' => '새 파일'],
        ['key' => 'copy', 'label' => '링크 복사'],
        ['key' => 'edit', 'label' => '파일 편집'],
        ['key' => 'delete', 'label' => '파일 삭제', 'color' => 'danger'],
    ];
@endphp
<div class="jds-listbox-frame">
    <x-listbox label="동적 파일 작업">
        @foreach($actions as $action)
            <x-listbox-item :value="$action['key']" :color="$action['color'] ?? null">
                {{ $action['label'] }}
            </x-listbox-item>
        @endforeach
    </x-listbox>
</div>
```

## 비활성 항목

`disabled-keys`로 여러 항목을 한곳에서 비활성화하거나 개별 항목에 `disabled`를 지정합니다.

```blade preview name="listbox-disabled"
<div class="jds-listbox-frame">
    <x-listbox label="사용 가능한 작업" :disabled-keys="['edit', 'delete']">
        <x-listbox-item value="new">새 파일</x-listbox-item>
        <x-listbox-item value="copy">링크 복사</x-listbox-item>
        <x-listbox-item value="edit">파일 편집</x-listbox-item>
        <x-listbox-item value="delete">파일 삭제</x-listbox-item>
    </x-listbox>
</div>
```

## 형태와 색상

`variant`와 `color`를 바꾸면 항목의 hover·focus 표현이 달라집니다. 아래에서 HeroUI v2와 같은 조합을 바로 비교할 수 있습니다.

```blade preview name="listbox-variants"
<div class="jds-listbox-demo" data-listbox-demo>
    <div class="jds-listbox-frame">
        <x-listbox variant="solid" color="default" label="형태와 색상 미리보기">
            <x-listbox-item value="new">새 파일</x-listbox-item>
            <x-listbox-item value="copy">링크 복사</x-listbox-item>
            <x-listbox-item value="edit">파일 편집</x-listbox-item>
            <x-listbox-item value="delete" color="danger">파일 삭제</x-listbox-item>
        </x-listbox>
    </div>

    <x-radio-group label="ListboxItem 형태 선택" orientation="horizontal">
        @foreach(['solid', 'bordered', 'light', 'flat', 'faded', 'shadow'] as $variant)
            <x-radio
                name="listbox_demo_variant"
                :value="$variant"
                :checked="$variant === 'solid'"
                data-listbox-demo-control="variant"
            >{{ $variant }}</x-radio>
        @endforeach
    </x-radio-group>

    <x-radio-group label="ListboxItem 색상 선택" orientation="horizontal">
        @foreach(['default', 'primary', 'secondary', 'success', 'warning', 'danger'] as $color)
            <x-radio
                name="listbox_demo_color"
                :value="$color"
                :checked="$color === 'default'"
                data-listbox-demo-control="color"
            >{{ $color }}</x-radio>
        @endforeach
    </x-radio-group>
</div>
```

## 단일 선택

`selection-mode="single"`은 하나의 항목만 선택합니다. `value`로 초기 선택값을 지정합니다.

```blade preview name="listbox-single"
<div class="jds-listbox-demo" data-listbox-demo>
    <div class="jds-listbox-frame">
    <x-listbox name="data_type" selection-mode="single" value="text" label="데이터 형식">
        <x-listbox-item value="text">텍스트</x-listbox-item>
        <x-listbox-item value="number">숫자</x-listbox-item>
        <x-listbox-item value="date">날짜</x-listbox-item>
        <x-listbox-item value="iteration">반복</x-listbox-item>
    </x-listbox>
    </div>
    <span class="jds-listbox-selected-value" data-listbox-selected-value>선택한 값: text</span>
</div>
```

## 다중 선택

`selection-mode="multiple"`은 배열 값을 선택합니다. `disallow-empty-selection`을 지정하면 마지막 선택을 해제하지 못합니다.

```blade preview name="listbox-multiple"
<div class="jds-listbox-demo" data-listbox-demo>
    <div class="jds-listbox-frame">
    <x-listbox
        name="permissions"
        selection-mode="multiple"
        :value="['read', 'write']"
        disallow-empty-selection
        label="권한"
    >
        <x-listbox-item value="read">조회</x-listbox-item>
        <x-listbox-item value="write">수정</x-listbox-item>
        <x-listbox-item value="download">다운로드</x-listbox-item>
        <x-listbox-item value="delete">삭제</x-listbox-item>
    </x-listbox>
    </div>
    <span class="jds-listbox-selected-value" data-listbox-selected-value>선택한 값: read, write</span>
</div>
```

## 위와 아래 콘텐츠

`topContent`와 `bottomContent` slot은 목록의 위아래에 고정 콘텐츠를 배치합니다.

```blade preview name="listbox-content"
<div class="jds-listbox-frame">
    <x-listbox selection-mode="single" value="kim" label="담당자 선택">
        <x-slot:topContent><strong style="display:block;padding:.5rem">담당자</strong></x-slot:topContent>
        <x-listbox-item value="kim" description="kim@jetcar.com">김제트</x-listbox-item>
        <x-listbox-item value="lee" description="lee@jetcar.com">이자동</x-listbox-item>
        <x-listbox-item value="park" description="park@jetcar.com">박모터</x-listbox-item>
        <x-slot:bottomContent><small style="display:block;padding:.5rem;color:hsl(var(--default-500))">3명의 담당자</small></x-slot:bottomContent>
    </x-listbox>
</div>
```

## 섹션

`ListboxSection`으로 항목을 묶습니다. 제목이 없는 섹션에는 `label`을 제공해야 합니다.

## 링크 항목

`href`를 지정한 항목은 링크로 렌더링됩니다.

```blade preview name="listbox-links"
<div class="jds-listbox-frame">
    <x-listbox label="문서 이동">
        <x-listbox-item value="input" href="/components/input">Input</x-listbox-item>
        <x-listbox-item value="select" href="/components/select">Select</x-listbox-item>
        <x-listbox-item value="textarea" href="/components/textarea">Textarea</x-listbox-item>
    </x-listbox>
</div>
```

## 빈 목록

항목이 없으면 `empty-content`가 표시됩니다. `hide-empty-content`로 숨길 수 있습니다.

```blade preview name="listbox-empty"
<div class="jds-listbox-frame">
    <x-listbox label="검색 결과" empty-content="검색 결과가 없습니다." />
</div>
```

## 많은 항목과 스크롤

항목이 많으면 `max-listbox-height` 안에서 목록만 세로로 스크롤됩니다. 각 항목의 보조 설명까지 유지한 상태로 스크롤 동작을 확인할 수 있습니다.

```blade preview name="listbox-scroll"
@php
    $members = collect(range(1, 30))->map(fn ($number) => [
        'id' => "member-{$number}",
        'name' => "담당자 {$number}",
        'email' => "member{$number}@jetcar.com",
    ]);
@endphp

<div class="jds-listbox-frame">
    <x-listbox
        label="담당자 목록"
        selection-mode="single"
        max-listbox-height="240"
    >
        @foreach($members as $member)
            <x-listbox-item :value="$member['id']" :description="$member['email']">
                {{ $member['name'] }}
            </x-listbox-item>
        @endforeach
    </x-listbox>
</div>
```

## 폼 전송과 Controller

선택값은 실제 hidden input으로 제출됩니다. 값 변경 시 native `input/change`와 `app-ui:listbox:change`, 항목 실행 시 `app-ui:listbox:action` 이벤트가 발생합니다.

```blade preview name="listbox-form"
<form method="post" class="jds-example-stack" style="width:min(100%,16.25rem)">
    <div class="jds-listbox-frame">
        <x-listbox name="status" selection-mode="single" value="ready" label="처리 상태">
            <x-listbox-item value="ready">준비</x-listbox-item>
            <x-listbox-item value="working">처리 중</x-listbox-item>
            <x-listbox-item value="done">완료</x-listbox-item>
        </x-listbox>
    </div>
    <x-button type="submit">저장</x-button>
</form>
```

```js
const listbox = document.querySelector('[data-ui-component="listbox"]');
const controller = AppUI.get(listbox);

controller.getValue();
controller.setValue('done');
controller.focus();
```

## 슬롯

- Listbox: `base`, `top-content`, `list`, `empty-content`, `bottom-content`
- ListboxItem: `listbox-item`, `start-content`, `wrapper`, `title`, `description`, `shortcut`, `selected-icon`, `end-content`
- ListboxSection: `section`, `heading`, `group`

## 접근성

실제 `listbox`와 `option` 역할을 사용합니다. 방향키, Home, End, Enter, Space와 문자 검색을 지원하며 비활성 항목은 탐색에서 제외됩니다.
