## 사용법

`length`만 지정하면 숫자만 입력할 수 있는 OTP 필드가 만들어집니다. 기본 길이는 4자리이며 실제 `<input>` 하나를 렌더링하므로 자동 완성, 붙여넣기, 폼 전송을 그대로 사용할 수 있습니다.

```blade preview name="input-otp-basic"
<div id="otp-basic-example">
    <x-input-otp name="verification_code" aria-label="인증번호" />
    <p style="margin:.25rem 0 0;color:hsl(var(--default-500));font-size:.75rem">OTP 값: <output data-otp-output></output></p>
</div>
<script>
    document.querySelector('#otp-basic-example [data-slot="input"]')?.addEventListener('input', event => {
        document.querySelector('#otp-basic-example [data-otp-output]').textContent = event.target.value
    })
</script>
```

## 비활성화

`disabled`를 지정하면 입력과 포커스를 막고 폼 전송에서도 제외합니다.

```blade preview name="input-otp-disabled"
<x-input-otp name="verification_code" value="1234" disabled aria-label="비활성화된 인증번호" />
```

## 읽기 전용

`read-only`는 값을 수정하지 못하게 하지만 현재 값과 외형, 폼 전송은 유지합니다.

```blade preview name="input-otp-readonly"
<x-input-otp name="verification_code" value="1234" read-only aria-label="읽기 전용 인증번호" />
```

## 필수 입력

`required`는 실제 input에 native 필수 검증과 `aria-required`를 적용합니다. 제출할 때 값이 비어 있으면 오류 상태로 전환됩니다.

```blade preview name="input-otp-required"
<x-form method="post" class="jds-example-stack">
    <x-input-otp name="verification_code" required error-message="인증번호를 입력하세요." aria-label="필수 인증번호" />
    <x-button type="submit" size="sm">제출</x-button>
</x-form>
```

## 크기

`size`는 `sm`, `md`, `lg`를 지원하며 기본값은 `md`입니다. 각 칸은 각각 32px, 40px, 48px입니다.

```blade preview name="input-otp-sizes"
<div class="jds-example-stack">
    <div><div style="margin-bottom:.375rem;font-size:.875rem">size: sm</div><x-input-otp size="sm" aria-label="작은 인증번호" /></div>
    <div><div style="margin-bottom:.375rem;font-size:.875rem">size: md</div><x-input-otp size="md" aria-label="중간 인증번호" /></div>
    <div><div style="margin-bottom:.375rem;font-size:.875rem">size: lg</div><x-input-otp size="lg" aria-label="큰 인증번호" /></div>
</div>
```

## 색상

`color`는 `default`, `primary`, `secondary`, `success`, `warning`, `danger`를 지원합니다. 색상은 입력값, 활성 칸, 커서와 형태별 배경·테두리에 함께 적용됩니다.

```blade preview name="input-otp-colors"
<div style="display:grid;grid-template-columns:repeat(auto-fit,minmax(11rem,1fr));gap:1rem;width:100%">
    @foreach(['default', 'primary', 'secondary', 'success', 'warning', 'danger'] as $color)
        <div><div style="margin-bottom:.375rem;font-size:.875rem">color: {{ $color }}</div><x-input-otp :color="$color" :aria-label="$color.' 인증번호'" /></div>
    @endforeach
</div>
```

## 형태

`variant`는 `flat`, `bordered`, `faded`, `underlined`를 지원하며 기본값은 `flat`입니다.

```blade preview name="input-otp-variants"

```

## 모서리

`radius`는 `none`, `sm`, `md`, `lg`, `full`을 지원하며 기본값은 `md`입니다.

```blade preview name="input-otp-radius"

        <div><div style="margin-bottom:.375rem;font-size:.875rem">radius: {{ $radius }}</div><x-input-otp :radius="$radius" :aria-label="$radius.' 모서리 인증번호'" /></div>
    @endforeach
```

## 비밀번호

`type="password"`를 지정하면 입력값 대신 점을 표시합니다. 실제 값은 폼과 Controller에서 그대로 사용할 수 있습니다.

```blade preview name="input-otp-password"
<x-input-otp name="pin" type="password" variant="bordered" radius="full" size="sm" aria-label="보안 PIN" />
```

## 설명

`description`은 입력 아래에 보조 안내를 표시합니다.

```blade preview name="input-otp-description"
<x-input-otp description="인증번호는 10분 동안 유효합니다." aria-label="안내가 있는 인증번호" />
```

## 오류 문구

`invalid`와 `error-message`를 함께 지정하면 모든 칸과 안내 문구에 danger 상태가 적용됩니다.

```blade preview name="input-otp-error"
<x-input-otp invalid error-message="인증번호가 올바르지 않습니다." aria-label="오류가 있는 인증번호" />
```

## 입력 가능한 문자

기본 `allowed-keys`는 `^[0-9]*$`입니다. 정규식 문자열을 바꾸면 영문이나 다른 문자를 허용할 수 있으며 일치하지 않는 키와 붙여넣기 문자는 자동으로 제외합니다.

```blade preview name="input-otp-allowed-keys"
<div style="display:flex;flex-wrap:wrap;gap:2rem">
    <div><div style="margin-bottom:.375rem;font-size:.875rem">영문 소문자만 (a-z)</div><x-input-otp allowed-keys="^[a-z]*$" aria-label="영문 소문자 코드" /></div>
    <div><div style="margin-bottom:.375rem;font-size:.875rem">영문 대문자만 (A-Z)</div><x-input-otp allowed-keys="^[A-Z]*$" aria-label="영문 대문자 코드" /></div>
</div>
```

## 값 제어

Controller의 `setValue()`를 사용하면 Blade 렌더링 이후에도 값을 변경할 수 있습니다.

```blade preview name="input-otp-controlled"
<div id="otp-controlled-example">
    <x-input-otp aria-label="제어되는 인증번호" />
    <p style="margin:.25rem 0 0;color:hsl(var(--default-500));font-size:.75rem">값: <output data-value></output></p>
    <x-button size="sm" variant="light" data-fill style="margin-top:.5rem">1234 입력</x-button>
</div>
<script>
    document.querySelector('#otp-controlled-example [data-fill]')?.addEventListener('click', () => {
        const root = document.querySelector('#otp-controlled-example [data-ui-component="input-otp"]')
        AppUI.get(root)?.setValue('1234')
        document.querySelector('#otp-controlled-example [data-value]').textContent = AppUI.get(root)?.getValue()
    })
</script>
```

## 폼 전송과 유효성

실제 input에 `name`, `required`, `autocomplete="one-time-code"`가 적용됩니다. 필수값이 비어 있으면 오류 상태를 표시하고 입력 필드로 포커스를 이동합니다.

```blade preview name="input-otp-form"
<x-form method="post" class="jds-example-stack">
    <x-input-otp name="verification_code" length="6" required error-message="인증번호를 입력하세요." aria-label="인증번호" />
    <x-button type="submit" size="sm">확인</x-button>
</x-form>
```

## 이벤트와 Controller

- native `input`, `change`: 실제 input 값이 변경될 때 발생
- `app-ui:input-otp:change`: 변경된 `event.detail.value` 제공
- `app-ui:input-otp:complete`: 모든 칸이 채워졌을 때 한 번 발생
- `app-ui:input-otp:paste`: 붙여넣기 직전에 발생하며 `event.detail.text`를 변경하면 붙여넣을 값을 변환

`AppUI.get(element)`은 `getValue()`, `setValue(value)`, `clear()`, `focus()`, `destroy()`를 제공합니다.

```blade preview name="input-otp-controller"
<div id="otp-controller-example" class="jds-example-stack">
    <x-input-otp length="6" aria-label="Controller 인증번호" />
    <div style="display:flex;gap:.5rem">
        <x-button size="sm" data-otp-fill>123456 입력</x-button>
        <x-button size="sm" variant="light" data-otp-clear>지우기</x-button>
    </div>
</div>
<script>
    document.querySelector('[data-otp-fill]')?.addEventListener('click', () => {
        const root = document.querySelector('#otp-controller-example [data-ui-component="input-otp"]')
        AppUI.get(root)?.setValue('123456')
    })
    document.querySelector('[data-otp-clear]')?.addEventListener('click', () => {
        const root = document.querySelector('#otp-controller-example [data-ui-component="input-otp"]')
        AppUI.get(root)?.clear()
    })
</script>
```

## 슬롯

- `base`: 전체 컴포넌트
- `wrapper`: 실제 input과 칸 묶음
- `input`: 폼에 전송되는 실제 input
- `segment-wrapper`: 모든 입력 칸 묶음
- `segment`: 개별 입력 칸
- `segment-value`: 입력 문자 표시 영역
- `caret`: 현재 입력 위치
- `password-char`: 비밀번호 점
- `helper-wrapper`: 설명과 오류 문구 묶음
- `description`: 설명 문구
- `error-message`: 오류 문구

## 상태 속성

루트에는 `data-filled`, `data-disabled`, `data-readonly`, `data-required`, `data-invalid`가 반영됩니다. 각 `segment`에는 `data-active`, `data-focus`, `data-focus-visible`, `data-has-value`가 반영됩니다.

## 접근성

하나의 실제 input을 사용해 모바일 OTP 자동 완성, 스크린 리더, 붙여넣기를 안정적으로 지원합니다. 방향키와 Home/End로 입력 위치를 옮기고 Backspace/Delete로 값을 수정할 수 있습니다. `aria-label`로 필드의 목적을 명확히 지정하세요.

## API

| 속성 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `length` | `number` | `4` | 입력 칸 수 |
| `allowed-keys` | `string` | `^[0-9]*$` | 허용 문자 정규식 |
| `variant` | `flat \| bordered \| faded \| underlined` | `flat` | 입력 칸 형태 |
| `color` | `default \| primary \| secondary \| success \| warning \| danger` | `default` | 의미 색상 |
| `size` | `sm \| md \| lg` | `md` | 입력 칸 크기 |
| `radius` | `none \| sm \| md \| lg \| full` | `md` | 입력 칸 모서리 |
| `type` | `text \| password` | `text` | 값 표시 방식 |
| `value` | `string` | 빈 문자열 | 초기값 |
| `placeholder` | `string` | 빈 문자열 | 칸별로 표시할 자리표시 문자 |
| `description` | `string` | - | 안내 문구 |
| `error-message` | `string` | - | 오류 문구 |
| `full-width` | `boolean` | `false` | 루트 너비 확장 |
| `text-align` | `left \| center \| right` | `center` | full-width 내부 정렬 |
| `required` | `boolean` | `false` | 필수 입력 |
| `read-only` | `boolean` | `false` | 읽기 전용 |
| `disabled` | `boolean` | `false` | 비활성화 |
| `invalid` | `boolean` | `false` | 오류 상태 |
| `auto-focus` | `boolean` | `false` | 초기 자동 포커스 |
| `disable-animation` | `boolean` | `false` | 전환 효과 비활성화 |
| `push-password-manager-strategy` | `increase-width \| none` | `increase-width` | 비밀번호 관리자 배지가 마지막 칸을 가리지 않도록 처리 |
