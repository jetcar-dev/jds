`Pagination`은 전체 페이지 중 현재 위치를 표시하고 원하는 페이지로 이동할 때 사용합니다. 페이지 수가 많으면 중간 항목을 자동으로 접고, 점 버튼으로 여러 페이지를 한 번에 건너뜁니다.

## 사용법

기본값은 `flat`, `primary`, `md`이며 이동 버튼은 표시하지 않습니다.

```blade preview name="pagination-basic"
<div style="display:flex;align-items:center;padding:1.5rem .75rem">
    <x-pagination :total="10" />
</div>
```

### 비활성

`disabled`를 지정하면 전체 페이지네이션이 흐려지고 모든 조작을 막습니다.

```blade preview name="pagination-disabled"
<div style="display:flex;align-items:center;padding:1.5rem .75rem">
    <x-pagination :total="10" disabled />
</div>
```

### 크기

`sm`은 32px, `md`는 36px, `lg`는 40px 높이로 렌더링됩니다.

```blade preview name="pagination-sizes"
<div style="display:flex;flex-direction:column;align-items:flex-start;gap:1rem;padding:1.5rem .75rem">
    <x-pagination size="sm" :total="10" />
    <x-pagination size="md" :total="10" />
    <x-pagination size="lg" :total="10" />
</div>
```

### 색상

색상은 움직이는 현재 페이지 표시와 선택 상태에 적용됩니다.

```blade preview name="pagination-colors"
<div style="display:flex;flex-direction:column;align-items:flex-start;gap:.875rem;padding:1.5rem .75rem">
    <x-pagination color="default" :total="10" />
    <x-pagination color="primary" :total="10" />
    <x-pagination color="secondary" :total="10" />
    <x-pagination color="success" :total="10" />
    <x-pagination color="warning" :total="10" />
    <x-pagination color="danger" :total="10" />
</div>
```

### 형태

`flat`, `bordered`, `faded`, `light` 네 가지 형태를 제공합니다. 형태별 배경, 테두리, hover와 pressed 효과도 HeroUI v2 기준으로 달라집니다.

```blade preview name="pagination-variants"
<div style="display:flex;flex-direction:column;align-items:flex-start;gap:1rem;padding:1.5rem .75rem">
    <x-pagination variant="flat" :total="10" />
    <x-pagination variant="bordered" :total="10" />
    <x-pagination variant="faded" :total="10" />
    <x-pagination variant="light" :total="10" />
</div>
```

### 이동 버튼

`show-controls`를 지정하면 이전·다음 버튼을 표시합니다. 첫 페이지와 마지막 페이지에서는 이동할 수 없는 버튼이 비활성화됩니다.

```blade preview name="pagination-controls"
<div style="display:flex;align-items:center;padding:1.5rem .75rem">
    <x-pagination :total="10" show-controls />
</div>
```

### 반복 이동

`loop`를 함께 사용하면 첫 페이지의 이전 버튼은 마지막 페이지로, 마지막 페이지의 다음 버튼은 첫 페이지로 이동합니다.

```blade preview name="pagination-loop"
<div style="display:flex;align-items:center;padding:1.5rem .75rem">
    <x-pagination color="success" :total="5" :page="5" show-controls loop />
</div>
```

### 초기 페이지

`initial-page`는 처음 표시할 페이지를 지정합니다. `page`가 있으면 `page` 값이 우선합니다.

```blade preview name="pagination-initial-page"
<div style="display:flex;align-items:center;padding:1.5rem .75rem">
    <x-pagination color="warning" :total="10" :initial-page="6" />
</div>
```

### 간결한 페이지네이션

`compact`는 항목 사이 간격을 없애 하나의 컨트롤처럼 연결합니다.

```blade preview name="pagination-compact"
<div style="display:flex;align-items:center;padding:1.5rem .75rem">
    <x-pagination :total="10" show-controls compact />
</div>
```

### 그림자

`show-shadow`는 현재 페이지 표시 아래에 선택한 색상의 그림자를 추가합니다.

```blade preview name="pagination-shadow"
<div style="display:flex;align-items:center;padding:1.5rem .75rem">
    <x-pagination color="warning" :total="10" :page="3" show-shadow />
</div>
```

### 모서리

```blade preview name="pagination-radius"
<div style="display:flex;flex-direction:column;align-items:flex-start;gap:1rem;padding:1.5rem .75rem">
    <x-pagination radius="none" :total="6" />
    <x-pagination radius="sm" :total="6" />
    <x-pagination radius="md" :total="6" />
    <x-pagination radius="lg" :total="6" />
    <x-pagination radius="full" :total="6" />
</div>
```

### 인접 페이지 수

`siblings`는 현재 페이지 양옆에 유지할 항목 수입니다. 값이 커질수록 현재 페이지 주변을 더 많이 보여줍니다.

```blade preview name="pagination-siblings"
<div style="display:flex;flex-direction:column;align-items:flex-start;gap:1rem;padding:1.5rem .75rem">
    <x-pagination :total="20" :page="10" :siblings="0" />
    <x-pagination :total="20" :page="10" :siblings="1" />
    <x-pagination :total="20" :page="10" :siblings="2" />
</div>
```

### 시작·끝 페이지 수

`boundaries`는 전체 목록의 시작과 끝에 항상 보여줄 페이지 수입니다.

```blade preview name="pagination-boundaries"
<div style="display:flex;flex-direction:column;align-items:flex-start;gap:1rem;padding:1.5rem .75rem">
    <x-pagination color="secondary" :total="20" :page="10" :boundaries="0" />
    <x-pagination color="secondary" :total="20" :page="10" :boundaries="1" />
    <x-pagination color="secondary" :total="20" :page="10" :boundaries="2" />
</div>
```

### 폼 전송

`name`을 지정하면 현재 페이지를 담은 hidden input이 렌더링됩니다. 클릭으로 값이 바뀔 때 native `input`, `change` 이벤트도 발생합니다.

```blade preview name="pagination-form"
<form style="display:flex;flex-direction:column;align-items:flex-start;gap:1rem;padding:1.5rem .75rem">
    <x-pagination name="page" :total="10" :page="3" show-controls />
    <x-button type="submit" size="sm">현재 페이지 전송</x-button>
</form>
```

## 슬롯

| slot | 설명 |
| --- | --- |
| `base` | 스크롤 가능한 루트 `nav` |
| `wrapper` | 모든 항목과 cursor를 배치하는 목록 |
| `item` | 페이지 번호와 점프 항목 |
| `cursor` | 현재 페이지 위를 이동하는 색상 레이어 |
| `prev` | 이전 페이지 버튼 |
| `next` | 다음 페이지 버튼 |
| `ellipsis` | 점프 버튼의 기본 점 아이콘 |
| `forward-icon` | hover·focus 시 나타나는 빠른 이동 아이콘 |

### 사용자 정의 스타일

각 파트의 `data-slot`과 루트 상태 속성을 사용하면 구조를 바꾸지 않고 스타일을 덮어쓸 수 있습니다.

```css
.my-pagination [data-slot="wrapper"] {
    gap: 0;
    border: 1px solid hsl(var(--divider));
}

.my-pagination [data-slot="item"] {
    border-radius: 0;
    box-shadow: none;
}
```

## 이벤트와 Controller

페이지가 바뀌면 `app-ui:pagination:change` 이벤트의 `detail.page`로 현재 페이지를 전달합니다. `AppUI.get(element)`는 `getValue()`, `setValue(page, notify)`, `focus()`, `destroy()`를 제공합니다.

```js
const pagination = document.querySelector('#orders-pagination')
const controller = AppUI.get(pagination)

controller.setValue(7, true)
console.log(controller.getValue())
```

## 접근성

- 루트는 이름이 있는 `navigation` 영역으로 렌더링됩니다.
- 현재 항목에는 `aria-current="page"`가 적용됩니다.
- 이전·다음 버튼의 비활성 상태는 `aria-disabled`로 전달됩니다.
- Enter, Space, 좌우 방향키, Home, End로 조작할 수 있습니다.
- 점 버튼에 focus하거나 hover하면 이동 방향 아이콘으로 바뀝니다.
- `prefers-reduced-motion`에서는 cursor와 pressed 전환을 중지합니다.
