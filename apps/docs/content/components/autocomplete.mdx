## 기본 사용법

`x-autocomplete-item`을 기본 슬롯에 넣습니다. 사용자가 보는 문구와 서버로 전송할 `value`를 분리할 수 있습니다.

```blade preview name="autocomplete-basic"
<div style="width:min(100%,20rem)">
    <x-autocomplete name="animal" label="좋아하는 동물">
        <x-autocomplete-item value="cat">고양이</x-autocomplete-item>
        <x-autocomplete-item value="dog">강아지</x-autocomplete-item>
        <x-autocomplete-item value="elephant">코끼리</x-autocomplete-item>
        <x-autocomplete-item value="lion">사자</x-autocomplete-item>
        <x-autocomplete-item value="tiger">호랑이</x-autocomplete-item>
    </x-autocomplete>
</div>
```

### 동적으로 만들기

서버나 API에서 받은 배열은 Blade 반복문으로 렌더링합니다. 실행 중 항목 DOM이 추가되거나 제거되어도 자동으로 다시 필터링됩니다.

```blade preview name="autocomplete-dynamic"
@php
    $cities = [
        ['id' => 'seoul', 'name' => '서울'],
        ['id' => 'busan', 'name' => '부산'],
        ['id' => 'incheon', 'name' => '인천'],
        ['id' => 'daegu', 'name' => '대구'],
    ];
@endphp

<div style="width:min(100%,20rem)">
    <x-autocomplete name="city" label="도시 선택" placeholder="도시를 검색하세요">
        @foreach($cities as $city)
            <x-autocomplete-item :value="$city['id']">{{ $city['name'] }}</x-autocomplete-item>
        @endforeach
    </x-autocomplete>
</div>
```

### 비활성화

`disabled`를 지정하면 입력과 선택 버튼을 모두 사용할 수 없습니다.

```blade preview name="autocomplete-disabled"
<div style="width:min(100%,20rem)">
    <x-autocomplete name="animal" value="cat" label="좋아하는 동물" disabled>
        <x-autocomplete-item value="cat">고양이</x-autocomplete-item>
        <x-autocomplete-item value="dog">강아지</x-autocomplete-item>
    </x-autocomplete>
</div>
```

### 특정 항목 비활성화

항목에 `disabled`를 지정하거나 루트의 `disabled-keys`에 여러 값을 전달합니다. 검색 결과에는 표시되지만 선택할 수 없습니다.

```blade preview name="autocomplete-disabled-items"
<div style="width:min(100%,20rem)">
    <x-autocomplete name="animal" label="좋아하는 동물" :disabled-keys="['dog']">
        <x-autocomplete-item value="cat">고양이</x-autocomplete-item>
        <x-autocomplete-item value="dog">강아지</x-autocomplete-item>
        <x-autocomplete-item value="lion" disabled>사자</x-autocomplete-item>
        <x-autocomplete-item value="tiger">호랑이</x-autocomplete-item>
    </x-autocomplete>
</div>
```

### 필수 입력

`required`는 라벨에 필수 표시를 추가하고 브라우저의 폼 검증에도 반영됩니다.

```blade preview name="autocomplete-required"
<div style="width:min(100%,20rem)">
    <x-autocomplete name="animal" label="좋아하는 동물" required>
        <x-autocomplete-item value="cat">고양이</x-autocomplete-item>
        <x-autocomplete-item value="dog">강아지</x-autocomplete-item>
    </x-autocomplete>
</div>
```

### 읽기 전용

`read-only`에서는 현재 값을 확인하고 목록을 열 수 있지만 다른 항목을 선택할 수 없습니다.

```blade preview name="autocomplete-readonly"
<div style="width:min(100%,20rem)">
    <x-autocomplete name="animal" value="cat" label="좋아하는 동물" read-only>
        <x-autocomplete-item value="cat">고양이</x-autocomplete-item>
        <x-autocomplete-item value="dog">강아지</x-autocomplete-item>
    </x-autocomplete>
</div>
```

### 크기

`size`는 `sm`, `md`, `lg`를 지원하며 기본값은 `md`입니다.

```blade preview name="autocomplete-sizes"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    @foreach(['sm', 'md', 'lg'] as $size)
        <x-autocomplete :size="$size" :label="strtoupper($size).' 크기'">
            <x-autocomplete-item value="cat">고양이</x-autocomplete-item>
            <x-autocomplete-item value="dog">강아지</x-autocomplete-item>
        </x-autocomplete>
    @endforeach
</div>
```

### 색상

### 입력 영역 콘텐츠

`startContent`, `endContent` named slot으로 입력 영역 앞뒤에 아이콘이나 보조 정보를 넣습니다.

```blade preview name="autocomplete-content"
<div style="width:min(100%,20rem)">
    <x-autocomplete name="country" label="국가 선택" value="kr">
        <x-slot:startContent><x-icon name="solar:map-point-linear" style="width:1.25rem;height:1.25rem" /></x-slot:startContent>
        <x-slot:endContent><x-code>국가</x-code></x-slot:endContent>
        <x-autocomplete-item value="kr">대한민국</x-autocomplete-item>
        <x-autocomplete-item value="jp">일본</x-autocomplete-item>
        <x-autocomplete-item value="us">미국</x-autocomplete-item>
    </x-autocomplete>
</div>
```

### 사용자 입력값 허용

기본적으로 목록에 없는 문구는 포커스를 잃을 때 선택값으로 남지 않습니다. `allows-custom-value`를 지정하면 사용자가 입력한 문구 자체를 폼 값으로 사용합니다.

```blade preview name="autocomplete-custom-value"
<div style="width:min(100%,20rem)">
    <x-autocomplete name="keyword" label="동물 검색" allows-custom-value>
        <x-autocomplete-item value="cat">고양이</x-autocomplete-item>
        <x-autocomplete-item value="dog">강아지</x-autocomplete-item>
    </x-autocomplete>
</div>
```

### 선택 아이콘 변경

`selectorIcon` named slot으로 목록 버튼의 아이콘을 바꿀 수 있습니다. `disable-selector-icon-rotation`을 지정하면 열림 상태에서도 회전하지 않습니다.

```blade preview name="autocomplete-selector-icon"
<div style="width:min(100%,20rem)">
    <x-autocomplete name="animal" label="좋아하는 동물" disable-selector-icon-rotation>
        <x-slot:selectorIcon><x-icon name="solar:magnifer-linear" /></x-slot:selectorIcon>
        <x-autocomplete-item value="cat">고양이</x-autocomplete-item>
        <x-autocomplete-item value="dog">강아지</x-autocomplete-item>
    </x-autocomplete>
</div>
```

### 많은 항목

항목이 50개를 넘으면 화면 밖 항목의 렌더링 비용을 자동으로 줄입니다. `virtualized`로 항상 활성화하고 `max-listbox-height`, `item-height`로 목록 크기를 조정할 수도 있습니다.

```blade preview name="autocomplete-virtualized"
<div style="width:min(100%,20rem)">
    <x-autocomplete name="number" label="100개 항목 검색" virtualized :max-listbox-height="224" :item-height="32">
        @for($number = 1; $number <= 100; $number++)
            <x-autocomplete-item :value="(string) $number">항목 {{ $number }}</x-autocomplete-item>
        @endfor
    </x-autocomplete>
</div>
```

### Controller로 제어하기

초기 선택값은 `value`로 지정하고 실행 중에는 `AppUI.get()`으로 변경합니다.

```blade preview name="autocomplete-controlled"
<div class="jds-example-stack" style="width:min(100%,20rem)">
    <x-autocomplete id="controlled-autocomplete" name="animal" value="cat" label="좋아하는 동물">
        <x-autocomplete-item value="cat">고양이</x-autocomplete-item>
        <x-autocomplete-item value="dog">강아지</x-autocomplete-item>
        <x-autocomplete-item value="tiger">호랑이</x-autocomplete-item>
    </x-autocomplete>
    <div class="jds-example-row">
        <x-button size="sm" variant="bordered" onclick="AppUI.get(document.querySelector('#controlled-autocomplete')).setValue('tiger')">호랑이 선택</x-button>
        <x-button size="sm" variant="light" onclick="AppUI.get(document.querySelector('#controlled-autocomplete')).clear()">지우기</x-button>
    </div>
</div>
```

### 폼 전송

`name`에는 선택한 항목의 `value`가 전송됩니다. 화면에 보이는 검색 문구와 서버로 제출되는 값은 별도로 관리됩니다.


## 슬롯

- `base`: 입력과 팝오버를 포함하는 루트
- `label`: 입력 라벨
- `input-wrapper`: 입력 필드 배경과 테두리
- `inner-wrapper`: 라벨과 실제 입력을 감싸는 영역
- `input`: 실제 검색 입력
- `endContentWrapper`: 사용자 콘텐츠, 지우기 버튼과 선택 버튼 영역
- `clearButton`: 입력값 지우기 버튼
- `selectorButton`: 추천 목록 열기 버튼
- `popoverContent`: 화면 위에 표시되는 추천 목록
- `listboxWrapper`: 스크롤 가능한 목록 외부 영역
- `listbox`: 선택 항목 목록
- `emptyContent`: 검색 결과가 없을 때 표시되는 문구

`x-autocomplete-item`은 `startContent`, `endContent` named slot과 `description` 속성을 지원합니다.

## 상태 속성

루트에는 `data-open`, `data-invalid`, `data-disabled`, `data-readonly`, `data-filled`가 반영됩니다. 항목에는 `data-disabled`, `data-selected`, `data-hover`, `data-pressed`, `data-focus`, `data-focus-visible`가 반영됩니다.

## 이벤트와 Controller

- `app-ui:autocomplete:change`: 선택값 변경, `event.detail.value`와 `event.detail.label` 제공
- `app-ui:autocomplete:input-change`: 검색 문구 변경, `event.detail.inputValue` 제공
- `app-ui:autocomplete:clear`: 지우기 버튼 실행
- native `input`, `change`: 폼에 제출되는 hidden input에서 발생

Controller는 `getValue()`, `getInputValue()`, `setValue(value)`, `setInputValue(value)`, `clear()`, `open()`, `close()`, `focus()`, `destroy()`를 제공합니다.

## 접근성

입력은 `role="combobox"`, 목록은 `role="listbox"`, 항목은 `role="option"`으로 연결됩니다. 입력 초점을 유지한 채 `aria-activedescendant`로 활성 항목을 알립니다. 위·아래 방향키와 Home/End로 이동하고 Enter로 선택하며 Escape로 목록을 닫습니다. 라벨, 설명, 오류 문구와 required/invalid 상태도 해당 ARIA 속성에 자동 연결됩니다.
