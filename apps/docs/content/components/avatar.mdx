## 기본 사용법

`src`에 이미지 주소를 전달합니다. `name`은 이미지 대체 텍스트와 fallback 이름으로 사용됩니다.

```blade preview name="avatar-basic"
<div class="jds-example-row">
    <x-avatar src="https://i.pravatar.cc/150?u=jds-avatar-1" name="김민준" />
    <x-avatar src="https://i.pravatar.cc/150?u=jds-avatar-2" name="이서연" />
    <x-avatar src="https://i.pravatar.cc/150?u=jds-avatar-3" name="박지훈" />
</div>
```

## 크기

`size`는 `sm`, `md`, `lg`를 지원하며 각각 32px, 40px, 56px입니다.

```blade preview name="avatar-sizes"
<div class="jds-example-row" style="align-items:center">
    <x-avatar size="sm" src="https://i.pravatar.cc/150?u=jds-size-1" name="Small" />
    <x-avatar size="md" src="https://i.pravatar.cc/150?u=jds-size-2" name="Medium" />
    <x-avatar size="lg" src="https://i.pravatar.cc/150?u=jds-size-3" name="Large" />
</div>
```

## 비활성화

`disabled`를 사용하면 투명도가 낮아지고 상호작용이 비활성화됩니다.

```blade preview name="avatar-disabled"
<div class="jds-example-row">
    <x-avatar disabled src="https://i.pravatar.cc/150?u=jds-disabled-1" name="김민준" />

```

```blade preview name="avatar-bordered"
    <x-avatar bordered src="https://i.pravatar.cc/150?u=jds-bordered-1" name="Default" />
    <x-avatar bordered color="primary" src="https://i.pravatar.cc/150?u=jds-bordered-2" name="Primary" />

    <x-avatar bordered color="danger" src="https://i.pravatar.cc/150?u=jds-bordered-4" name="Danger" />
</div>
```

## 이미지 fallback

이미지 주소가 없으면 `name`의 첫 글자가 표시됩니다. 이미지 로드 실패 시에도 fallback을 표시하려면 `show-fallback`을 사용합니다.

```blade preview name="avatar-fallbacks"
<div class="jds-example-row">
    <x-avatar name="김민준" />
    <x-avatar src="/missing-avatar-image.jpg" name="이서연" show-fallback />
    <x-avatar src="/missing-avatar-image.jpg" name="fallback 미사용" />
    <x-avatar show-fallback />
</div>
```

## 사용자 정의 fallback

`fallback` 슬롯에 아이콘이나 HTML을 넣을 수 있습니다. 이미지 로드 실패 시 표시하려면 `show-fallback`을 함께 사용합니다.

```blade preview name="avatar-custom-fallback"
<div class="jds-example-row">
    <x-avatar src="/missing-camera-avatar.jpg" show-fallback>
        <x-slot:fallback>
            <x-icon name="camera-linear" />
        </x-slot:fallback>
    </x-avatar>
    <x-avatar src="/missing-jane-avatar.jpg" name="Jane" show-fallback />
    <x-avatar src="/missing-joe-avatar.jpg" name="Joe" />
</div>
```

## 아이콘 변경

이미지와 이름이 없을 때 표시되는 기본 아이콘은 `icon` named slot으로 교체합니다. 사용자 아이콘은 `24px`, 기본 Avatar 아이콘은 Avatar 크기의 `80%`로 표시됩니다.

```blade preview name="avatar-custom-icon"
<div class="jds-example-row">
    <x-avatar show-fallback>
        <x-slot:icon><x-icon name="camera-linear" /></x-slot:icon>
    </x-avatar>
    <x-avatar show-fallback>
        <x-slot:icon><x-icon name="buildings-linear" /></x-slot:icon>
    </x-avatar>
</div>
```

## 포커스 가능

정보 팝오버나 메뉴의 트리거처럼 키보드 포커스가 필요하면 `focusable`을 사용합니다. 단순 표시용 Avatar는 기본적으로 탭 순서에 포함되지 않습니다.

```blade preview name="avatar-focusable"
<div class="jds-example-row">
    <x-avatar focusable src="https://i.pravatar.cc/150?u=jds-focus-1" name="키보드 포커스 가능" />
    <x-avatar src="https://i.pravatar.cc/150?u=jds-focus-2" name="단순 표시" />
</div>
```

## Avatar Group

여러 Avatar를 겹쳐 표시할 때 `<x-avatar-group>`으로 묶습니다. 그룹의 크기, 색상, 모서리, 테두리 속성이 하위 Avatar에 일괄 적용됩니다.

```blade preview name="avatar-group-basic"
<x-avatar-group>
    <x-avatar src="https://i.pravatar.cc/150?u=jds-group-1" name="사용자 1" />
    <x-avatar src="https://i.pravatar.cc/150?u=jds-group-2" name="사용자 2" />
    <x-avatar src="https://i.pravatar.cc/150?u=jds-group-3" name="사용자 3" />
    <x-avatar src="https://i.pravatar.cc/150?u=jds-group-4" name="사용자 4" />
</x-avatar-group>
```

### 최대 표시 수와 전체 인원

`max` 이후 항목은 숨기고 남은 인원을 `+N`으로 표시합니다. 서버가 전체 인원만 알고 있다면 `total`을 함께 전달합니다.

```blade preview name="avatar-group-count"
<div class="jds-example-stack">
    <x-avatar-group :max="3">
        <x-avatar src="https://i.pravatar.cc/150?u=jds-count-1" name="사용자 1" />
        <x-avatar src="https://i.pravatar.cc/150?u=jds-count-2" name="사용자 2" />
        <x-avatar src="https://i.pravatar.cc/150?u=jds-count-3" name="사용자 3" />
        <x-avatar src="https://i.pravatar.cc/150?u=jds-count-4" name="사용자 4" />
        <x-avatar src="https://i.pravatar.cc/150?u=jds-count-5" name="사용자 5" />
    </x-avatar-group>

    <x-avatar-group :max="3" :total="10" color="primary">
        <x-avatar src="https://i.pravatar.cc/150?u=jds-total-1" name="사용자 1" />
        <x-avatar src="https://i.pravatar.cc/150?u=jds-total-2" name="사용자 2" />
        <x-avatar src="https://i.pravatar.cc/150?u=jds-total-3" name="사용자 3" />
    </x-avatar-group>
</div>
```

## 이미지 속성

`image-attributes`로 실제 `<img>`에 필요한 HTML 속성을 전달할 수 있습니다.

```blade preview name="avatar-image-attributes"
<x-avatar
    src="https://i.pravatar.cc/150?u=jds-image-attributes"
    name="김민준"
    :image-attributes="['loading' => 'eager', 'referrerpolicy' => 'no-referrer']"
/>
```

## 슬롯

- `base`: Avatar 전체 영역
- `img`: 실제 이미지
- `fallback`: 이미지가 없거나 로드에 실패했을 때 표시되는 영역
- `name`: fallback 이니셜
- `icon`: 기본 또는 사용자 정의 아이콘
- Avatar Group의 `base`: 그룹 전체 영역
- Avatar Group의 `count`: 숨겨진 인원 수

## 상태와 Controller

루트에는 `data-hover`, `data-focus`, `data-focus-visible`, `data-loaded`, `data-fallback-visible`, `data-disabled`가 반영됩니다.

```js
const avatar = AppUI.get(document.querySelector('[data-ui-component="avatar"]'));

avatar.setSource('/images/new-profile.jpg');
avatar.showFallback(true);
```

Avatar Group의 `refresh()`는 동적으로 추가된 Avatar와 `max`, `total`을 다시 계산합니다.

## 접근성

이미지는 `name` 또는 `alt`를 접근 가능한 이름으로 사용합니다. fallback도 `role="img"`와 같은 이름을 유지합니다. 상호작용이 필요한 경우에만 `focusable`을 사용하고, 클릭 동작은 Avatar를 감싼 실제 `<button>` 또는 메뉴 트리거에 연결하는 것이 좋습니다.
