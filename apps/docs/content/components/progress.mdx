## 사용법

`value`를 지정하면 `min-value`와 `max-value` 사이의 진행률을 계산합니다. 화면에 라벨을 표시하지 않는 경우 접근성을 위해 `aria-label`을 반드시 지정하세요.

```blade preview name="progress-basic"
<x-progress aria-label="파일 업로드 진행률" value="60" />
```

## 크기

`sm`, `md`, `lg`를 지원합니다. 막대 높이는 각각 4px, 12px, 20px이며 라벨 크기도 함께 변경됩니다.

```blade preview name="progress-sizes"
<div class="jds-example-stack" style="width:100%">
    <x-progress aria-label="작은 진행률" size="sm" value="30" />
    <x-progress aria-label="중간 진행률" size="md" value="50" />
    <x-progress aria-label="큰 진행률" size="lg" value="70" />
</div>
```

## 색상

`default`, `primary`, `secondary`, `success`, `warning`, `danger` 의미 색상을 사용할 수 있습니다.

```blade preview name="progress-colors"
<div class="jds-example-stack" style="width:100%">
    @foreach(['default', 'primary', 'secondary', 'success', 'warning', 'danger'] as $color)
        <x-progress :aria-label="$color . ' 진행률'" :color="$color" value="70" />
    @endforeach
</div>
```

## 진행률을 알 수 없는 작업

완료 시점을 계산할 수 없는 작업에는 `indeterminate`를 사용합니다. 이 상태에서는 값과 관련된 ARIA 속성을 출력하지 않습니다.

```blade preview name="progress-indeterminate"
<x-progress aria-label="불러오는 중" indeterminate />
```

## 줄무늬

`striped`를 지정하면 현재 색상에 맞는 줄무늬 표시를 사용합니다.

```blade preview name="progress-striped"
<x-progress aria-label="파일 업로드 진행률" value="60" color="warning" striped />
```

## 라벨 표시

`label`을 지정하면 막대 위에 작업명을 표시합니다. 라벨 자체가 접근 가능한 이름으로 사용되므로 별도의 `aria-label`은 필요하지 않습니다.

```blade preview name="progress-label"
<x-progress label="불러오는 중..." value="55" />
```

## 값 표시

`show-value-label`을 지정하면 라벨 오른쪽에 현재 값을 표시합니다. 기본 형식은 백분율입니다.

```blade preview name="progress-value"
<x-progress label="다운로드 중..." value="40" show-value-label />
```

## 값 형식

`format-options`는 브라우저의 `Intl.NumberFormat` 옵션을 그대로 사용합니다. `locale`을 생략하면 문서의 `lang` 값을 사용합니다. 완전히 고정된 문구가 필요하면 `value-label`을 지정하세요.

```blade preview name="progress-formatting"
<div class="jds-example-stack" style="width:100%">
    <x-progress
        label="월간 지출"
        value="4000"
        min-value="0"
        max-value="10000"
        locale="ko-KR"
        :format-options="[
            'style' => 'currency',
            'currency' => 'KRW',
            'maximumFractionDigits' => 0,
        ]"
        show-value-label
    />
    <x-progress label="처리한 문서" value="24" max-value="50" value-label="24 / 50" show-value-label />
</div>
```

## 모서리

`none`, `sm`, `md`, `lg`, `full`을 지원하며 기본값은 `full`입니다.

```blade preview name="progress-radius"
<div class="jds-example-stack" style="width:100%">
    @foreach(['none', 'sm', 'md', 'lg', 'full'] as $radius)
        <x-progress :aria-label="$radius . ' 모서리 진행률'" :radius="$radius" value="65" />
    @endforeach
</div>
```

## 비활성화와 애니메이션

`disabled`는 진행률을 흐리게 표시하며 `aria-disabled`도 함께 제공합니다. `disable-animation`을 사용하면 값 변경과 불확정 상태의 움직임을 제거합니다. 사용자가 동작 줄이기를 설정한 경우에도 애니메이션은 자동으로 정지합니다.

```blade preview name="progress-states"
<div class="jds-example-stack" style="width:100%">
    <x-progress label="일시 중지됨" value="45" disabled show-value-label />
    <x-progress label="애니메이션 없음" value="70" disable-animation show-value-label />
</div>
```

## 사용자 정의 스타일

모든 부분은 안정적인 `data-slot`을 제공합니다. 컴포넌트에 클래스를 추가한 뒤 필요한 부분만 선택해 변경할 수 있습니다.

```blade preview name="progress-custom-styles"
<style>
    .custom-progress [data-slot="track"] {
        height: 1.25rem;
        border-radius: .375rem;
        background: hsl(var(--secondary-100));
    }
    .custom-progress [data-slot="indicator"] {
        border-radius: .375rem;
        background: linear-gradient(90deg, hsl(var(--secondary)), hsl(var(--primary)));
    }
    .custom-progress [data-slot="labelWrapper"] {
        color: hsl(var(--secondary));
        font-weight: 600;
    }
</style>
<x-progress class="custom-progress" label="목표 달성" value="65" show-value-label />
```

## Controller와 이벤트

`AppUI.get(element)`에서 `getValue()`, `setValue(value)`, `setIndeterminate(boolean)`을 사용할 수 있습니다. 값이 변경되면 `app-ui:progress:change` 이벤트가 발생합니다.

```blade preview name="progress-controller"
<div class="jds-example-stack" style="width:100%">
    <x-progress id="upload-progress" label="업로드" value="25" show-value-label />
    <div class="jds-example-row">
        <x-button size="sm" variant="bordered" onclick="AppUI.get(document.querySelector('#upload-progress')).setValue(50)">50%</x-button>
        <x-button size="sm" variant="bordered" onclick="AppUI.get(document.querySelector('#upload-progress')).setValue(85)">85%</x-button>
        <x-button size="sm" variant="light" onclick="AppUI.get(document.querySelector('#upload-progress')).setIndeterminate(true)">계산 중</x-button>
    </div>
</div>
```

## 슬롯

- `base`: 전체 컨테이너
- `labelWrapper`: 라벨과 값 영역
- `label`: 작업 라벨
- `value`: 포맷된 값
- `track`: 진행률 트랙
- `indicator`: 현재 진행률 표시

## 접근성

- 루트는 `role="progressbar"`로 렌더링됩니다.
- 확정된 값에는 `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-valuetext`가 제공됩니다.
- `indeterminate` 상태에서는 값 관련 ARIA 속성을 제거합니다.
- 화면에 `label`이 없다면 반드시 `aria-label`을 지정해야 합니다.
