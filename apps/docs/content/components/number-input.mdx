## 사용법

라벨을 생략한 기본 입력입니다. 오른쪽 증감 버튼이나 `↑`, `↓` 키로 값을 변경할 수 있습니다.

```blade preview name="number-input-basic"
<div style="width:20rem;max-width:100%">
    <x-number-input name="amount" placeholder="금액을 입력하세요" />
</div>
```

## 비활성화

`disabled`는 사용자 입력과 증감 동작을 비활성화합니다.

```blade preview name="number-input-disabled"

</div>
```

## 읽기 전용

`read-only`는 현재 값을 보여주되 사용자가 변경하지 못하게 합니다.


## 값 제어

Blade 렌더링 이후에는 Controller의 `getValue()`와 `setValue()`로 값을 제어합니다. 값이 바뀌면 `app-ui:number-input:change`에서 현재 숫자를 받을 수 있습니다.

```blade preview name="number-input-controlled"
<div id="number-input-controlled-example" style="display:flex;width:15rem;max-width:100%;flex-direction:column;gap:.5rem">
    <x-number-input label="금액" placeholder="숫자를 입력하세요" />
    <p style="margin:0;color:hsl(var(--default-500));font-size:.875rem">NumberInput 값: <output data-value></output></p>
</div>
<script>
    document.querySelector('#number-input-controlled-example [data-ui-component="number-input"]')
        ?.addEventListener('app-ui:number-input:change', (event) => {
            document.querySelector('#number-input-controlled-example [data-value]').textContent = event.detail.value ?? ''
        })
</script>
```

## 폼과 함께 사용

화면에는 지역화된 값을 보여주고 같은 컴포넌트의 hidden input이 서식을 제거한 숫자를 전송합니다. `<x-form>`은 native 폼 제출과 Controller 기반 서버 오류를 모두 지원합니다.

### 사용자 정의 유효성 검사

입력값이 바뀔 때 Controller의 `setInvalid()`로 업무 규칙을 적용합니다. 아래 예제는 100 초과, 1000 미만만 허용하고 777은 별도 오류로 처리합니다.

```blade preview name="number-input-form"
<x-form id="number-input-custom-validation" style="width:20rem;max-width:100%">
    <x-number-input name="amount" label="금액" placeholder="숫자를 입력하세요" required />
    <x-button color="primary" type="submit">제출</x-button>
    <div data-submitted hidden style="color:hsl(var(--default-500));font-size:.875rem"></div>
</x-form>
<script>
    const customForm = document.querySelector('#number-input-custom-validation')
    const customNumber = customForm?.querySelector('[data-ui-component="number-input"]')
    customNumber?.addEventListener('app-ui:number-input:change', (event) => {
        const value = event.detail.value
        const message = value !== null && value <= 100
            ? '100보다 큰 숫자를 입력하세요.'
            : value >= 1000
                ? '1000보다 작은 숫자를 입력하세요.'
                : value === 777 ? '다시 시도해 주세요.' : ''
        AppUI.get(customNumber)?.setInvalid(Boolean(message), message)
    })
    customForm?.addEventListener('submit', (event) => {
        event.preventDefault()
        const output = customForm.querySelector('[data-submitted]')
        output.hidden = false
        output.textContent = `제출한 값: ${JSON.stringify(Object.fromEntries(new FormData(customForm)))}`
    })
</script>
```

### 실시간 유효성 검사

오류 배열을 줄바꿈 문자열로 전달하면 입력하는 즉시 여러 검증 결과를 함께 표시할 수 있습니다.

```blade preview name="number-input-realtime-validation"
<x-form id="number-input-realtime-form" style="width:20rem;max-width:100%">
    <x-number-input name="amount" label="금액" placeholder="숫자를 입력하세요" invalid
        :error-message="implode(PHP_EOL, ['값을 입력하세요.', '100보다 큰 숫자를 입력하세요.'])" />
    <x-button color="primary" type="submit">제출</x-button>
    <div data-submitted hidden style="color:hsl(var(--default-500));font-size:.875rem"></div>
</x-form>
<script>
    const realtimeForm = document.querySelector('#number-input-realtime-form')
    const realtimeNumber = realtimeForm?.querySelector('[data-ui-component="number-input"]')
    realtimeNumber?.addEventListener('app-ui:number-input:change', (event) => {
        const value = event.detail.value
        const errors = []
        if (value === null) errors.push('값을 입력하세요.')
        if (value === null || value <= 100) errors.push('100보다 큰 숫자를 입력하세요.')
        if (value > 1000) errors.push('1000보다 작은 숫자를 입력하세요.')
        AppUI.get(realtimeNumber)?.setInvalid(errors.length > 0, errors.join('\n'))
    })
    realtimeForm?.addEventListener('submit', (event) => {
        event.preventDefault()
        const output = realtimeForm.querySelector('[data-submitted]')
        output.hidden = false
        output.textContent = `제출한 값: ${JSON.stringify(Object.fromEntries(new FormData(realtimeForm)))}`
    })
</script>
```

### 서버 유효성 검사

서버에서 받은 `{필드명: 오류 문구}` 객체는 Form Controller의 `setValidationErrors()`로 연결합니다.

```blade preview name="number-input-server-validation"
<x-form id="number-input-server-form" style="width:20rem;max-width:100%">
    <x-number-input name="amount" label="금액" placeholder="숫자를 입력하세요" required />
    <x-button color="primary" type="submit">제출</x-button>
</x-form>
<script>
    const serverForm = document.querySelector('#number-input-server-form')
    serverForm?.querySelector('[data-ui-component="number-input"]')
        ?.addEventListener('app-ui:number-input:change', () => AppUI.get(serverForm)?.clearValidationErrors())
    serverForm?.addEventListener('submit', (event) => {
        event.preventDefault()
        const button = serverForm.querySelector('[type="submit"]')
        button.disabled = true
        const label = button.textContent
        button.textContent = '확인 중...'
        window.setTimeout(() => {
            AppUI.get(serverForm)?.setValidationErrors({amount: '이 금액은 사용할 수 없습니다.'})
            button.disabled = false
            button.textContent = label
        }, 500)
    })
</script>
```

## Controller와 이벤트

값이 바뀌면 native `input`, `change`와 `app-ui:number-input:change` 이벤트가 발생합니다. Controller는 `getValue`, `setValue`, `increment`, `decrement`, `clear`, `focus`, `destroy`를 제공합니다.

```js
const field = document.querySelector('[data-ui-component="number-input"]');
const numberInput = AppUI.get(field);

numberInput.setValue(12);
numberInput.increment();
console.log(numberInput.getValue());
```

## 슬롯

`base`, `label`, `main-wrapper`, `input-wrapper`, `inner-wrapper`, `input`, `hidden-input`, `clear-button`, `stepper-wrapper`, `increase-button`, `decrease-button`, `description`, `error-message`에 안정적인 `data-slot`을 제공합니다.

## 접근성

표시 입력은 `role="spinbutton"`과 `aria-valuemin`, `aria-valuemax`, `aria-valuenow`를 사용합니다. 방향키, Page Up/Down, Home/End를 지원하고 라벨·설명·오류를 각각 연결합니다.

## API 안내

- `variant`: `flat`(기본), `bordered`, `faded`, `underlined`
- `color`: `default`(기본), `primary`, `secondary`, `success`, `warning`, `danger`
- `size`: `sm`, `md`(기본), `lg`
- `radius`: `none`, `sm`, `md`(기본), `lg`, `full`
- `label-placement`: `inside`(기본), `outside`, `outside-left`, `outside-top`
- `min`, `max`, `step`: 값 범위와 증감 단위
- `format-options`, `locale`: 표시용 숫자 서식
- `clearable`, `hide-stepper`, `wheel-disabled`, `disabled`, `read-only`, `required`, `invalid`, `full-width`: Boolean 상태
