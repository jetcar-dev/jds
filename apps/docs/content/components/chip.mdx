## 사용법

기본 Chip은 짧은 텍스트를 한 줄로 표시합니다.

```blade preview name="chip-basic"
<x-chip>Chip</x-chip>
```

## 비활성화

`disabled`를 지정하면 흐리게 표시되고 닫기 같은 상호작용도 비활성화됩니다.

```blade preview name="chip-disabled"
<x-chip disabled>비활성화</x-chip>
<x-chip color="primary" closable disabled>완료</x-chip>
```

## 크기

`size`는 `sm`, `md`, `lg`를 지원하며 기본값은 `md`입니다.

```blade preview name="chip-sizes"
<x-chip size="sm">Small</x-chip>
<x-chip size="md">Medium</x-chip>
<x-chip size="lg">Large</x-chip>
```

## 색상

의미에 맞게 `default`, `primary`, `secondary`, `success`, `warning`, `danger`를 사용합니다.

```blade preview name="chip-colors"
<x-chip color="default">Default</x-chip>
<x-chip color="primary">Primary</x-chip>
<x-chip color="secondary">Secondary</x-chip>
<x-chip color="success">Success</x-chip>
<x-chip color="warning">Warning</x-chip>
<x-chip color="danger">Danger</x-chip>
```

## 모서리

`radius`는 `none`, `sm`, `md`, `lg`, `full`을 지원하며 기본값은 `full`입니다.

```blade preview name="chip-radius"
<x-chip radius="none" color="primary">None</x-chip>
<x-chip radius="sm" color="primary">Small</x-chip>
<x-chip radius="md" color="primary">Medium</x-chip>
<x-chip radius="lg" color="primary">Large</x-chip>
<x-chip radius="full" color="primary">Full</x-chip>
```

```blade preview name="chip-variants"

<x-chip variant="bordered" color="primary">Bordered</x-chip>
<x-chip variant="light" color="primary">Light</x-chip>
<x-chip variant="flat" color="primary">Flat</x-chip>
<x-chip variant="faded" color="primary">Faded</x-chip>
<x-chip variant="shadow" color="primary">Shadow</x-chip>
<x-chip variant="dot" color="primary">Dot</x-chip>
```

## 시작과 끝 콘텐츠

`startContent`, `endContent` named slot에 아이콘이나 짧은 콘텐츠를 넣을 수 있습니다.

```blade preview name="chip-content"
<x-chip color="success" variant="flat">
    <x-slot:startContent><x-icon name="bolt-linear" /></x-slot:startContent>
    활성
</x-chip>

<x-chip color="primary" variant="flat">
    저장됨
    <x-slot:endContent><x-icon name="bookmark-bold" /></x-slot:endContent>
</x-chip>
```

## 닫기 버튼

`closable`을 지정하면 닫기 버튼이 생깁니다. 클릭하면 사라지고 `app-ui:chip:close` 이벤트가 발생합니다.

```blade preview name="chip-close"
<x-chip closable>Chip</x-chip>
<x-chip closable color="primary">Primary</x-chip>
<x-chip closable color="danger" variant="flat">삭제 예정</x-chip>
```

## Avatar와 함께 사용

`avatar` named slot은 Chip 크기에 맞게 자동으로 배치됩니다.

```blade preview name="chip-avatar"
<x-chip color="secondary" variant="flat">
    <x-slot:avatar><x-avatar name="김제트" /></x-slot:avatar>
    김제트
</x-chip>

<x-chip color="primary" variant="flat" closable>
    <x-slot:avatar><x-avatar name="JDS" color="primary" /></x-slot:avatar>
    Designer
</x-chip>
```

## Chip 목록

여러 항목은 일반 Blade 반복문으로 렌더링할 수 있습니다. 배열 전용 API가 필요하지 않습니다.

```blade preview name="chip-list"
@foreach (['Blade', 'Vanilla JS', 'CSS'] as $technology)
    <x-chip variant="flat" color="primary" closable>{{ $technology }}</x-chip>
@endforeach
```

## 닫기 아이콘 변경

`closeIcon` named slot으로 기본 닫기 아이콘을 교체합니다. `closable`과 함께 사용합니다.

```blade preview name="chip-custom-close"
<x-chip closable color="warning" variant="flat">
    확인 필요
    <x-slot:closeIcon><x-icon name="close-circle-bold" /></x-slot:closeIcon>
</x-chip>
```

## 슬롯

| 슬롯 | 용도 |
| --- | --- |
| 기본 슬롯 | Chip의 텍스트 |
| `avatar` | 텍스트 앞 Avatar |
| `startContent` | 텍스트 앞 아이콘 또는 콘텐츠 |
| `endContent` | 텍스트 뒤 콘텐츠. `closable`일 때는 닫기 버튼 콘텐츠 |
| `closeIcon` | 기본 닫기 아이콘 교체 |

CSS를 직접 확장할 때는 `base`, `content`, `dot`, `avatar`, `start-content`, `end-content`, `close-button`의 안정적인 `data-slot`을 사용할 수 있습니다.

## 이벤트와 Controller

닫기 버튼을 누르면 `app-ui:chip:close`가 발생하며 `event.detail.value`에 Chip 텍스트가 전달됩니다. `AppUI.get(element)`는 `close()`, `getValue()`, `focus()`, `destroy()`를 제공합니다.

```js
const chip = document.querySelector('#status-chip')

chip.addEventListener('app-ui:chip:close', event => {
    console.log(event.detail.value)
})

AppUI.get(chip).close()
```

## 접근성

닫기 버튼은 실제 `button`으로 렌더링되어 Tab 키와 Enter 또는 Space 키로 실행할 수 있습니다. `disabled` 상태에서는 버튼도 함께 비활성화되며, 모션 감소 설정에서는 닫기 애니메이션을 생략합니다.
