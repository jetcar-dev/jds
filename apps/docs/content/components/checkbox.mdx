## 기본 사용법

Checkbox는 실제 HTML `input[type="checkbox"]`를 사용하므로 별도 연결 코드 없이 클릭, 키보드와 폼 전송이 동작합니다.

```blade preview name="checkbox-basic"
<x-checkbox checked name="option" value="yes">Option</x-checkbox>
```

## 비활성화

`disabled`를 지정하면 포인터와 키보드 입력을 막고 비활성화 상태를 표시합니다. 선택된 상태와 선택되지 않은 상태 모두 사용할 수 있습니다.

```blade preview name="checkbox-disabled"
<div style="display:flex;align-items:center;gap:2rem">
    <x-checkbox disabled>Option</x-checkbox>
    <x-checkbox checked disabled>Option</x-checkbox>
</div>
```

## 크기

`size`는 체크 영역과 라벨 크기를 함께 변경합니다.

```blade preview name="checkbox-sizes"
<div style="display:flex;align-items:center;gap:2rem">
    <x-checkbox checked size="sm">Small</x-checkbox>
    <x-checkbox checked size="md">Medium</x-checkbox>
    <x-checkbox checked size="lg">Large</x-checkbox>
</div>
```

## 색상

선택 상태에는 `default`, `primary`, `secondary`, `success`, `warning`, `danger` 의미 색상을 사용할 수 있습니다.

```blade preview name="checkbox-colors"
<div style="display:flex;flex-wrap:wrap;align-items:center;gap:2rem">
    <x-checkbox checked color="default">Default</x-checkbox>
    <x-checkbox checked color="primary">Primary</x-checkbox>
    <x-checkbox checked color="secondary">Secondary</x-checkbox>
    <x-checkbox checked color="success">Success</x-checkbox>
    <x-checkbox checked color="warning">Warning</x-checkbox>
    <x-checkbox checked color="danger">Danger</x-checkbox>
</div>
```

## 모서리

`radius`를 생략하면 크기에 맞는 기본 모서리를 사용합니다. 직접 지정할 때는 `none`, `sm`, `md`, `lg`, `full`을 사용합니다.

```blade preview name="checkbox-radius"
<div style="display:flex;flex-wrap:wrap;align-items:center;gap:2rem">
    <x-checkbox checked radius="full">Full</x-checkbox>
    <x-checkbox checked radius="lg">Large</x-checkbox>
    <x-checkbox checked radius="md">Medium</x-checkbox>
    <x-checkbox checked radius="sm">Small</x-checkbox>
    <x-checkbox checked radius="none">None</x-checkbox>
</div>
```

## 일부 선택

`indeterminate`는 하위 항목 중 일부만 선택된 상태를 나타냅니다. 이 표시는 사용자가 눌러도 유지되며, 상태를 끝내려면 controller의 `setIndeterminate(false)`를 호출합니다.

```blade preview name="checkbox-indeterminate"
<x-checkbox indeterminate>Option</x-checkbox>
```

## 취소선

`line-through`를 사용하면 선택된 라벨 중앙에 취소선을 표시합니다.

```blade preview name="checkbox-line-through"
<x-checkbox checked line-through>Option</x-checkbox>
```

## 사용자 지정 아이콘

`icon` named slot으로 기본 체크 표시를 원하는 아이콘으로 바꿀 수 있습니다.

```blade preview name="checkbox-custom-icon"
<x-checkbox checked color="danger">
    <x-slot:icon>
        <x-icon name="solar:heart-bold" />
    </x-slot:icon>
    Favorite
</x-checkbox>
```

루트에 사용자 클래스를 지정하고 공개된 `data-slot`을 선택하면 Checkbox의 각 부분을 안전하게 꾸밀 수 있습니다. 상태별 스타일은 `data-selected`, `data-hover`, `data-focus-visible` 같은 상태 속성을 사용합니다.


## 값 제어

`AppUI.get()`으로 controller를 얻어 현재 선택값을 읽거나 변경할 수 있습니다. `setValue()`는 native `input`, `change`와 `app-ui:checkbox:change` 이벤트를 함께 발생시킵니다.

```blade preview name="checkbox-controlled"
<div style="display:flex;align-items:center;gap:2rem">
    <x-checkbox id="subscribe-checkbox">Subscribe</x-checkbox>
    <x-button
        type="button"
        size="sm"
        onclick="const checkbox=document.getElementById('subscribe-checkbox').closest('[data-ui-component=checkbox]');const controller=AppUI.get(checkbox);controller.setValue(!controller.getValue())"
    >
        선택 전환
    </x-button>
</div>
```

## 폼과 유효성

`name`, `value`, `required`, `readonly`, `invalid`를 일반 Blade boolean 속성으로 지정할 수 있습니다. `readonly`는 현재 값을 폼에 포함하지만 사용자가 바꾸지 못하게 합니다.

```blade preview name="checkbox-form"
<form onsubmit="event.preventDefault()" style="display:grid;gap:1rem">
    <x-checkbox name="terms" value="accepted" required>이용약관에 동의합니다</x-checkbox>
    <x-checkbox invalid>필수 확인 항목입니다</x-checkbox>
    <x-checkbox checked name="notice" value="yes">공지 수신 상태</x-checkbox>
    <x-checkbox checked readonly name="policy" value="locked">관리자 고정 정책</x-checkbox>
    <x-button type="submit" size="sm">전송</x-button>
</form>
```

## 슬롯

- `base`: Checkbox 전체를 감싸는 클릭 영역
- `wrapper`: 선택 배경과 테두리를 표시하는 영역
- `hidden-input`: 폼 전송과 키보드 입력을 담당하는 실제 Checkbox
- `icon`: 체크 또는 일부 선택 표시
- `label`: Checkbox에 연결된 텍스트

## 상태 속성

루트에는 상태에 따라 `data-selected`, `data-pressed`, `data-invalid`, `data-readonly`, `data-indeterminate`, `data-hover`, `data-focus`, `data-focus-visible`, `data-disabled`, `data-loading`이 반영됩니다.

## 이벤트와 Controller

값 변경 시 native `input`, `change`와 `app-ui:checkbox:change` 이벤트가 발생합니다. CustomEvent의 `detail`에는 `selected`, `indeterminate`, `value`가 포함됩니다.

```js
const checkbox = document.querySelector('[data-ui-component="checkbox"]');
const controller = AppUI.get(checkbox);

controller.getValue();
controller.setValue(true);
controller.setIndeterminate(true);
controller.setIndeterminate(false);
controller.focus();
```

## 접근성

실제 Checkbox input과 이를 감싼 label을 사용합니다. `Tab`으로 초점을 이동하고 `Space`로 상태를 바꿀 수 있으며, `required`, `aria-invalid`, `aria-readonly`, `aria-disabled` 상태가 함께 전달됩니다.
