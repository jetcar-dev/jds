## 사용법

`value`, `min-value`, `max-value`, `step`으로 선택 범위를 정합니다. 현재 값은 기본으로 라벨 오른쪽에 표시되며 실제 `range` 입력으로 폼에 제출됩니다.

```blade preview name="slider-basic"
<x-slider name="temperature" label="온도" :value="40" :min-value="0" :max-value="100" />
```

## 비활성화

```blade preview name="slider-disabled"
<x-slider label="음량" :value="35" disabled />
```

## 크기

`sm`, `md`, `lg`에 따라 트랙과 손잡이 크기가 함께 바뀝니다.

```blade preview name="slider-sizes"
<x-slider label="Small" size="sm" :value="20" />
<x-slider label="Medium" size="md" :value="50" />
<x-slider label="Large" size="lg" :value="80" />
```

## 모서리

`none`, `sm`, `md`, `lg`, `full`을 지원합니다.

```blade preview name="slider-radius"
<x-slider label="None" radius="none" :value="20" />
<x-slider label="Small" radius="sm" :value="40" />
<x-slider label="Medium" radius="md" :value="60" />
<x-slider label="Large" radius="lg" :value="80" />
<x-slider label="Full" radius="full" :value="100" />
```

## 눈금

`marks`에는 `value`와 `label`을 가진 배열을 전달합니다. 눈금 라벨을 누르면 해당 값으로 이동합니다.

```blade preview name="slider-marks"
<x-slider label="월 예산" :value="50" :step="10" :marks="[
    ['value' => 0, 'label' => '0원'],
    ['value' => 50, 'label' => '50만 원'],
    ['value' => 100, 'label' => '100만 원'],
]" />
```

## 범위 선택

`value`에 두 값을 전달하면 두 손잡이 사이를 선택합니다. 폼에서는 같은 이름의 배열로 제출됩니다.

```blade preview name="slider-range"
<x-slider name="price" label="가격 범위" :value="[100, 500]" :min-value="0" :max-value="1000" :step="10"
    :format-options="['style' => 'currency', 'currency' => 'KRW', 'maximumFractionDigits' => 0]" />
```

## 채우기 시작점

```blade preview name="slider-fill-offset"
<x-slider label="균형" :value="25" :min-value="-100" :max-value="100" :fill-offset="0" />
```

## 툴팁

손잡이를 가리키거나 조작할 때 값을 보여줍니다. `tooltip-value-format-options`로 출력 형식을 따로 정할 수 있습니다.

```blade preview name="slider-tooltip"
<x-slider label="완료율" :value="0.65" :min-value="0" :max-value="1" :step="0.05" show-tooltip
    :format-options="['style' => 'percent']"
    :tooltip-value-format-options="['style' => 'percent', 'maximumFractionDigits' => 0]" />
```

```blade preview name="slider-content"

    <x-slot:startContent><x-icon name="solar:sun-2-linear" /></x-slot:startContent>
    <x-slot:endContent><x-icon name="solar:sun-2-bold" /></x-slot:endContent>
</x-slider>
```

## 값 형식

`format-options`는 `Intl.NumberFormat` 옵션을 그대로 받습니다. `locale`로 표시 언어를 정할 수 있습니다.

```blade preview name="slider-format"
<x-slider label="예산" :value="350000" :min-value="0" :max-value="1000000" :step="10000" locale="ko-KR"
    :format-options="['style' => 'currency', 'currency' => 'KRW', 'maximumFractionDigits' => 0]" />
```

## 사용자 정의 손잡이

```blade preview name="slider-custom-thumb"
<x-slider label="전력" color="warning" :value="70" show-tooltip>
    <x-slot:thumb><x-icon name="solar:bolt-bold" /></x-slot:thumb>
</x-slider>
```

## 폼과 Controller

단일 값은 `volume=40`, 범위는 `price[]=100&price[]=500` 형태로 제출됩니다. 조작 중 `app-ui:slider:change`, 조작을 끝내면 `app-ui:slider:change-end`가 발생합니다.

```blade preview name="slider-form"
<form class="slider-form-example" method="post">
    <x-slider id="volume-slider" name="volume" label="음량" :value="40" />
    <x-button type="submit">저장</x-button>
</form>
<script>
const slider = document.querySelector('#volume-slider')
slider.addEventListener('app-ui:slider:change-end', (event) => console.log(event.detail.value))
// AppUI.get(slider).setValue(65)
</script>
<style>.slider-form-example{display:grid;gap:1.5rem;max-width:28rem}</style>
```

## 접근성

실제 `input[type="range"]`를 사용하므로 Tab으로 이동한 뒤 방향키, Page Up/Down, Home/End로 조작할 수 있습니다. 범위 선택의 두 손잡이는 서로를 넘어가지 않습니다.
