## 기본 사용법

`title`과 `description`으로 메시지의 제목과 설명을 구분합니다. Alert는 화면에
표시되는 즉시 보조 기술에 전달되도록 `role="alert"`로 렌더링됩니다.

```blade preview name="alert-basic"
<x-alert
    title="새로운 업데이트가 있습니다"
    description="페이지를 새로고침하면 최신 내용을 확인할 수 있습니다."
/>
```

## 색상

상황의 의미에 맞춰 여섯 가지 semantic color를 사용합니다. 색상을 지정하지
않으면 `default`가 적용됩니다.

```blade preview name="alert-colors"
<div class="jds-example-stack">
    <x-alert color="default" title="기본 안내" description="일반적인 정보를 전달합니다." />
    <x-alert color="primary" title="주요 안내" description="중요한 기능을 안내합니다." />
    <x-alert color="secondary" title="보조 안내" description="추가 정보를 전달합니다." />
    <x-alert color="success" title="저장 완료" description="변경 사항을 반영했습니다." />
    <x-alert color="warning" title="확인 필요" description="계속하기 전에 내용을 확인하세요." />
    <x-alert color="danger" title="저장 실패" description="입력값을 확인하고 다시 시도하세요." />
</div>
```

## 형태와 모서리

Alert가 지원하는 형태는 `solid`, `bordered`, `flat`, `faded`입니다. 모서리는
`none`, `sm`, `md`, `lg`, `full` 중에서 선택하며 기본값은 `md`입니다.

```blade preview name="alert-variants"
<div class="jds-example-stack">
    <x-alert variant="solid" color="primary" title="Solid" description="강한 배경으로 강조합니다." />
    <x-alert variant="bordered" color="secondary" title="Bordered" description="투명한 배경과 테두리를 사용합니다." />
    <x-alert variant="flat" color="success" title="Flat" description="부드러운 배경을 사용합니다." />
    <x-alert variant="faded" color="warning" title="Faded" description="부드러운 배경에 옅은 테두리를 더합니다." />
    <x-alert radius="full" color="danger" title="Full radius" />
</div>
```

## 아이콘, 작업과 닫기

색상별 기본 아이콘이 자동으로 표시됩니다. `hide-icon`은 아이콘 전체를 숨기고,
`hide-icon-wrapper`는 원형 배경만 제거합니다. `startContent`, `icon`,
`endContent` named slot으로 내용을 교체하거나 작업 버튼을 추가할 수 있습니다.
`closable` Alert를 닫으면 DOM에서 제거되고 `app-ui:alert:close` 및
`app-ui:alert:visible-change` 이벤트가 발생합니다.

```blade preview name="alert-content"
<div class="jds-example-stack">
    <x-alert hide-icon title="아이콘 없이 표시" description="텍스트만 필요한 경우입니다." />

    <x-alert hide-icon-wrapper color="primary" title="아이콘 배경 제거" />

    <x-alert color="secondary" title="사용자 정의 콘텐츠">
        <x-slot:icon><x-icon name="solar:bolt-bold" /></x-slot:icon>
        <x-slot:endContent><x-button size="sm" variant="light">확인</x-button></x-slot:endContent>
    </x-alert>

    <x-alert closable color="success" title="닫을 수 있는 알림" description="오른쪽 닫기 버튼을 눌러 보세요." />
</div>
```

## 슬롯

- `startContent`: 기본 아이콘보다 앞에 표시할 내용
- `icon`: 색상별 기본 아이콘을 대체할 내용
- 기본 슬롯: 제목과 설명 아래에 표시할 추가 내용
- `endContent`: 닫기 버튼 앞에 표시할 작업 또는 보조 내용

루트와 내부 요소에는 `base`, `main-wrapper`, `title`, `description`,
`icon-wrapper`, `alert-icon`, `close-button`, `start-content`, `end-content`
`data-slot`이 제공됩니다.

## 접근성

Alert는 `role="alert"`를 사용하며 닫기 버튼의 접근 가능한 이름은 `닫기`입니다.
긴급하지 않고 지속적으로 갱신되는 메시지는 Alert 대신 별도의 status 영역을
사용하세요.
