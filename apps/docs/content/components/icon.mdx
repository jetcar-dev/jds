JDS는 프로젝트 번들에 포함된 Iconify 아이콘을 `<x-icon>` 하나로 표시합니다. 별도 아이콘 패키지나 CDN은 필요하지 않습니다.

## 기본 사용법

`solar:` 접두사를 생략하면 Solar 아이콘으로 처리합니다. 다른 아이콘 세트는 접두사를 포함한 전체 이름을 사용합니다.

```blade preview name="icon-basic"
<div class="jds-example-row" style="font-size:1.5rem">
    <x-icon name="home-angle-2-linear" />
    <x-icon name="solar:user-linear" />
    <x-icon name="solar:calendar-search-linear" />
    <x-icon name="material-symbols:add-rounded" />
</div>
```

## 크기와 색상

아이콘은 `1em` 크기와 `currentColor`를 사용하므로 부모의 글자 크기와 색상을 그대로 따릅니다.

```blade preview name="icon-size-color"
<div class="jds-example-row">
    <span style="font-size:1rem;color:hsl(var(--default-600))"><x-icon name="info-circle-linear" /></span>
    <span style="font-size:1.5rem;color:hsl(var(--primary))"><x-icon name="info-circle-bold" /></span>
    <span style="font-size:2rem;color:hsl(var(--success))"><x-icon name="check-circle-bold" /></span>
    <span style="font-size:2.5rem;color:hsl(var(--danger))"><x-icon name="trash-bin-2-linear" /></span>
</div>
```

## 버튼에서 사용

버튼의 `startContent`, `endContent` 슬롯에 넣거나 `icon-only` 버튼의 본문으로 사용합니다.

```blade preview name="icon-button"
<div class="jds-example-row">
    <x-button color="primary">
        <x-slot:startContent><x-icon name="add-square-linear" /></x-slot:startContent>
        새 항목
    </x-button>
    <x-button variant="bordered">
        저장
        <x-slot:endContent><x-icon name="diskette-linear" /></x-slot:endContent>
    </x-button>
    <x-button icon-only variant="flat" aria-label="복사">
        <x-icon name="copy-linear" />
    </x-button>
</div>
```

## 전체 아이콘

현재 JDS 번들에 저장된 아이콘을 모두 표시합니다. 이름으로 검색할 수 있고, 항목을 누르면 `<x-icon>` 사용 코드가 복사됩니다.

## 속성

| 속성 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `name` | `string` | 필수 | 아이콘 이름입니다. 접두사가 없으면 `solar:`를 사용합니다. |
| 그 외 속성 | HTML attributes | - | `class`, `style`, `data-*` 등을 루트 `<span>`에 전달합니다. |

`x-icon`은 장식용 아이콘으로 렌더링되어 보조 기술에서 숨겨집니다. 아이콘만 있는 버튼이나 링크에는 반드시 `aria-label`을 지정하세요.
