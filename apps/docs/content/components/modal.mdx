## 사용법

`ModalTrigger`, `ModalContent`, `ModalHeader`, `ModalBody`, `ModalFooter`를 조합합니다. 열리면 첫 번째 조작 요소로 초점이 이동하고, 닫히면 열었던 버튼으로 초점이 돌아갑니다.

```blade preview name="modal-basic"
<x-modal>
    <x-modal-trigger>
        <x-button>Modal 열기</x-button>
    </x-modal-trigger>
    <x-modal-content>
        <x-modal-header>
            <x-modal-title>회원 추가</x-modal-title>
            <x-modal-description>새 회원 정보를 입력해 주세요.</x-modal-description>
        </x-modal-header>
        <x-modal-body>
            <x-input name="name" label="이름" />
            <x-input name="email" type="email" label="이메일" />
        </x-modal-body>
        <x-modal-footer>
            <x-button variant="light" color="danger" data-modal-close>취소</x-button>
            <x-button color="primary">저장</x-button>
        </x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 크기

`size`는 `xs`, `sm`, `md`, `lg`, `xl`, `2xl`, `3xl`, `4xl`, `5xl`, `full`을 지원합니다. 기본값은 `md`입니다.

```blade preview name="modal-sizes"
<div class="jds-example-row">
    @foreach (['xs', 'md', 'xl', '3xl', 'full'] as $size)
        <x-modal :size="$size">
            <x-modal-trigger><x-button variant="flat">{{ $size }}</x-button></x-modal-trigger>
            <x-modal-content>
                <x-modal-header><x-modal-title>{{ $size }} Modal</x-modal-title></x-modal-header>
                <x-modal-body>Modal의 최대 너비가 size에 맞게 변경됩니다.</x-modal-body>
                <x-modal-footer><x-button color="primary" data-modal-close>확인</x-button></x-modal-footer>
            </x-modal-content>
        </x-modal>
    @endforeach
</div>
```

## 닫기 제한

`dismissable="false"`는 배경 클릭 닫기를 막고, `keyboard-dismiss-disabled`는 Escape 닫기를 막습니다. 명시적인 닫기 버튼은 그대로 사용할 수 있습니다.

```blade preview name="modal-non-dismissible"
<x-modal :dismissable="false" keyboard-dismiss-disabled>
    <x-modal-trigger><x-button>닫기 제한 Modal</x-button></x-modal-trigger>
    <x-modal-content>
        <x-modal-header>
            <x-modal-title>작업을 완료해 주세요</x-modal-title>
            <x-modal-description>배경 클릭과 Escape 키로 닫히지 않습니다.</x-modal-description>
        </x-modal-header>
        <x-modal-body>아래 버튼을 사용해야 Modal을 닫을 수 있습니다.</x-modal-body>
        <x-modal-footer><x-button color="primary" data-modal-close>완료</x-button></x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 배치

`placement`는 `auto`, `top`, `center`, `bottom`을 지원합니다. `auto`는 모바일에서 아래쪽, 넓은 화면에서 중앙에 표시됩니다.

```blade preview name="modal-placement"
<div class="jds-example-row">
    @foreach (['auto', 'top', 'bottom', 'center'] as $placement)
        <x-modal :placement="$placement" size="sm">
            <x-modal-trigger><x-button variant="flat">{{ $placement }}</x-button></x-modal-trigger>
            <x-modal-content>
                <x-modal-header><x-modal-title>{{ $placement }}</x-modal-title></x-modal-header>
                <x-modal-body>선택한 위치에 Modal이 표시됩니다.</x-modal-body>
                <x-modal-footer><x-button data-modal-close>닫기</x-button></x-modal-footer>
            </x-modal-content>
        </x-modal>
    @endforeach
</div>
```

## 긴 내용과 스크롤

기본 `normal`은 Modal 전체 내부를 스크롤합니다. `inside`는 Body만 스크롤하고 Header와 Footer를 고정하며, `outside`는 화면 바깥 영역에서 Modal 전체를 스크롤합니다.

```blade preview name="modal-scroll"
<div class="jds-example-row">
    @foreach (['normal', 'inside', 'outside'] as $behavior)
        <x-modal :scroll-behavior="$behavior">
            <x-modal-trigger><x-button variant="flat">{{ $behavior }}</x-button></x-modal-trigger>
            <x-modal-content>
                <x-modal-header>
                    <x-modal-title>{{ $behavior }} 스크롤</x-modal-title>
                    <x-modal-description>내용이 길 때의 스크롤 방식을 비교합니다.</x-modal-description>
                </x-modal-header>
                <x-modal-body>
                    @for ($index = 1; $index <= 18; $index++)
                        <p>긴 내용 {{ $index }} — Modal 안에서 스크롤 위치와 고정 영역을 확인합니다.</p>
                    @endfor
                </x-modal-body>
                <x-modal-footer><x-button color="primary" data-modal-close>확인</x-button></x-modal-footer>
            </x-modal-content>
        </x-modal>
    @endforeach
</div>
```

## 배경 효과

`backdrop`은 `opaque`, `blur`, `transparent`를 지원합니다.

```blade preview name="modal-backdrop"
<div class="jds-example-row">
    @foreach (['opaque', 'blur', 'transparent'] as $backdrop)
        <x-modal :backdrop="$backdrop" size="sm">
            <x-modal-trigger><x-button variant="flat">{{ $backdrop }}</x-button></x-modal-trigger>
            <x-modal-content>
                <x-modal-header><x-modal-title>{{ $backdrop }} 배경</x-modal-title></x-modal-header>
                <x-modal-body>Modal 뒤의 화면 효과를 비교할 수 있습니다.</x-modal-body>
                <x-modal-footer><x-button data-modal-close>닫기</x-button></x-modal-footer>
            </x-modal-content>
        </x-modal>
    @endforeach
</div>
```

## 사용자 정의 배경

`ModalContent`의 `backdrop` slot에 원하는 HTML을 넣어 배경을 직접 구성할 수 있습니다.

```blade preview name="modal-custom-backdrop"
<x-modal backdrop="transparent">
    <x-modal-trigger><x-button>사용자 정의 배경</x-button></x-modal-trigger>
    <x-modal-content>
        <x-slot:backdrop>
            <div style="background:radial-gradient(circle at center,rgba(0,111,238,.28),rgba(0,0,0,.72));backdrop-filter:blur(5px)"></div>
        </x-slot:backdrop>
        <x-modal-header><x-modal-title>사용자 정의 배경</x-modal-title></x-modal-header>
        <x-modal-body>backdrop slot은 전체 Overlay 영역을 채웁니다.</x-modal-body>
        <x-modal-footer><x-button data-modal-close>닫기</x-button></x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 사용자 정의 움직임

`motion`은 Web Animations API의 `enter`, `exit`, `options` 값을 받습니다. React나 Framer Motion 없이 열림과 닫힘 움직임을 바꿀 수 있습니다.

```blade preview name="modal-custom-motion"
<x-modal :motion="[
    'enter' => [
        ['opacity' => 0, 'transform' => 'translateY(-28px) scale(.98)'],
        ['opacity' => 1, 'transform' => 'translateY(0) scale(1)'],
    ],
    'exit' => [
        ['opacity' => 1, 'transform' => 'translateY(0) scale(1)'],
        ['opacity' => 0, 'transform' => 'translateY(28px) scale(.98)'],
    ],
    'options' => ['duration' => 260, 'easing' => 'cubic-bezier(.16,1,.3,1)'],
]">
    <x-modal-trigger><x-button>사용자 정의 움직임</x-button></x-modal-trigger>
    <x-modal-content>
        <x-modal-header><x-modal-title>사용자 정의 움직임</x-modal-title></x-modal-header>
        <x-modal-body>motion 배열로 진입과 종료 움직임을 정의합니다.</x-modal-body>
        <x-modal-footer><x-button data-modal-close>닫기</x-button></x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 드래그

`draggable`을 사용하면 Header를 잡고 Modal을 이동할 수 있습니다. 기본적으로 화면 안에서만 움직이며, `draggable-overflow`를 함께 사용하면 화면 경계를 넘어갈 수 있습니다.

```blade preview name="modal-draggable"
<div class="jds-example-row">
    <x-modal draggable>
        <x-modal-trigger><x-button variant="flat">화면 안에서 드래그</x-button></x-modal-trigger>
        <x-modal-content>
            <x-modal-header><x-modal-title>Header를 드래그하세요</x-modal-title></x-modal-header>
            <x-modal-body>Modal은 화면 경계 안에서 움직입니다.</x-modal-body>
            <x-modal-footer><x-button data-modal-close>닫기</x-button></x-modal-footer>
        </x-modal-content>
    </x-modal>
    <x-modal draggable draggable-overflow>
        <x-modal-trigger><x-button variant="flat">경계 밖 드래그</x-button></x-modal-trigger>
        <x-modal-content>
            <x-modal-header><x-modal-title>경계 밖 이동 허용</x-modal-title></x-modal-header>
            <x-modal-body>화면 바깥까지 Modal을 옮길 수 있습니다.</x-modal-body>
            <x-modal-footer><x-button data-modal-close>닫기</x-button></x-modal-footer>
        </x-modal-content>
    </x-modal>
</div>
```

## 하나의 Modal을 여러 버튼에서 열기

Modal에 `id`를 주고 외부의 `ModalTrigger`에 `for`를 지정하면 여러 버튼이 같은 Modal을 열 수 있습니다.

```blade preview name="modal-external-triggers"
<div class="jds-example-row">
    <x-modal-trigger for="shared-member-modal"><x-button>회원 추가</x-button></x-modal-trigger>
    <x-modal-trigger for="shared-member-modal"><x-button variant="bordered">담당자 선택</x-button></x-modal-trigger>
</div>
<x-modal id="shared-member-modal" backdrop="blur">
    <x-modal-content>
        <x-modal-header><x-modal-title>회원 선택</x-modal-title></x-modal-header>
        <x-modal-body><x-input name="member" label="회원명" /></x-modal-body>
        <x-modal-footer><x-button data-modal-close>닫기</x-button></x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 닫기 버튼 사용자 정의

`ModalContent`의 `closeButton` slot으로 아이콘을 교체하거나, Modal의 `hide-close-button`으로 기본 버튼을 숨길 수 있습니다.

```blade preview name="modal-custom-close"
<x-modal>
    <x-modal-trigger><x-button variant="flat">사용자 정의 닫기</x-button></x-modal-trigger>
    <x-modal-content>
        <x-slot:closeButton><x-icon name="solar:close-circle-linear" /></x-slot:closeButton>
        <x-modal-header><x-modal-title>사용자 정의 버튼</x-modal-title></x-modal-header>
        <x-modal-body>닫기 버튼에도 동일한 hover와 focus 동작이 적용됩니다.</x-modal-body>
    </x-modal-content>
</x-modal>
```

## 사용자 정의 스타일

각 구성 요소에 일반 HTML `class`와 `style` 속성을 전달해 Modal 파트를 직접 꾸밀 수 있습니다. `ModalContent`는 base, `ModalHeader`, `ModalBody`, `ModalFooter`는 각 영역에 적용됩니다.

```blade preview name="modal-custom-styles"
<x-modal>
    <x-modal-trigger><x-button>사용자 정의 스타일</x-button></x-modal-trigger>
    <x-modal-content style="border:1px solid hsl(var(--primary));background:linear-gradient(145deg,hsl(var(--content1)),hsl(var(--primary-50)))">
        <x-modal-header style="border-bottom:1px solid hsl(var(--divider))">
            <x-modal-title>사용자 정의 Modal</x-modal-title>
        </x-modal-header>
        <x-modal-body style="padding-block:2rem">각 파트에 속성을 직접 전달할 수 있습니다.</x-modal-body>
        <x-modal-footer style="border-top:1px solid hsl(var(--divider))"><x-button data-modal-close>닫기</x-button></x-modal-footer>
    </x-modal-content>
</x-modal>
```

## 상태 속성

Modal root와 base에는 `data-open`, `data-dismissable`이 반영됩니다. wrapper에는 `data-size`, `data-radius`, `data-shadow`, `data-placement`, `data-scroll-behavior`, `data-draggable`이 표시되므로 사용자 CSS와 테스트에서 안정적으로 상태를 선택할 수 있습니다.

## 초기 상태, 스크롤 잠금과 Portal

`default-open`은 처음부터 Modal을 열고, `:should-block-scroll="false"`는 배경 문서의 스크롤 잠금을 해제합니다. `portal-target`에는 Overlay를 옮길 요소의 id 또는 CSS 선택자를 지정합니다.

```blade
<div id="erp-overlay-root"></div>

<x-modal
    default-open
    :should-block-scroll="false"
    portal-target="#erp-overlay-root"
>
    <x-modal-content>
        <x-modal-header><x-modal-title>초기 Modal</x-modal-title></x-modal-header>
        <x-modal-body>지정한 Portal에 바로 열립니다.</x-modal-body>
    </x-modal-content>
</x-modal>
```

## 이벤트와 Controller

열릴 때 `app-ui:modal:open`, 닫힐 때 `app-ui:modal:close`, 상태가 바뀔 때 `app-ui:modal:change` 이벤트가 발생합니다. `AppUI.get(modal)`에서 `open(trigger)`, `close(true)`, `getValue()`, `setValue(open)`, `focus()`, `destroy()`를 사용할 수 있습니다.

## 접근성

Modal은 `role="dialog"`, `aria-modal="true"`를 사용하고 Title과 Description을 자동 연결합니다. 열린 동안 배경을 비활성화하고 초점을 Modal 내부에 가두며, 닫힌 뒤에는 열었던 요소로 초점을 복원합니다.
