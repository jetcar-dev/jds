## 기본 사용법

`name`, `description`, `avatar`를 지정하면 Avatar와 사용자 정보를 한 줄로 표시합니다. Avatar는 HeroUI와 같은 기본 `md` 크기(40px)를 사용합니다.

```blade preview name="user-basic"
<x-user
    name="Jane Doe"
    description="Product Designer"
    avatar="https://i.pravatar.cc/150?u=jds-user-jane"
/>
```

> Avatar의 크기, 색상, 모서리와 fallback은 `avatar-attributes`로 전달합니다.

### 링크가 있는 설명

설명에 링크나 다른 Blade 컴포넌트를 넣을 때는 `description` named slot을 사용합니다.

```blade preview name="user-link-description"
<x-user name="Junior Garcia" avatar="https://i.pravatar.cc/150?u=jds-user-junior">
    <x-slot:description>
        <x-link href="https://x.com/jrgarciadev" size="sm" target="_blank">@jrgarciadev</x-link>
    </x-slot:description>
</x-user>
```

## Avatar 속성

`avatar-attributes`는 내부 `<x-avatar>`에 전달됩니다. `src`도 이 배열로 지정하면 `avatar`보다 우선합니다.

```blade preview name="user-avatar-attributes"
<div class="jds-example-row">
    <x-user name="김민준" description="개발자" :avatar-attributes="[
        'src' => 'https://i.pravatar.cc/150?u=jds-user-small',
        'size' => 'sm',
        'color' => 'primary',
        'bordered' => true,
    ]" />
    <x-user name="이서연" description="디자이너" :avatar-attributes="[
        'src' => 'https://i.pravatar.cc/150?u=jds-user-large',
        'size' => 'lg',
        'radius' => 'lg',
    ]" />
</div>
```

## 포커스 가능

단순 표시용 User는 탭 순서에 포함되지 않습니다. 메뉴나 Popover 트리거로 사용할 때만 `focusable`을 지정합니다.

```blade preview name="user-focusable"
<x-user
    focusable
    name="박지훈"
    description="키보드로 포커스할 수 있습니다"
    avatar="https://i.pravatar.cc/150?u=jds-user-focusable"
/>
```

## 사용자 정의 스타일

`class-names`로 `base`, `wrapper`, `name`, `description` 슬롯에 클래스를 추가할 수 있습니다. 별도 CSS에서는 안정적인 `data-slot`을 직접 선택할 수도 있습니다.

```blade preview name="user-custom-styles"
<x-user
    name="정유진"
    description="서비스 운영"
    avatar="https://i.pravatar.cc/150?u=jds-user-custom"
    :class-names="[
        'name' => 'user-example-name',
        'description' => 'user-example-description',
    ]"
/>
<style>
.user-example-name{color:hsl(var(--primary));font-weight:600}
.user-example-description{letter-spacing:.02em}
</style>
```

## 슬롯

- `base`: User 전체 영역
- `wrapper`: 이름과 설명을 묶는 영역
- `name`: 사용자 이름
- `description`: 보조 설명
- `name-content`: 이름에 넣을 사용자 정의 Blade 콘텐츠

## 접근성

Avatar의 대체 텍스트는 `name`을 사용합니다. `focusable`을 지정한 경우에만 `tabindex="0"`이 적용되며 키보드 포커스가 표시됩니다. 표시 전용 User는 폼 값이나 이벤트를 만들지 않습니다.
