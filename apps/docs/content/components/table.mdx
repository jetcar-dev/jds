## 기본 사용법

구조화된 행과 열 데이터를 표시하고 선택합니다.


## 크기와 상태

`sm`, `md`, `lg` 크기와 disabled, invalid, selected, loading 상태는 컴포넌트 성격에 맞게 사용합니다. 상태는 루트의 안정적인 `data-*` 속성에도 반영됩니다.

```blade preview name="table-states"
<div data-theme="dark" style="padding:1rem;background:var(--background);color:var(--foreground)"><x-table selection-mode="single"><x-table-header><x-table-row><x-table-column>이름</x-table-column><x-table-column>상태</x-table-column></x-table-row></x-table-header><x-table-body><x-table-row key="1" selectable><x-table-cell>홍길동</x-table-cell><x-table-cell>활성</x-table-cell></x-table-row></x-table-body></x-table></div>
```

## 폼 전송

입력 컴포넌트는 실제 input 또는 hidden input을 렌더링합니다. 표시 전용 컴포넌트는 폼 안에서도 값 전송에 관여하지 않습니다.

```blade preview name="table-form"
<form method="post"><x-table selection-mode="single"><x-table-header><x-table-row><x-table-column>이름</x-table-column><x-table-column>상태</x-table-column></x-table-row></x-table-header><x-table-body><x-table-row key="1" selectable><x-table-cell>홍길동</x-table-cell><x-table-cell>활성</x-table-cell></x-table-row></x-table-body></x-table><x-button type="submit" size="sm">전송</x-button></form>
```

## 슬롯

기본 슬롯과 컴포넌트별 named slot을 사용해 아이콘, 설명, 사용자 정의 콘텐츠를 배치합니다. 목록형 컴포넌트는 배열보다 명시적인 하위 컴포넌트를 기본으로 사용합니다.

## 이벤트와 Controller

값 변경 시 native `input/change`와 `app-ui:table:change` 이벤트가 발생합니다. `AppUI.get(element)`로 controller를 가져와 지원되는 `getValue`, `setValue`, `open`, `close`, `focus`, `destroy`를 호출할 수 있습니다.

## 접근성

접근 가능한 이름을 제공하고 키보드 탐색, focus-visible, reduced motion을 보존합니다. 아이콘만 있는 작업에는 반드시 `aria-label`을 지정합니다.
