## 기본 사용법

`TableHeader`, `TableColumn`, `TableBody`, `TableRow`, `TableCell`을 조합합니다. 기본값은 HeroUI v2처럼 둥근 wrapper와 작은 그림자를 사용합니다.

```blade preview name="table-basic"
<x-table aria-label="팀 구성원">
    <x-table-header>
        <x-table-row>
            <x-table-column>이름</x-table-column>
            <x-table-column>직무</x-table-column>
            <x-table-column>상태</x-table-column>
        </x-table-row>
    </x-table-header>
    <x-table-body>
        <x-table-row key="1"><x-table-cell>김민준</x-table-cell><x-table-cell>대표</x-table-cell><x-table-cell>활성</x-table-cell></x-table-row>
        <x-table-row key="2"><x-table-cell>이서연</x-table-cell><x-table-cell>기술 리드</x-table-cell><x-table-cell>일시 정지</x-table-cell></x-table-row>
        <x-table-row key="3"><x-table-cell>박도윤</x-table-cell><x-table-cell>시니어 개발자</x-table-cell><x-table-cell>활성</x-table-cell></x-table-row>
        <x-table-row key="4"><x-table-cell>최지우</x-table-cell><x-table-cell>커뮤니티 매니저</x-table-cell><x-table-cell>휴가</x-table-cell></x-table-row>
    </x-table-body>
</x-table>
```

## 열 너비

기본 `layout="auto"`는 셀 내용 길이에 맞춰 열 너비를 배분합니다. 같은 비율로 고정하려면 `layout="fixed"`를 사용하고, 특정 열만 조절하려면 `width`, `min-width`, `max-width`를 지정합니다. 기본 행 간격은 `compact`가 아닙니다.

```blade preview name="table-column-layout"
<x-table layout="fixed" aria-label="고정 너비 주문 목록">
    <x-table-header>
        <x-table-row>
            <x-table-column width="30%">주문번호</x-table-column>
            <x-table-column width="45%">고객</x-table-column>
            <x-table-column width="25%" align="end">금액</x-table-column>
        </x-table-row>
    </x-table-header>
    <x-table-body>
        <x-table-row key="1"><x-table-cell>ORD-1048</x-table-cell><x-table-cell>제트카 모빌리티</x-table-cell><x-table-cell align="end">₩1,240,000</x-table-cell></x-table-row>
        <x-table-row key="2"><x-table-cell>ORD-1049</x-table-cell><x-table-cell>아크모터스</x-table-cell><x-table-cell align="end">₩850,000</x-table-cell></x-table-row>
    </x-table-body>
</x-table>
```

## 빈 상태

행이 없을 때 `empty-content`로 안내 문구나 사용자 정의 콘텐츠를 표시합니다.

```blade preview name="table-empty"
<x-table aria-label="검색 결과">
    <x-table-header>
        <x-table-row><x-table-column>이름</x-table-column><x-table-column>직무</x-table-column><x-table-column>상태</x-table-column></x-table-row>
    </x-table-header>
    <x-table-body empty-content="표시할 데이터가 없습니다." />
</x-table>
```

## 선택 방식

기본 `toggle`은 각 행을 독립적으로 켜고 끕니다. `replace`는 일반 클릭으로 기존 선택을 교체하며, `Ctrl` 또는 `Cmd`를 누른 클릭과 `Shift` 범위 선택도 지원합니다.

```blade preview name="table-selection-behavior"
<x-table selection-mode="multiple" selection-behavior="replace" color="primary" :default-selected-keys="['1']" aria-label="교체 방식 구성원 선택">
    <x-table-header><x-table-row><x-table-column>이름</x-table-column><x-table-column>직무</x-table-column><x-table-column>상태</x-table-column></x-table-row></x-table-header>

        <x-table-row key="2"><x-table-cell>이서연</x-table-cell><x-table-cell>기술 리드</x-table-cell><x-table-cell>일시 정지</x-table-cell></x-table-row>
```

## 비활성 행

`disabled-keys`에 포함된 행은 선택할 수 없습니다. `disabled-behavior="selection"`은 행 작업은 허용하고 선택만 막으며, `all`은 행 작업까지 막습니다.

## 정렬

정렬 가능한 열에 `key`와 `allows-sorting`을 지정합니다. 변경 시 `app-ui:table:sort-change` 이벤트가 발생합니다.

```blade preview name="table-sorting"
<x-table sort-column="name" sort-direction="ascending" aria-label="정렬 가능한 구성원 목록">
    <x-table-header><x-table-row><x-table-column key="name" allows-sorting>이름</x-table-column><x-table-column key="role" allows-sorting>직무</x-table-column><x-table-column key="status">상태</x-table-column></x-table-row></x-table-header>
    <x-table-body>
        <x-table-row key="1"><x-table-cell>김민준</x-table-cell><x-table-cell>대표</x-table-cell><x-table-cell>활성</x-table-cell></x-table-row>
        <x-table-row key="2"><x-table-cell>이서연</x-table-cell><x-table-cell>기술 리드</x-table-cell><x-table-cell>일시 정지</x-table-cell></x-table-row>
        <x-table-row key="3"><x-table-cell>박도윤</x-table-cell><x-table-cell>시니어 개발자</x-table-cell><x-table-cell>활성</x-table-cell></x-table-row>
    </x-table-body>
</x-table>
```

정렬 아이콘은 `sortIcon` slot으로 교체할 수 있습니다.

```blade
<x-table-column key="name" allows-sorting>
    이름
    <x-slot:sortIcon><x-icon name="solar:arrow-up-bold" /></x-slot:sortIcon>
</x-table-column>
```

```blade preview name="table-form"
        </x-table-body>
    </x-table>
    <x-button type="submit" size="sm" color="primary">선택 저장</x-button>
</form>
```

## 이벤트와 Controller

선택 변경 시 `app-ui:table:change`, 정렬 변경 시 `app-ui:table:sort-change`, 행 작업 시 `app-ui:table:row-action` 이벤트가 발생합니다.

```js
const table = document.querySelector('#members-table')
const controller = AppUI.get(table)

controller.setValue(['1', '3'])
controller.setSort('name', 'descending')
```

## 접근성

Table은 `grid`로 노출됩니다. 방향키와 `Home`/`End`로 행을 이동하고, `Space`와 `Enter`로 선택하며, 여러 행 선택에서는 `Ctrl+A`로 전체 선택할 수 있습니다. `text-value`를 지정하면 키 입력으로 행을 빠르게 찾을 수 있습니다.
